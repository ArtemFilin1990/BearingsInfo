# Учебник по работе с базой знаний о подшипниках

> **Практический курс для работы с репозиторием Baza**  
> Основан на реальных данных из CSV-файлов и технических статей

---

## 📋 Оглавление и навигация

Этот учебник представляет собой **практическое руководство** по работе с данными репозитория Baza. Каждое утверждение подкреплено ссылками на исходные файлы. Стиль изложения — сухой, технический, инструктивный.

### Структура учебника

1. **[Введение](<./Введение.md>)**  
   Цель учебника, принципы работы, описание структуры репозитория

2. **[Модуль 1: Базовые параметры подшипников](<./Модуль_1_Базовые_параметры.md>)**  
   Основные характеристики: тип, размеры, серии диаметров и ширины

3. **[Модуль 2: Расшифровка обозначений ГОСТ](<./Модуль_2_Расшифровка_ГОСТ.md>)** ⭐ **Ключевой модуль**  
   Детальный разбор маркировки с примерами из реальных данных

4. **[Модуль 3: Поиск аналога ГОСТ ↔ ISO](<./Модуль_3_Поиск_аналога_ГОСТ_ISO.md>)**  
   Работа с таблицами соответствий, алгоритм подбора аналогов

5. **[Модуль 4: Работа с каталогом производителя](<./Модуль_4_Работа_с_каталогом_производителя.md>)**  
   Поиск подшипника в каталогах брендов по номеру ISO

6. **[Практикум: Итоговые задания](<./Практикум_Итоговые_задания.md>)**  
   Комплексные задачи, объединяющие навыки из всех модулей

## 🎯 Принципы работы с учебником

### 1. Фактология
Все примеры, расшифровки, таблицы соответствий взяты строго из:
- CSV-файлов в [`../../data/`](../../data/README.md)
- Статей в [`../../articles/`](../../articles/README.md)
- Каталогов в [`../../data/katalogi/README.md`](<../../data/katalogi/README.md>)

**Не добавляется информация**, которой нет в репозитории.

### 2. Прямые ссылки
В тексте используются **относительные гиперссылки** на исходные файлы:
- [`../../data/gost/bearings.csv`](../../data/gost/bearings.csv) — подшипники ГОСТ
- [`../../data/analogs/gost_iso.csv`](../../data/analogs/gost_iso.csv) — таблица аналогов
- [`../../articles/bearings/1_1_designations_gost_iso_etu/1_1_1_gost_designation_system.md`](../../articles/bearings/1_1_designations_gost_iso_etu/1_1_1_gost_designation_system.md) — система обозначений

### 3. Проверка на полноту
Если параметр **отсутствует в базе**, это явно указывается:
> ⚠️ **Параметр "масса" отсутствует в текущей версии [`data/gost/bearings.csv`](../../data/gost/bearings.csv).  
> Для уточнения используйте каталог производителя в [`../../data/katalogi/README.md`](<../../data/katalogi/README.md>).**

### 4. Структура урока
Каждый модуль строится по схеме:
1. **Теория** (ссылка на статью)
2. **Конкретный пример** (данные из CSV)
3. **Алгоритм действия**
4. **Задание** (с указанием файла для поиска ответа)

## 🗺️ Путь данных в репозитории

Учебник отражает логику работы с информацией о подшипниках:

```
Базовые понятия
    ↓
Система обозначений ГОСТ (разбор маркировки)
    ↓
Поиск аналога ISO по таблице соответствий
    ↓
Работа с каталогом конкретного бренда
```

## 🚀 Как начать работу

### Для новичков
Начните с **[Введения](<./Введение.md>)**, затем последовательно пройдите модули 1-4.

### Для опытных пользователей
Переходите напрямую к нужному модулю:
- Нужно расшифровать маркировку? → [Модуль 2](<./Модуль_2_Расшифровка_ГОСТ.md>)
- Ищете аналог? → [Модуль 3](<./Модуль_3_Поиск_аналога_ГОСТ_ISO.md>)
- Работаете с каталогом? → [Модуль 4](<./Модуль_4_Работа_с_каталогом_производителя.md>)

### Для проверки знаний
Выполните задания из [Практикума](<./Практикум_Итоговые_задания.md>).

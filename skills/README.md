# Agent Skills для BearingsInfo

Единый пакет навыков для работы с репозиторием `BearingsInfo`: каталог подшипников, ГОСТ/ISO, аналоги, Excel/CSV, PDF/DOCX-источники, B2B-контент и интеграционные правила.

## Назначение

Папка `skills/` хранит процедурные правила для AI-агентов и разработчиков. Каждый навык оформлен как отдельная папка с файлом `SKILL.md`. Агент должен подключать только тот навык, который соответствует текущей задаче.

## Состав пакета

| Skill | Когда использовать |
|---|---|
| `bearings-catalog` | Нормализация подшипников, ГОСТ/ISO, аналоги, суффиксы, размеры, масса, справочники |
| `xlsx-processing` | Excel/CSV, прайсы, каталоги, выгрузки, дедупликация, подготовка таблиц |
| `pdf-processing` | PDF-источники, каталоги производителей, извлечение таблиц, OCR, сверка страниц |
| `docx-processing` | DOCX-документы, отчёты, ТЗ, договорные и технические материалы |
| `everest-b2b-content` | B2B-тексты, сайт, карточки, коммерческие формулировки для ООО «Эверест» |
| `bitrix24-master` | Bitrix24, CRM, DaData, REST, поля, воронки, карточки товара и автоматизация |
| `everest-bitrix24-kb` | Создание, редактирование, генерация, валидация и безопасный Bitrix24 импорт базы знаний `Технический справочник «Эверест»` |
| `legal-contracts-everest` | Договоры поставки, протоколы разногласий, юридические риски в интересах ООО «Эверест» |

## Общий приоритет источников

1. Прямое указание пользователя в текущей задаче.
2. Загруженный файл, таблица, PDF, DOCX или CSV.
3. Файлы репозитория.
4. Документированные правила внутри `skills/`.
5. Общие знания.
6. Предположение — только если оно явно помечено.

## Общие запреты

- Не выдумывать размеры, массу, аналоги, бренды, сроки, цены, наличие, документы и источники.
- Не смешивать разные проекты без прямого указания.
- Не менять структуру файлов, таблиц и документов без необходимости.
- Не удалять строки и данные без лога изменений.
- Не записывать секреты, токены, webhook URL, API-ключи и приватные реквизиты в репозиторий.

## Формат результата для задач

Любой агент, работающий с этим пакетом, должен возвращать:

1. `РЕШЕНИЕ` — что сделано или что нужно сделать.
2. `ИЗМЕНЕНИЯ` — список изменённых файлов, строк, колонок или правил.
3. `ПРОВЕРКА` — как проверить результат.
4. `РИСКИ` — что может быть неверно или требует подтверждения.
5. `НЕИЗВЕСТНО` — какие данные отсутствуют.

## Проверка структуры skills

Для базовой проверки можно использовать скрипт:

```bash
python skills/scripts/validate_skills.py
```

Скрипт проверяет наличие `SKILL.md`, YAML-полей `name` и `description`, а также базовую структуру пакета.

# Внутренний зазор и предварительный натяг

## Назначение

Данный документ содержит исчерпывающую информацию о внутреннем зазоре подшипников, группах зазора, концепциях предварительного натяга, расчете рабочего зазора и правильном выборе зазора или предварительного натяга для различных применений. Понимание зазора и предварительного натяга имеет важное значение для оптимальной работы, долговечности и точности подшипников.

---

## 1. Основы внутреннего зазора

### 1.1 Определение

**Внутренний зазор (Internal Clearance):**

Общее расстояние, на которое одно кольцо подшипника может быть перемещено относительно другого кольца в радиальном или осевом направлении, когда подшипник не смонтирован и внешняя нагрузка не приложена.

**Ключевые характеристики:**
- Измеряется перед установкой (свободное состояние)
- Изменяется при монтаже (посадки создают натяг)
- Изменяется во время работы (температурное расширение)
- Критический параметр, влияющий на: распределение нагрузки, трение, долговечность, шум

### 1.2 Типы зазора

**1. Радиальный внутренний зазор (Radial Internal Clearance):**

Максимальное расстояние, на которое одно кольцо может быть радиально смещено относительно другого.

**Метод измерения:**
- Зафиксировать одно кольцо
- Сместить другое кольцо из одного крайнего радиального положения в противоположное
- Измерить общее смещение

**Применяется к:**
- Радиальным подшипникам (шариковым радиальным, роликовым цилиндрическим, роликовым сферическим)
- Радиально-упорным подшипникам

**2. Осевой внутренний зазор (Axial Internal Clearance):**

Максимальное расстояние, на которое одно кольцо может быть осевоо смещено относительно другого.

**Применяется к:**
- Шарикоподшипникам радиально-упорным
- Роликоподшипникам коническим (неразборные узлы)
- Упорным подшипникам

**Связь с радиальным зазором (радиально-упорные подшипники):**

```
Осевой зазор = Радиальный зазор / sin α
```

Где α = угол контакта

### 1.3 Эволюция зазора

**Три стадии зазора:**

**1. Начальный зазор (Initial Clearance / Начальный зазор):**
- В состоянии изготовления, до монтажа
- Обозначается на подшипнике (маркировка группы зазора)
- Эталонное состояние для спецификаций

**2. Посадочный зазор (Mounted Clearance / Посадочный зазор):**
- После монтажа на валу и в корпусе
- Зависит от посадок с натягом
- Обычно уменьшается от начального зазора

**3. Рабочий зазор (Operating Clearance / Рабочий зазор):**
- Во время работы при установившейся температуре
- Зависит от дифференциального температурного расширения
- Окончательный зазор, определяющий поведение подшипника

**Критическое соотношение:**

```
Начальный зазор > Посадочный зазор ≥ Рабочий зазор
```

**Цель:**

Выбрать начальный зазор так, чтобы рабочий зазор был оптимальным (слегка положительным для большинства применений).

### 2.6 Маркировка зазора на подшипнике

**Позиция в обозначении:**

Группа зазора указывается **перед** классом точности в обозначении подшипника.

**Примеры:**

- **75-313** → Группа 7, Класс 5, Подшипник 313
- **8-180213** → Группа 8, Подшипник 180213
- **0-32210** → Группа 0, Подшипник 32210
- **313** → Нормальный зазор (не маркируется), Подшипник 313

**Специальные обозначения:**

- **Н** (H) → Нестандартизированный (специальный зазор)
- **М** (M) → Нормальный зазор с требованиями к моменту
- **НТ** → Жесткий отбор (узкий допуск зазора)

## 3. Влияние монтажа на зазор

### 3.1 Влияние посадки с натягом

**Плотная посадка (натяг) вызывает:**

1. **Внутреннее кольцо:** Расширяется радиально наружу
2. **Наружное кольцо:** Сжимается радиально внутрь
3. **Суммарный эффект:** Уменьшение внутреннего зазора

**Формула уменьшения зазора:**

**Натяг внутреннего кольца (посадка на валу):**

```
Δs_inner ≈ d · Δd / dm
```

Где:
- d = диаметр отверстия [мм]
- Δd = эффективный натяг [мкм]
- dm = средний диаметр подшипника = (d + D) / 2

**Натяг наружного кольца (посадка в корпусе):**

```
Δs_outer ≈ D · ΔD / dm
```

Где:
- D = наружный диаметр [мм]
- ΔD = эффективный натяг [мкм]

**Полное уменьшение зазора:**

```
ΔCr = Δs_inner + Δs_outer
```

**Посадочный зазор:**

```
Cr_mounted = Cr_initial - ΔCr
```

### 3.2 Практические значения уменьшения зазора

**Типовые значения для стальных колец, цельного стального вала, разъемного корпуса:**

**Натяг внутреннего кольца (распространенные посадки):**

| Посадка (ISO) | Натяг [мкм] | Уменьшение зазора [мкм] |
|-----------|------------------|-------------------------|
| **g6** | Небольшой зазор | 0 (или небольшое увеличение) |
| **h5, h6** | Переходная | 0 - 5 |
| **j5, j6** | Переходная | 2 - 8 |
| **k5, k6** | Легкий натяг | 5 - 15 |
| **m5, m6** | Натяг | 10 - 25 |
| **n6** | Плотный натяг | 20 - 40 |
| **p6** | Очень плотный | 30 - 60 |

**Посадка наружного кольца (в корпусе):**

Обычно **H7, H8** (посадка с зазором) → минимальное влияние на зазор (уменьшение 0-5 мкм)

При плотной посадке в корпусе (редко):
- **M7, N7** → уменьшение 10-30 мкм

### 3.3 Пример расчета - влияние монтажа

**Дано:**
- Подшипник: 6308 (d = 40 мм, D = 90 мм, B = 23 мм)
- Начальный зазор: Cr = 18 мкм (группа CN, среднее значение)
- Посадка на валу: k6 (эффективный натяг ≈ 10 мкм)
- Посадка в корпусе: H7 (минимальное влияние, принять 2 мкм)

**Решение:**

```
dm = (40 + 90) / 2 = 65 мм

Δs_inner = 40 · 10 / 65 ≈ 6 мкм
Δs_outer ≈ 2 мкм

ΔCr = 6 + 2 = 8 мкм

Cr_mounted = 18 - 8 = 10 мкм
```

**Результат:** Посадочный зазор ≈ 10 мкм (все еще положительный).

## 4. Влияние температуры на зазор

### 4.1 Основы температурного расширения

**Различное температурное расширение:**

Во время работы:
- **Внутреннее кольцо:** Нагревается от вала (более высокая температура)
- **Наружное кольцо:** Охлаждается корпусом (более низкая температура)
- **Разница температур:** ΔT = T_inner - T_outer

**Типичная разница температур:**

- Нормальная работа: ΔT = 5 - 10°C
- Высокоскоростная работа: ΔT = 10 - 20°C
- Плохой теплоотвод: ΔT = 15 - 30°C

### 4.2 Температурное изменение зазора

**Внутреннее кольцо расширяется больше → Зазор уменьшается**

**Формула:**

```
ΔCr_thermal = α · dm · ΔT
```

Где:
- α = коэффициент теплового расширения [1/K]
  - Сталь: α ≈ 11,5 × 10⁻⁶ /K
  - Алюминиевый корпус: α ≈ 23 × 10⁻⁶ /K
- dm = средний диаметр [мм]
- ΔT = температура внутреннего кольца - температура наружного кольца [K или °C]

**Примечание:** Если корпус алюминиевый, наружное кольцо расширяется больше → частично компенсирует.

### 4.3 Пример - температурный эффект

**Дано:**
- Подшипник 6308: dm = 65 мм
- Посадочный зазор: Cr_mounted = 10 мкм
- Рабочая разница температур: ΔT = 15°C
- Стальной вал и стальной корпус

**Решение:**

```
ΔCr_thermal = 11,5 × 10⁻⁶ × 65 × 15
ΔCr_thermal = 11,2 мкм

Cr_operating = Cr_mounted - ΔCr_thermal
Cr_operating = 10 - 11,2 = -1,2 мкм
```

**Результат:** Рабочий зазор **слегка отрицательный** (легкий предварительный натяг).

**Интерпретация:** 
- Для прецизионных применений: Может быть приемлемым или даже желательным
- Для высокоскоростных: Риск перегрева → использовать больший начальный зазор (C3)

## 5. Расчет рабочего зазора

### 5.1 Полная процедура расчета

**Шаг 1: Определить начальный зазор** (из каталога или ГОСТ 24810)

**Шаг 2: Рассчитать уменьшение зазора из-за посадок**

```
ΔCr_fit = Δs_inner + Δs_outer
```

**Шаг 3: Рассчитать посадочный зазор**

```
Cr_mounted = Cr_initial - ΔCr_fit
```

**Шаг 4: Рассчитать температурное изменение зазора**

```
ΔCr_thermal = α · dm · ΔT
```

**Шаг 5: Рассчитать рабочий зазор**

```
Cr_operating = Cr_mounted - ΔCr_thermal
```

### 5.2 Желаемый рабочий зазор

**Оптимальный рабочий зазор зависит от применения:**

| Тип применения | Рекомендуемый Cr_operating |
|-----------------|------------------------|
| **Общее машиностроение, нормальная точность** | +5 до +15 мкм (слегка положительный) |
| **Высокая точность, минимальное биение** | 0 до +5 мкм (очень малый или нулевой) |
| **Высокая скорость, легкая нагрузка** | +10 до +25 мкм (положительный) |
| **Тяжелая нагрузка, ударная** | +15 до +30 мкм (больший положительный) |
| **Прецизионные шпиндели, с предварительным натягом** | -5 до -20 мкм (отрицательный = предварительный натяг) |

**Руководство:**

- **Положительный зазор:** Нормально для большинства применений
- **Нулевой зазор:** Высокая точность, тщательное управление температурой
- **Отрицательный зазор (предварительный натяг):** Точность, жесткость, устранение люфта

### 5.3 Стратегия выбора

**Если расчет рабочего зазора показывает:**

**Cr_operating слишком малый (< 5 мкм) или отрицательный:**
- Выбрать больший начальный зазор (C3, C4)
- Уменьшить посадки с натягом
- Улучшить охлаждение (уменьшить ΔT)

**Cr_operating слишком большой (> 30 мкм для прецизионных применений):**
- Выбрать меньший начальный зазор (C2)
- Увеличить посадки с натягом (осторожно)
- Принять для не прецизионных применений

### 5.4 Комплексный пример

**Применение:** Подшипник электродвигателя

**Технические характеристики:**
- Подшипник: 6210 (d = 50 мм, D = 90 мм)
- Скорость: 3000 об/мин
- Нагрузка: Умеренная
- Посадка на валу: k6
- Посадка в корпусе: H7
- Ожидаемая разница температур: ΔT = 12°C

**Шаг 1: Начальный зазор**

Из каталога, подшипник 6210, нормальный зазор (CN):
- Cr_initial = 12 мкм (среднее значение для d = 50 мм)

**Шаг 2: Влияние посадок**

Посадка на валу k6 для d = 50 мм:
- Эффективный натяг ≈ 12 мкм

```
dm = (50 + 90) / 2 = 70 мм

Δs_inner = 50 · 12 / 70 ≈ 8,6 мкм
Δs_outer ≈ 2 мкм (H7, минимальное)

ΔCr_fit = 8,6 + 2 = 10,6 мкм
```

**Шаг 3: Посадочный зазор**

```
Cr_mounted = 12 - 10,6 = 1,4 мкм
```

**Шаг 4: Температурный эффект**

```
ΔCr_thermal = 11,5 × 10⁻⁶ × 70 × 12
ΔCr_thermal ≈ 9,7 мкм
```

**Шаг 5: Рабочий зазор**

```
Cr_operating = 1,4 - 9,7 = -8,3 мкм
```

**Анализ:**

Рабочий зазор **отрицательный** (предварительный натяг ≈ 8 мкм).

**Последствия:**
- Увеличенное трение
- Более высокая рабочая температура
- Возможный перегрев при 3000 об/мин

**Решение:**

Использовать **Группу 7 (C3)** зазор:
- Cr_initial ≈ 20 мкм (группа C3, среднее значение)

**Пересчет:**

```
Cr_mounted = 20 - 10,6 = 9,4 мкм
Cr_operating = 9,4 - 9,7 = -0,3 мкм
```

Все еще слегка отрицательный, но приемлемый для обычного электродвигателя.

**Альтернатива:**

Использовать **Группу 8 (C4)** для более высокой скорости или температуры:
- Cr_initial ≈ 30 мкм

```
Cr_mounted = 30 - 10,6 = 19,4 мкм
Cr_operating = 19,4 - 9,7 = 9,7 мкм
```

Положительный зазор → подходит для более высокой скорости.

## 6. Основы предварительного натяга

### 6.1 Определение предварительного натяга

**Предварительный натяг (Preload / Предварительный натяг):**

Намеренно приложенная нагрузка, которая устраняет внутренний зазор, создавая состояние натяга, при котором тела качения всегда находятся под нагрузкой.

**Достигается:**
- Осевым усилием на кольца подшипника
- Температурным расширением (контролируемая посадка)
- Давлением пружины
- Размерным несоответствием (спаренные подшипники)

**Эффект:**
- Внутренний зазор → **Нулевой или отрицательный** (натяг)
- Все тела качения несут нагрузку одновременно
- Нет свободного люфта в подшипнике

### 6.2 Назначение предварительного натяга

**Преимущества:**

1. **Увеличенная жесткость:** Устраняет зазор → жесткая система
2. **Улучшенная точность:** Нет люфта → лучшая прецизия
3. **Уменьшенная вибрация:** Все тела качения задействованы → более плавная работа
4. **Контролируемое распределение нагрузки:** Оптимизированные условия контакта
5. **Предотвращение проскальзывания:** Обеспечивает правильное качение на высокой скорости

**Применения, требующие предварительного натяга:**

- Шпиндели станков (точность, жесткость)
- Высокоточные приборы
- Высокоскоростные применения (предотвращает проскальзывание)
- Узлы радиально-упорных подшипников
- Комплекты конических роликоподшипников
- Применения с моментными нагрузками

### 6.3 Недостатки предварительного натяга

**Недостатки:**

1. **Увеличенное трение:** Больше тепловыделения
2. **Уменьшенная долговечность:** Более высокое контактное напряжение
3. **Температурная чувствительность:** Необходимо управлять повышением температуры
4. **Более сложный монтаж:** Требуется точность
5. **Более высокая стоимость:** Специальные подшипники, прецизионная сборка

**Когда НЕ использовать предварительный натяг:**

- Тяжелые радиальные нагрузки (нормальный зазор лучше)
- Высокотемпературные применения (проблемы температурного расширения)
- Машины с низкой точностью
- Экономичные применения

## 7. Методы предварительного натяга

### 7.1 Позиционный предварительный натяг (жесткий предварительный натяг)

**Принцип:**

Осевое положение колец подшипника фиксировано. Предварительный натяг определяется размерным натягом или длиной распорного кольца.

**Реализация:**

1. **Шлифовка распорных колец:** Распорные кольца внутреннего или наружного кольца шлифуются до точной длины
2. **Регулировка прокладками:** Добавление/удаление прокладок для установки предварительного натяга
3. **Регулировка стопорной гайкой:** Затяжка до определенного момента или осевого смещения

**Характеристики:**

- Предварительный натяг **постоянный** при сборке
- Изменяется с температурой (температурное расширение)
- Может значительно увеличиться при повышении температуры
- Подходит для стабильных температурных условий

**Преимущества:**
- Высокая жесткость
- Точный контроль (если выполнен правильно)

**Недостатки:**
- Чувствителен к изменениям температуры
- Риск перегрузки, если не учтено температурное расширение
- Требует прецизионной сборки

### 7.2 Пружинный предварительный натяг (эластичный предварительный натяг)

**Принцип:**

Предварительный натяг прикладывается пружиной (тарельчатые пружины, винтовые пружины, волнистые шайбы).

**Характеристики:**

- Предварительный натяг **приблизительно постоянный** независимо от температурного расширения
- Пружина прогибается для компенсации изменений длины
- Более низкая жесткость, чем позиционный предварительный натяг

**Преимущества:**
- Устойчив к изменениям температуры
- Более простая сборка (менее критичные размеры)
- Защищает от перегрузки

**Недостатки:**
- Более низкая жесткость (податливость пружины)
- Более сложная конструкция (требуется пружина, фиксатор)
- Возможна усталость пружины

**Применения:**
- Среды с переменной температурой
- Менее критичная точность (по сравнению с позиционным предварительным натягом)
- Автомобильная промышленность, бытовые приборы

### 7.3 Величина предварительного натяга

**Легкий предварительный натяг:**
- Осевая нагрузка: 0,5 - 2% от C₀
- Применения: Общее машиностроение, умеренная точность
- Увеличение трения: Минимальное

**Средний предварительный натяг:**
- Осевая нагрузка: 2 - 5% от C₀
- Применения: Станки, прецизионное оборудование
- Увеличение трения: Умеренное

**Тяжелый предварительный натяг:**
- Осевая нагрузка: 5 - 10% от C₀
- Применения: Шпиндели с высокой жесткостью, аэрокосмические применения
- Увеличение трения: Значительное

**Спецификации производителей:**

Каталоги подшипников часто указывают предварительный натяг в классах:
- **Легкий (L):** Низкий предварительный натяг
- **Средний (M):** Стандартный предварительный натяг
- **Тяжелый (H):** Высокий предварительный натяг

## 8. Предварительный натяг для радиально-упорных подшипников

### 8.1 Схемы установки подшипников

**Дуплексные комплекты подшипников:**

Предварительно подобранные пары или триплеты, отшлифованные для определенного предварительного натяга.

**Спина к спине (DB, O-схема):**

```
O ← →
```

- Высокая моментная жесткость
- Центры давления широко разнесены
- Наиболее распространенная для высокой точности

**Лицом к лицу (DF, X-схема):**

```
X → ←
```

- Более низкая моментная жесткость, чем DB
- Центры давления близко друг к другу
- Менее распространенная

**Тандем (DT, II-схема):**

```
II ↑ ↑
```

- Грузоподъемность удвоена (в одном направлении)
- Нет улучшения моментной жесткости
- Используется для высоких осевых нагрузок

### 8.2 Спецификация предварительного натяга для радиально-упорных подшипников

**Универсальные подобранные комплекты подшипников (суффикс):**

- **DB:** Спина к спине, универсальная
- **DF:** Лицом к лицу, универсальная
- **DT:** Тандем, универсальная

**Классы предварительного натяга (система SKF, пример):**

- **Суффикс A:** Легкий предварительный натяг
- **Суффикс B:** Средний предварительный натяг
- **Суффикс C:** Тяжелый предварительный натяг

**Пример обозначения:**

- **7208 BECBP:** Радиально-упорный, спина к спине (B), средний предварительный натяг (C)

### 8.3 Регулировка предварительного натяга шлифовкой распорного кольца

**Процедура:**

1. Установить подшипники спина к спине с начальными распорными кольцами
2. Измерить осевой зазор или люфт
3. Рассчитать требуемое уменьшение распорного кольца
4. Отшлифовать распорные кольца до точной длины
5. Пересобрать с целевым предварительным натягом

**Формула:**

```
Δs = (Clearance + Desired_preload) / 2
```

Где Δs = величина, которую нужно удалить с распорных колец (с каждой стороны)

**Пример:**

- Начальный осевой зазор: 20 мкм
- Желаемый предварительный натяг (эквивалентное осевое смещение): 10 мкм

```
Δs = (20 + 10) / 2 = 15 мкм на распорное кольцо
```

Удалить 15 мкм с каждого распорного кольца (распорное кольцо внутреннего или наружного кольца).

## 9. Предварительный натяг для конических роликоподшипников

### 9.1 Схема установки и регулировка

**Конические роликоподшипники всегда используются парами:**

- **Прямой монтаж (лицом к лицу):** Распространенный
- **Непрямой монтаж (спина к спине):** Менее распространенный

**Методы регулировки:**

1. **Стопорная гайка и шайба:** Затяжка до определенного момента или осевого люфта
2. **Регулировка прокладками:** Добавление/удаление прокладок
3. **Резьбовая регулировка:** Прецизионная резьба и стопорная гайка

### 9.2 Осевой люфт против предварительного натяга

**Осевой люфт (End play):** Небольшой положительный осевой зазор (старая практика)

**Современная практика:** Предпочтителен легкий предварительный натяг

**Установка:**

1. Затянуть стопорную гайку до нулевого осевого люфта (повернуть подшипник вручную, нет люфта)
2. Слегка отпустить для осевого люфта, ИЛИ
3. Затянуть дальше для предварительного натяга (определенный момент или угол)

**Типичный автомобильный колесный подшипник:**

- Затянуть до 50 Нм с вращением
- Отпустить на 1/4 оборота
- Повторно затянуть до 5-10 Нм
- Установить фиксатор (шплинт, стопорная шайба)

**Прецизионные применения:**

- Измерить осевой люфт индикатором
- Отрегулировать до 5-10 мкм осевого люфта, или
- Установить предварительный натяг, эквивалентный 1-2% C₀

### 9.3 Проверка предварительного натяга

**Измерить момент:**

Момент вращения подшипника увеличивается с предварительным натягом.

**Индикатор:**

Измерение осевого смещения:
- Положительное смещение = осевой люфт
- Нет смещения = нулевой зазор
- Сопротивление смещению = предварительный натяг

**Мониторинг температуры:**

После работы:
- Нормальная температура → правильный предварительный натяг
- Перегрев → чрезмерный предварительный натяг

## 10. Когда использовать зазор против предварительного натяга

### 10.1 Применения с зазором

**Использовать увеличенный зазор (C3, C4, C5) когда:**

1. **Тяжелые нагрузки**, требующие плотной посадки на валу
2. **Высокая температура** работы (> 100°C)
3. **Внутреннее кольцо горячее** наружного кольца (типично)
4. **Свободная посадка корпуса** (наружное кольцо не ограничено)
5. **Температурное расширение** от нагрева вала
6. **Ожидаемое несоосность** (сферические подшипники)
7. **Вибрация и ударные** нагрузки

**Примеры:**
- Электродвигатели (непрерывно, ΔT ≈ 10-15°C)
- Насосы (высокотемпературные жидкости)
- Редукторы (тяжелая нагрузка, плотные посадки)
- Конвейеры (надежные, не прецизионные)

### 10.2 Применения с нормальным зазором

**Использовать стандартный зазор (CN) когда:**

1. **Нормальные условия работы**
2. **Умеренная скорость и нагрузка**
3. **Стандартные посадки** (k5, k6 на валу, H7 в корпусе)
4. **Разница температур** 5-10°C
5. **Нет специальных требований** к точности

**Примеры:**
- Общее промышленное оборудование
- Вентиляторы и воздуходувки
- Сельскохозяйственное оборудование
- Строительная техника

### 10.3 Применения с предварительным натягом

**Использовать предварительный натяг когда:**

1. **Требуется высокая точность**
2. **Необходима высокая жесткость** (станки)
3. **Устранить люфт** для точности
4. **Предотвратить проскальзывание** на высокой скорости
5. **Присутствуют моментные нагрузки**
6. **Критично осевое позиционирование**

**Примеры:**
- Шпиндели станков
- Прецизионные шлифовальные машины
- Турбомашины (компрессоры, турбины)
- Робототехника (прецизионные соединения)
- Аэрокосмические приводы
- Высокоскоростные стоматологические наконечники

## 11. Практические примеры

### 11.1 Пример 1: Электродвигатель

**Применение:** Стандартный 3-фазный двигатель, 1500 об/мин

**Анализ:**
- Рабочая температура: Внутреннее кольцо +70°C, Наружное кольцо +60°C
- ΔT = 10°C
- Посадка на валу: k6 (стандартная)
- Ожидаемое уменьшение зазора: 10-15 мкм

**Выбор:**

Использовать **зазор C3** (Группа 7):
- Компенсирует температурное расширение
- Поддерживает небольшой положительный рабочий зазор
- Стандартная практика для электродвигателей

### 11.2 Пример 2: Шпиндель станка

**Применение:** Шпиндель фрезерного станка, точность ±5 мкм

**Анализ:**
- Требуется высокая жесткость
- Прецизионное позиционирование
- Требуются радиально-упорные подшипники

**Выбор:**

Использовать **комплект радиально-упорных подшипников, спина к спине (DB), средний предварительный натяг**:
- Устраняет люфт
- Высокая осевая и моментная жесткость
- Масло-воздушная смазка для охлаждения

**Пример:** 7210 BECBP (пара, спина к спине, средний предварительный натяг)

### 11.3 Пример 3: Автомобильный колесный подшипник

**Применение:** Подшипник переднего колеса, легковой автомобиль

**Анализ:**
- Умеренная скорость (до 120 км/ч → ~1000 об/мин на колесе)
- Комбинированные радиальные и осевые нагрузки (поворот)
- Некоторая моментная нагрузка
- Изменение температуры

**Выбор:**

Использовать **пару конических роликоподшипников, легкий предварительный натяг или небольшой осевой люфт**:
- Выдерживает комбинированные нагрузки
- Регулируется при сборке (стопорная гайка)
- Небольшой предварительный натяг улучшает управляемость и снижает шум

**Типично:** 30205 + 30205 (спаренные конические роликоподшипники)

### 11.4 Пример 4: Высокоскоростная шлифовальная машина

**Применение:** Шпиндель плоскошлифовального станка, 15 000 об/мин

**Анализ:**
- Очень высокая скорость
- Легкая нагрузка резания
- Требуется точность

**Выбор:**

Использовать **керамические гибридные радиально-упорные подшипники, легкий или средний предварительный натяг**:
- Гибридные подшипники для высокоскоростных возможностей
- Предварительный натяг предотвращает проскальзывание
- Масло-воздушная смазка необходима

**Пример:** 7208 CDGA/P4A DB (керамический гибрид, спина к спине, точность P4)

## 12. Измерение зазора и предварительного натяга

### 12.1 Измерение начального зазора

**Измерение радиального зазора:**

**Метод 1: Щуп**
- Вставить щуп между шариком и дорожкой качения
- Измерить в положении максимального смещения
- Ограниченная точность

**Метод 2: Индикатор часового типа**
- Установить подшипник на приспособление
- Зафиксировать наружное кольцо, сместить внутреннее кольцо радиально
- Измерить полное смещение индикатором часового типа
- Точный метод

**Стандартная процедура (ГОСТ):**

Приложить определенную радиальную нагрузку → измерить смещение под нагрузкой.

### 12.2 Измерение посадочного зазора

**После установки на валу, в корпусе:**

**Метод: Осевое смещение**
- Приложить легкую осевую нагрузку (несколько Н)
- Измерить осевое смещение
- Преобразовать в радиальный зазор (для шарикоподшипников)

**Метод: Измерение поднятия**
- Поднять внутреннее кольцо относительно наружного
- Измерить радиальное смещение

**Сложно на собранной машине → обычно рассчитывается, а не измеряется.**

### 12.3 Проверка предварительного натяга

**Метод момента:**

Измерить момент вращения подшипника:
- Более высокий момент = более высокий предварительный натяг
- Сравнить со спецификацией

**Осевое смещение:**

Приложить известную осевую нагрузку, измерить смещение:
- Жесткость указывает уровень предварительного натяга

**Мониторинг температуры:**

Запустить подшипник, контролировать температуру:
- Правильный предварительный натяг → стабильная, приемлемая температура
- Чрезмерный предварительный натяг → перегрев

## 13. Устранение неисправностей

### 13.1 Проблемы чрезмерного зазора

**Симптомы:**
- Высокая вибрация
- Шум (дребезжание)
- Плохая точность
- Ускоренный износ

**Причины:**
- Выбрана неправильная группа зазора
- Свободные посадки (недостаточный натяг)
- Износ (конец срока службы)

**Решения:**
- Выбрать уменьшенную группу зазора (C2)
- Увеличить натяг посадки (более жесткие допуски)
- Заменить изношенный подшипник

### 13.2 Недостаточный зазор / Чрезмерный предварительный натяг

**Симптомы:**
- Перегрев
- Высокое трение
- Преждевременный отказ
- Шум (непрерывный гул)

**Причины:**
- Группа зазора слишком мала
- Чрезмерный натяг посадки
- Высокое температурное расширение (ΔT > ожидаемого)
- Чрезмерно затянутый предварительный натяг

**Решения:**
- Выбрать большую группу зазора (C3, C4)
- Уменьшить натяг посадки (более свободные допуски)
- Улучшить охлаждение (уменьшить ΔT)
- Уменьшить предварительный натяг (отрегулировать распорные кольца, стопорную гайку)

### 13.3 Температурное разбегание

**Механизм:**

1. Недостаточный рабочий зазор → высокое трение
2. Тепловыделение → повышение температуры
3. Дальнейшее уменьшение зазора (температурное расширение)
4. Больше трения → больше тепла
5. **Разбегание:** Непрерывное повышение температуры → заклинивание

**Предотвращение:**
- Правильный выбор зазора (C3, C4 для высокого ΔT)
- Адекватное охлаждение
- Правильная смазка
- Мониторинг (датчики температуры)

## 15. Резюме

### 15.1 Ключевые концепции

1. **Начальный зазор** → Посадочный зазор → **Рабочий зазор**
2. **Посадки уменьшают зазор** (натяг на валу)
3. **Температура уменьшает зазор** (ΔT между кольцами)
4. **Выбрать начальный зазор** для достижения оптимального рабочего зазора
5. **Предварительный натяг устраняет зазор** для точности и жесткости

### 15.2 Руководства по выбору

**Нормальный зазор (CN):**
- Стандартные условия
- Умеренная скорость, нагрузка, температура

**Увеличенный зазор (C3, C4):**
- Высокая температура (ΔT > 10°C)
- Плотные посадки на валу
- Тяжелые нагрузки
- Электродвигатели, насосы

**Уменьшенный зазор (C2):**
- Высокая точность
- Низкое повышение температуры
- Легкие нагрузки
- Приборы

**Предварительный натяг:**
- Станки
- Высокоскоростные прецизионные применения
- Моментные нагрузки
- Устранение люфта

### 15.3 Критические формулы

**Посадочный зазор:**
```
Cr_mounted = Cr_initial - ΔCr_fit
```

**Рабочий зазор:**
```
Cr_operating = Cr_mounted - ΔCr_thermal
```

**Температурный эффект:**
```
ΔCr_thermal = α · dm · ΔT
```

## 16. Заключение

Правильный выбор и управление внутренним зазором и предварительным натягом критически важны для:
- **Долговечности подшипника:** Оптимальное распределение нагрузки
- **Производительности:** Точность, жесткость, плавная работа
- **Надежности:** Предотвращение перегрева, износа, отказа

Понимание:
- Групп зазора (C2, CN, C3, C4, C5)
- Влияния посадок и температуры
- Расчета рабочего зазора
- Когда использовать зазор против предварительного натяга
- Методов предварительного натяга и применений

Позволяет инженерам правильно выбирать и применять подшипники для любого применения, от надежного промышленного оборудования до ультрапрецизионных шпинделей.

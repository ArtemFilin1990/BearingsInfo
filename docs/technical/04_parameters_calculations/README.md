## Usage Notes

### For Designers
1. Start with **04_01_load_ratings.md** to calculate equivalent loads
2. Proceed to **04_02_life_calculations.md** to verify bearing life
3. Check **04_03_speed_limits.md** for speed capability
4. Use **04_04_clearance_preload.md** for fit and clearance selection

### For Maintenance Engineers
- Use life calculations to plan replacement intervals
- Monitor temperatures and compare to predicted values
- Understand clearance requirements for bearing replacement
- Apply troubleshooting guides for operational issues

### For Students
- Study fundamental concepts in each document
- Work through practical examples
- Understand relationships between load, speed, clearance, and life
- Learn to apply ГОСТ and ISO standards

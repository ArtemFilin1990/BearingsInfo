# 2.1. Карта стандартов ГОСТ, ISO, DIN, ANSI

## Назначение

Систематизация основных международных и национальных стандартов, применяемых в области подшипников качения. Раздел содержит навигационную карту взаимосвязей между стандартами ГОСТ, ISO, DIN, ANSI, JIS и другими системами стандартизации, используемыми производителями и потребителями подшипников по всему миру.

## Ключевые вопросы

- Какие основные системы стандартов применяются для подшипников?
- Как соотносятся стандарты ГОСТ и ISO?
- В чём различия между европейскими (DIN, ISO) и американскими (ANSI, ABMA) стандартами?
- Как найти эквивалентный стандарт в другой системе?
- Какие стандарты регламентируют размеры, точность, материалы и обозначения?

### Основные системы стандартизации

#### 2. ГОСТ (Государственный стандарт)
**Назначение:** Национальные стандарты России, Беларуси, Казахстана и других стран СНГ.

**Основные группы стандартов:**

**Размеры и конструкция:**
- **ГОСТ 8338-2014** — Подшипники шариковые и роликовые. Система условных обозначений
- **ГОСТ 3478-2012** — Подшипники шариковые радиальные однорядные. Основные размеры
- **ГОСТ 831-75** — Подшипники шариковые радиально-упорные однорядные. Основные размеры
- **ГОСТ 7242-81** — Подшипники шариковые радиальные сферические двухрядные. Основные размеры
- **ГОСТ 8328-75** — Подшипники роликовые конические однорядные. Основные размеры
- **ГОСТ 5721-75** — Подшипники роликовые цилиндрические однорядные. Основные размеры

**Точность и зазоры:**
- **ГОСТ 520-2011** — Подшипники качения. Общие технические условия (≈ ISO 492)
- **ГОСТ 24810-2013** — Подшипники качения. Внутренние зазоры (≈ ISO 5753)
- **ГОСТ 3325-85** — Подшипники качения. Поля допусков и технические требования к посадочным поверхностям

**Расчёт и долговечность:**
- **ГОСТ 18854-2013** — Подшипники качения. Статическая грузоподъёмность (≈ ISO 76)
- **ГОСТ 18855-2013** — Подшипники качения. Динамическая грузоподъёмность и расчётный ресурс (≈ ISO 281)
- **ГОСТ 16162-93** — Подшипники качения. Расчёт ресурса при осевом нагружении

#### 3. DIN (Deutsches Institut für Normung)
**Назначение:** Немецкие национальные стандарты, широко применяемые в Европе.

**Ключевые стандарты:**

| DIN | Содержание | ISO эквивалент |
|-----|------------|----------------|
| **DIN 625** | Шариковые радиальные однорядные подшипники | ISO 15 |
| **DIN 628** | Шариковые радиально-упорные подшипники | ISO 15 |
| **DIN 635** | Роликовые игольчатые подшипники | ISO 3030 |
| **DIN 720** | Подшипники качения. Термины | ISO 5593 |
| **DIN 5412** | Роликовые цилиндрические подшипники | ISO 15 |
| **DIN 711** | Конические роликоподшипники | ISO 355 |

**Примечание:** С 2000-х годов многие стандарты DIN гармонизированы с ISO и имеют двойное обозначение (например, DIN ISO 15).

#### 4. ANSI/ABMA (American National Standards Institute / American Bearing Manufacturers Association)
**Назначение:** Американские стандарты, применяемые в США, Канаде и некоторых странах Латинской Америки.

**Основные стандарты:**

| Стандарт | Область применения | ISO аналог |
|----------|-------------------|------------|
| **ANSI/ABMA 19.1** | Ненагруженные шариковые радиальные подшипники. Метрические размеры | ISO 15 |
| **ANSI/ABMA 19.2** | Ненагруженные шариковые радиальные подшипники. Дюймовые размеры | — |
| **ANSI/ABMA 20** | Радиально-упорные шариковые подшипники. Метрические размеры | ISO 15 |
| **ANSI/ABMA 12.1** | Классы точности (ABEC) | ISO 492 |
| **ANSI/ABMA 7** | Конические роликоподшипники | ISO 355 |
| **ANSI/ABMA 11** | Нагрузки и расчёт долговечности | ISO 281 |

**Особенность:** США используют собственную систему классов точности **ABEC** (Annular Bearing Engineering Committee), которая частично соответствует ISO:

| ABEC класс | ISO класс | ГОСТ класс |
|------------|-----------|------------|
| ABEC 1 | Normal (P0) | 0 |
| ABEC 3 | P6 | 6 |
| ABEC 5 | P5 | 5 |
| ABEC 7 | P4 | 4 |
| ABEC 9 | P2 | 2 |

#### 5. JIS (Japanese Industrial Standards)
**Назначение:** Японские национальные стандарты, используемые производителями Азиатско-Тихоокеанского региона.

**Основные стандарты:**

| JIS | Содержание | ISO эквивалент |
|-----|------------|----------------|
| **JIS B 1512** | Шариковые подшипники. Размеры | ISO 15 |
| **JIS B 1513** | Роликовые подшипники. Размеры | ISO 15 |
| **JIS B 1514** | Игольчатые роликовые подшипники | ISO 3030 |
| **JIS B 1516** | Корпусные подшипниковые узлы | ISO 1206 |
| **JIS B 1518** | Допуски на подшипники качения | ISO 492 |
| **JIS B 1519** | Внутренние зазоры | ISO 5753 |

**Примечание:** Стандарты JIS во многом гармонизированы с ISO, что облегчает взаимозаменяемость японских и европейских подшипников.

### Практические рекомендации

#### Как работать с разными стандартами?

**1. Определение эквивалента:**
- Для перехода от ГОСТ к ISO используйте таблицы сопоставления в ГОСТ 8338-2014
- Для перехода от ISO к ANSI смотрите каталоги производителей (SKF, Timken, NSK)
- Японские стандарты JIS наиболее близки к ISO

**2. Обозначения подшипников:**
```
ГОСТ:    42726        (старая система)
         6-42726      (новая система с префиксом)
ISO:     NU 2226      (более структурированное)
DIN:     DIN 5412 NU 2226
ANSI:    NU2226       (без пробелов)
```

**3. Точность:**
- При заказе из Европы указывайте класс ISO (P0, P6, P5, P4, P2)
- При заказе из США используйте ABEC (1, 3, 5, 7, 9)
- При заказе в России/СНГ — класс ГОСТ (0, 6, 5, 4, 2)

**4. Размеры:**
- ISO, ГОСТ, DIN, JIS — метрические размеры, взаимозаменяемы
- ANSI — метрические и дюймовые серии (серии R для дюймовых)

#### Региональные особенности

**Европа:**
- Преимущественно ISO + национальные стандарты (EN)
- DIN широко используется в машиностроении Германии
- Требования по RoHS, REACH для материалов

**США и Канада:**
- ANSI/ABMA стандарты
- Система ABEC для точности
- Дюймовые размеры в специальных применениях

**Россия и СНГ:**
- ГОСТ как основной стандарт
- Постепенный переход к гармонизации с ISO
- Обязательная сертификация по ГОСТ Р

**Азия:**
- JIS (Япония), GB (Китай), KS (Корея)
- Высокая степень соответствия ISO
- Экспортная продукция маркируется по ISO

### Гармонизация стандартов

#### Процесс сближения

С 1990-х годов наблюдается активная гармонизация национальных стандартов с международными ISO:

- **Европейский союз:** Директива EN переносит ISO стандарты в национальное законодательство
- **Россия:** ГОСТ Р постепенно приводится в соответствие с ISO (например, ГОСТ 520-2011 ≈ ISO 492)
- **США:** ANSI сохраняет специфику (ABEC, дюймовые размеры), но признаёт ISO для экспорта

#### Будущие тенденции

- Унификация обозначений и маркировки
- Цифровизация: электронные паспорта подшипников по ISO 13374
- Экологические требования: стандарты по утилизации и переработке
- Интеграция с Industry 4.0: мониторинг состояния (ISO 17359, ISO 20816)

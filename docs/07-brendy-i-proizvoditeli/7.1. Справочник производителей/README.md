# 7.1. Справочник производителей

## Назначение

Систематизированный справочник мировых производителей подшипников качения с описанием их продуктовых линеек, географии присутствия и позиционирования на рынке.

## Ключевые вопросы

- Какие основные производители подшипников существуют в мире?
- Как классифицируются производители по сегментам (премиум, индустриальные, бюджетные)?
- Какие продуктовые линейки представлены у крупных производителей?
- Где географически расположены производственные мощности?
- Какие производители СНГ и как они соотносятся с мировыми брендами?

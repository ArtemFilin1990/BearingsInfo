# 2.2. Система обозначений: базовая модель

## Назначение

Описание структуры обозначения подшипников качения по ГОСТ, базовой системы кодирования типа, размеров и конструктивных особенностей подшипника.

## Ключевые вопросы

- Из каких частей состоит обозначение подшипника?
- Как определить тип подшипника по его обозначению?
- Как определить размеры подшипника по базовому обозначению?
- Что означают цифры в базовом обозначении подшипника?
- В каком порядке указываются дополнительные характеристики?

## Содержание

### Структура обозначения подшипника

Полное обозначение подшипника качения по ГОСТ состоит из трёх основных частей:

```
[ПРЕФИКС] + БАЗОВОЕ ОБОЗНАЧЕНИЕ + [СУФФИКС]
```

**Префикс (дополнительные знаки слева):**
- Зазор (7, 8, 9)
- Класс точности (6, 5, 4, Т, 2)
- Момент сопротивления вращения
- Категория подшипника

**Базовое обозначение (основная часть):**
- Тип подшипника (1-2 цифры)
- Серия диаметров (1 цифра)
- Серия ширины (1 цифра)
- Диаметр отверстия (2 цифры)

**Суффикс (дополнительные знаки справа):**
- Конструктивные изменения
- Материал сепаратора
- Уплотнения и защитные шайбы
- Смазка и другие параметры

### Базовое обозначение подшипника

Базовое обозначение представляет собой **3-7 цифр**, определяющих основные параметры подшипника.

#### Структура базового обозначения

```
[X] [X] Y Z Z ZZ
 │   │  │ │  └─ Диаметр отверстия (2 цифры)
 │   │  │ └──── Серия ширины (1 цифра)
 │   │  └────── Серия диаметров (1 цифра)
 │   └───────── Тип подшипника (1-2 цифры)
 └───────────── Конструктивная разновидность (опционально)
```

**Пример:** **6205**
- **6** — тип подшипника (однорядный радиальный шариковый)
- **2** — серия диаметров (лёгкая серия)
- **0** — серия ширины (нормальная)
- **5** — диаметр отверстия d = 05 → 5 мм

### Определение диаметра отверстия

#### Для d = 20-495 мм

Диаметр отверстия обозначается **двумя последними цифрами** базового обозначения.

**Правило расчёта:**
```
d (мм) = код × 5
```

| Код | Диаметр, мм | Код | Диаметр, мм | Код | Диаметр, мм |
|-----|-------------|-----|-------------|-----|-------------|
| 00 | 10 | 05 | 25 | 10 | 50 |
| 01 | 12 | 06 | 30 | 12 | 60 |
| 02 | 15 | 07 | 35 | 14 | 70 |
| 03 | 17 | 08 | 40 | 16 | 80 |
| 04 | 20 | 09 | 45 | 18 | 90 |

**Примеры:**
- **6305** → d = 05 × 5 = 25 мм
- **6308** → d = 08 × 5 = 40 мм
- **6312** → d = 12 × 5 = 60 мм

#### Для d = 10-17 мм

**Исключение:** Для отверстий менее 20 мм используется прямое указание диаметра.

| Обозначение | Диаметр, мм |
|-------------|-------------|
| 00 | 10 |
| 01 | 12 |
| 02 | 15 |
| 03 | 17 |

#### Для d < 10 мм

Диаметр указывается **явно** через дробь или отдельным числом.

**Примеры:**
- **618/8** → d = 8 мм
- **619/9** → d = 9 мм
- **607** → d = 7 мм (для миниатюрных подшипников)

#### Для d > 500 мм

Диаметр указывается явно **полным числом** через дробь.

**Пример:**
- **6/530** → d = 530 мм

### Серии диаметров и ширин

#### Серия диаметров (третья цифра справа)

Определяет наружный диаметр подшипника при одинаковом диаметре отверстия.

| Серия | Обозначение | Относительный размер D |
|-------|-------------|------------------------|
| **Особо лёгкая** | 1, 8 | Минимальный D |
| **Лёгкая** | 2, 9 | Малый D |
| **Средняя** | 3, 0 | Средний D (стандарт) |
| **Тяжёлая** | 4 | Увеличенный D |
| **Особо тяжёлая** | 5 | Максимальный D |

**Пример при d = 25 мм:**
- **6205** (серия 2) → D = 52 мм
- **6305** (серия 3) → D = 62 мм
- **6405** (серия 4) → D = 80 мм

#### Серия ширины (вторая цифра справа)

Определяет ширину подшипника при одинаковых диаметрах d и D.

| Серия | Ширина |
|-------|--------|
| **7, 8, 9** | Узкие |
| **0, 1** | Нормальные |
| **2, 3, 4** | Широкие |

**Пример серии 63:**
- **6305** (серия 0) → B = 15 мм (нормальная)
- **6306** (серия 0) → B = 13 мм (нормальная)

### Обозначение типа подшипника

Тип подшипника обозначается **первой или первыми двумя цифрами** основного обозначения.

#### Основные типы подшипников

| Код | Тип подшипника | Пример |
|-----|----------------|--------|
| **0** | Шариковый радиальный однорядный | 305 |
| **1** | Шариковый радиальный двухрядный сферический | 1205 |
| **2** | Роликовый с короткими цилиндрическими роликами | 2305 |
| **3** | Роликовый двухрядный сферический | 3516 |
| **4** | Роликовый игольчатый | 4074120 |
| **5** | Роликовый с витыми роликами | 5-2305 |
| **6** | Шариковый радиальный однорядный | 6205 |
| **7** | Роликовый конический | 7205 |
| **8** | Шариковый упорный | 8101 |
| **36** | Шариковый радиально-упорный однорядный | 36205 |
| **46** | Шариковый радиально-упорный двухрядный | 46305 |
| **66** | Шариковый радиально-упорный четырёхточечный | 66412 |

**Примечание:** Тип "0" обычно опускается в начале обозначения. Подшипник **305** эквивалентен **0305**.

### Примеры расшифровки базового обозначения

#### Пример 1: **6205**

**Расшифровка:**
- **6** — шариковый радиальный однорядный
- **2** — серия диаметров (лёгкая)
- **0** — серия ширины (нормальная)
- **05** — диаметр отверстия: 05 × 5 = 25 мм

**Результат:** Шариковый радиальный подшипник, лёгкая серия, d = 25 мм, D = 52 мм, B = 15 мм

#### Пример 2: **7520**

**Расшифровка:**
- **7** — роликовый конический
- **5** — серия диаметров (тяжёлая)
- **2** — серия ширины (широкая)
- **20** — диаметр отверстия: 20 × 5 = 100 мм

**Результат:** Роликовый конический подшипник, тяжёлая широкая серия, d = 100 мм

#### Пример 3: **36205**

**Расшифровка:**
- **36** — шариковый радиально-упорный однорядный
- **2** — серия диаметров (лёгкая)
- **0** — серия ширины (нормальная)
- **05** — диаметр отверстия: 05 × 5 = 25 мм

**Результат:** Шариковый радиально-упорный подшипник, d = 25 мм, угол контакта α = 12°

#### Пример 4: **3520**

**Расшифровка:**
- **3** — роликовый двухрядный сферический
- **5** — серия диаметров (тяжёлая)
- **2** — серия ширины (широкая)
- **20** — диаметр отверстия: 20 × 5 = 100 мм

**Результат:** Роликовый сферический подшипник, тяжёлая широкая серия, d = 100 мм

### Префикс: дополнительные знаки слева

Дополнительные обозначения перед основным обозначением указывают на класс точности, зазор и другие параметры.

#### Структура префикса

```
[Зазор] [Класс точности] [Момент] [Категория] - ОСНОВНОЕ_ОБОЗНАЧЕНИЕ
```

**Пример:** **7-5-6205**
- **7** — радиальный зазор 7-й группы
- **5** — класс точности 5
- **6205** — базовое обозначение

#### Обозначение класса точности

**Классы точности** (в порядке повышения точности):
```
8 → 7 → 0 (нормальный) → 6Х → 6 → 5 → 4 → Т → 2
```

**Правила:**
- Класс **0** (нормальный) **не указывается**
- Класс точности ставится **перед** основным обозначением через **дефис**

**Примеры:**
- **6205** — класс точности 0 (нормальный)
- **5-6205** — класс точности 5
- **4-6205** — класс точности 4

#### Обозначение радиального зазора

**Группы зазоров** (в порядке увеличения):
```
6 → нормальная → 7 → 8 → 9
```

**Правила:**
- Нормальная группа **не указывается**
- Ставится **впереди** класса точности

**Примеры:**
- **6205** — нормальный зазор
- **7-6205** — увеличенный зазор (группа 7)
- **7-5-6205** — зазор группы 7, точность класса 5

#### Момент сопротивления вращению

Обозначается буквой **М** или **Т** с последующей цифрой.

**Примеры:**
- **М-6205** — ограниченный момент трения
- **Т1-6205** — специальные требования по моменту

#### Категория подшипника

Обозначается буквой **А**, **В**, **С** для специальных категорий.

**Пример:**
- **А-6205** — специальная категория А

### Суффикс: дополнительные знаки справа

Суффикс указывается **после** основного обозначения и определяет конструктивные изменения.

#### Основные обозначения суффикса

| Обозначение | Описание | Пример |
|-------------|----------|--------|
| **Н** | С одной защитной шайбой | 6205-Н |
| **2Н** | С двумя защитными шайбами | 6205-2Н |
| **Z** | С одним защитным кольцом | 6205-Z |
| **ZZ (2Z)** | С двумя защитными кольцами | 6205-ZZ |
| **RS** | С одним резиновым уплотнением | 6205-RS |
| **2RS** | С двумя резиновыми уплотнениями | 6205-2RS |
| **Е** | Сепаратор из текстолита | 6205-Е |
| **Е5** | Сепаратор из полиамида | 6205-Е5 |
| **Б** | Сепаратор из бронзы | 6205-Б |
| **Л** | Сепаратор из латуни | 6205-Л |
| **К** | Коническое отверстие (конусность 1:12) | 6205-К |
| **Р** | Канавка и отверстия для смазки | 6205-Р |
| **У** | Усиленное исполнение | 6205-У |

**Примечание:** Несколько суффиксов могут комбинироваться.

**Пример:** **6205-2RS-Е5** → подшипник с двумя резиновыми уплотнениями и полиамидным сепаратором.

### Примеры полного обозначения

#### Пример 1: **7-5-6205-2RS-Е**

**Расшифровка:**
- **7** — радиальный зазор группы 7 (увеличенный)
- **5** — класс точности 5 (высокая точность)
- **6** — шариковый радиальный однорядный
- **2** — серия диаметров (лёгкая)
- **0** — серия ширины (нормальная)
- **05** — диаметр отверстия 25 мм
- **2RS** — два резиновых уплотнения (контактные)
- **Е** — сепаратор из текстолита

**Описание:** Шариковый радиальный подшипник d = 25 мм, класс точности 5, увеличенный зазор, с двумя резиновыми уплотнениями и текстолитовым сепаратором.

#### Пример 2: **6-36208-К**

**Расшифровка:**
- **6** — радиальный зазор группы 6 (уменьшенный)
- **36** — шариковый радиально-упорный однорядный
- **2** — серия диаметров (лёгкая)
- **0** — серия ширины (нормальная)
- **08** — диаметр отверстия 40 мм
- **К** — коническое отверстие (1:12)

**Описание:** Шариковый радиально-упорный подшипник d = 40 мм, уменьшенный зазор, коническое отверстие.

#### Пример 3: **4-7520-А**

**Расшифровка:**
- **4** — класс точности 4 (прецизионный)
- **7** — роликовый конический
- **5** — серия диаметров (тяжёлая)
- **2** — серия ширины (широкая)
- **20** — диаметр отверстия 100 мм
- **А** — специальная категория А

**Описание:** Роликовый конический подшипник d = 100 мм, тяжёлая широкая серия, класс точности 4, специальное исполнение.

### Особенности обозначения различных типов

#### Подшипники с защитными шайбами и уплотнениями

**Защитные шайбы:**
- **Н** — с одной стальной защитной шайбой (бесконтактное уплотнение)
- **2Н** — с двумя стальными защитными шайбами

**Защитные кольца:**
- **Z** — с одним стальным защитным кольцом
- **ZZ (2Z)** — с двумя стальными защитными кольцами

**Резиновые уплотнения:**
- **RS** — с одним резиновым контактным уплотнением
- **2RS** — с двумя резиновыми контактными уплотнениями
- **RSН** — с одним резиновым бесконтактным уплотнением

#### Подшипники с коническим отверстием

**К** — коническое отверстие с конусностью 1:12

**Применение:**
- Упрощённый монтаж/демонтаж
- Возможность регулировки зазора
- Монтаж на конический вал или с помощью втулки

**Пример:** **1213-К** → двухрядный сферический с коническим отверстием

#### Роликовые конические подшипники

**Особенность:** Состоят из **двух комплектов** (наружное кольцо с роликами + внутреннее кольцо).

**Обозначение:** **7ХХХХХ**

**Пример:** **7208**
- **7** — тип (конический роликовый)
- **2** — серия диаметров
- **08** — диаметр отверстия 40 мм

**Дополнительные обозначения:**
- **А** — модифицированный угол контакта
- **У** — повышенная точность по монтажной высоте

#### Игольчатые подшипники

**Особенность:** Обозначение содержит прямое указание размеров.

**Формат:** **4ТИП-dхDхB**

**Пример:** **4074115** → игольчатый подшипник 7×41×15 мм

### Стандартные сокращения

| Сокращение | Расшифровка |
|------------|-------------|
| **d** | Диаметр отверстия подшипника |
| **D** | Наружный диаметр подшипника |
| **B** | Ширина подшипника |
| **Т** | Монтажная высота (для конических) |
| **α** | Угол контакта (для радиально-упорных) |

### Связь с международными стандартами

**ГОСТ → ISO:**
- Базовое обозначение в ГОСТ и ISO **похоже**, но не всегда идентично
- Дополнительные обозначения (суффиксы) **существенно различаются**

**Пример:**
- ГОСТ: **6205-2RS**
- ISO: **6205-2RSR** или **6205.2RSR.C3** (с указанием зазора)

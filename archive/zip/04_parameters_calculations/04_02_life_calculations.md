# Расчёты долговечности подшипников

## Назначение

Данный документ содержит комплексную методологию расчёта номинальной долговечности подшипников, включая базовую долговечность L₁₀, модифицированные расчёты долговечности по ISO 281, коэффициенты корректировки долговечности и требования к ресурсу для различных применений. Понимание долговечности подшипников является критически важным для надёжного проектирования машин и планирования технического обслуживания.

---

## 1. Основные понятия

### 1.1 Определение долговечности подшипника

**Долговечность подшипника (Bearing Life):**

Число оборотов (или часов работы), которое подшипник может совершить до появления первых признаков усталости материала на телах качения или дорожках качения.

**Ключевые характеристики:**
- Статистическое явление (не детерминированное)
- Основано на подповерхностном усталостном разрушении
- Исключает отказы от: износа, коррозии, электрического повреждения, неправильного монтажа
- Предполагается: достаточная смазка, правильная установка, чистая среда

### 1.2 Механизм усталостного разрушения

**Контактная усталость качения:**

1. **Герцовское контактное напряжение** → подповерхностное касательное напряжение
2. **Циклическая нагрузка** → инициация микротрещин (10-50 мкм под поверхностью)
3. **Распространение трещин** → выкрашивание (отслоение материала)
4. **Прогрессирующее повреждение** → вибрация, шум, отказ

**Распределение Вейбулла:**

Долговечность подшипника следует вероятностному распределению Вейбулла с параметром формы β ≈ 1,5 (для шарикоподшипников) или β ≈ 1,1-1,3 (для роликоподшипников).

### 1.3 Понятие номинальной долговечности

**Базовая номинальная долговечность L₁₀ (Basic Rating Life):**

Долговечность, которую **90% группы внешне идентичных подшипников** достигнут или превысят до появления первых признаков усталости.

**Интерпретация:**
- L₁₀ = 90% вероятность выживания
- 10% вероятность отказа
- Также называется: **B₁₀ life** (B = bearing, 10% частота отказов)

**Стандартные условия:**
- Материал: сквозь закалённая подшипниковая сталь (≥ 58 HRC)
- Смазка: достаточная, чистая
- Температура: ≤ 120°C
- Правильный монтаж и соосность
- Отсутствие загрязнений

## 2. Базовый расчёт долговечности (L₁₀)

### 2.1 Формула для шарикоподшипников

**Базовая номинальная долговечность (обороты):**

```
L₁₀ = (C / P)³  [млн оборотов]
```

Где:
- **L₁₀** = базовая номинальная долговечность [10⁶ оборотов]
- **C** = базовая динамическая грузоподъёмность [кН]
- **P** = эквивалентная динамическая нагрузка [кН]
- **Показатель степени = 3** (для шарикоподшипников)

**Базовая номинальная долговечность (часы):**

```
L₁₀h = (10⁶ / (60 · n)) · L₁₀
```

Где:
- **L₁₀h** = базовая номинальная долговечность [часы работы]
- **n** = частота вращения [об/мин]
- **60** = перевод минут в часы

**Упрощённая формула:**

```
L₁₀h = (10⁶ / (60 · n)) · (C / P)³

L₁₀h = 16667 / n · (C / P)³   [часов]
```

### 2.2 Формула для роликоподшипников

**Базовая номинальная долговечность (обороты):**

```
L₁₀ = (C / P)^(10/3)  [млн оборотов]
```

**Показатель степени = 10/3 ≈ 3,33** (для роликоподшипников)

**Базовая номинальная долговечность (часы):**

```
L₁₀h = (10⁶ / (60 · n)) · (C / P)^(10/3)

L₁₀h = 16667 / n · (C / P)^3,33   [часов]
```

**Причина различия показателя степени:**

Линейный контакт (ролики) в сравнении с точечным контактом (шарики) создаёт различное распределение напряжений и усталостное поведение.

### 2.3 Справочная таблица

| Тип подшипника | Показатель долговечности p |
|----------------|---------------------------|
| **Шарикоподшипники** (все типы) | 3 |
| **Роликоподшипники** (цилиндрические, конические, сферические) | 10/3 ≈ 3,33 |
| **Игольчатые роликоподшипники** | 10/3 ≈ 3,33 |

## 3. Модифицированная номинальная долговечность (ISO 281:2007)

### 3.1 Общая формула

**ISO 281:2007** ввёл коэффициенты модификации долговечности для учёта реальных условий эксплуатации:

```
L₁₀m = a₁ · aISO · L₁₀
```

Где:
- **L₁₀m** = модифицированная номинальная долговечность [10⁶ оборотов или часов]
- **a₁** = коэффициент корректировки надёжности
- **aISO** = коэффициент модификации долговечности (смазка, загрязнение, предел усталости)
- **L₁₀** = базовая номинальная долговечность

### 3.2 Коэффициент корректировки надёжности (a₁)

**Назначение:** Корректировка долговечности для различных уровней надёжности (вероятностей выживания).

**Формула:**

```
a₁ = (Lp / L₁₀)^(1/β)
```

Для типичной подшипниковой стали: β ≈ 1,5

**Стандартные значения (ISO 281, ГОСТ 18855):**

| Надёжность | Обозначение | a₁ | Интерпретация |
|------------|-------------|-----|---------------|
| **90%** | L₁₀, B₁₀ | 1,00 | Стандартная (10% отказов) |
| **95%** | L₅, B₅ | 0,64 | Высокая надёжность (5% отказов) |
| **96%** | L₄, B₄ | 0,55 | — |
| **97%** | L₃, B₃ | 0,47 | — |
| **98%** | L₂, B₂ | 0,37 | — |
| **99%** | L₁, B₁ | 0,25 | Очень высокая надёжность (1% отказов) |

**Пример:**

Для надёжности 95% (L₅):
```
L₅ = 0,64 · L₁₀
```

Для надёжности 99% (L₁):
```
L₁ = 0,25 · L₁₀
```

**Применение:**

- Критически важные применения → использовать L₅ или L₁
- Стандартное оборудование → использовать L₁₀
- Некритичное, заменяемое → L₁₀ приемлемо

### 3.3 Коэффициент модификации долговечности ISO (aISO)

**Назначение:** Учёт качества смазки, загрязнения и предела усталости материала.

**Формула (ISO 281:2007):**

```
aISO = f(κ, Pu/P, загрязнение)
```

Где:
- **κ** (каппа) = параметр условий смазки (отношение вязкостей)
- **Pu/P** = отношение предельной нагрузки усталости
- **загрязнение** = коэффициент чистоты

**Упрощённый подход:**

```
aISO ≈ 1,0 до 50+ в зависимости от условий
```

- **Плохие условия:** aISO ≈ 0,1 - 0,3 (недостаточная смазка, загрязнение)
- **Нормальные условия:** aISO ≈ 1,0 (достаточная смазка)
- **Хорошие условия:** aISO ≈ 3 - 10 (отличная смазка, чистота, лёгкая нагрузка)
- **Отличные условия:** aISO ≈ 10 - 50+ (очень лёгкая нагрузка, оптимальная смазка)

### 3.4 Параметр условий смазки (κ)

**Определение:**

```
κ = ν / ν₁
```

Где:
- **ν** = фактическая кинематическая вязкость при рабочей температуре [мм²/с]
- **ν₁** = эталонная кинематическая вязкость (минимально необходимая) [мм²/с]

**Эталонная вязкость ν₁:**

Зависит от скорости и среднего диаметра подшипника:

```
dm = (d + D) / 2   [мм]
n·dm = параметр скорости [мм·об/мин]
```

**Таблица: Эталонная вязкость ν₁ (ISO 281, SKF):**

| n·dm | ν₁ [мм²/с] |
|------|-----------|
| 1 000 | 140 |
| 2 000 | 100 |
| 5 000 | 50 |
| 10 000 | 25 |
| 20 000 | 13 |
| 50 000 | 7 |
| 100 000 | 4 |
| 200 000 | 3 |

*Для промежуточных значений использовать интерполяцию*

**Интерпретация качества смазки:**

| κ | Качество смазки | Влияние на aISO |
|---|-----------------|-----------------|
| **< 0,4** | Недостаточная | aISO < 0,1 (очень короткий ресурс) |
| **0,4 - 1** | Граничная | aISO ≈ 0,1 - 1 |
| **1 - 4** | Достаточная до хорошей | aISO ≈ 1 - 10 |
| **> 4** | Отличная | aISO ≈ 10 - 50+ |

### 3.5 Предельная нагрузка усталости (Pu)

**Определение:**

Нагрузка, ниже которой долговечность приближается к бесконечности (усталостного разрушения не ожидается).

**Приближённые значения:**

```
Pu ≈ 0,01 · C₀   (для шарикоподшипников)
Pu ≈ 0,02 · C₀   (для роликоподшипников)
```

**Влияние на aISO:**

Когда P < Pu:
- Усталостное разрушение маловероятно
- aISO значительно увеличивается
- Преобладают другие режимы отказа (износ, коррозия)

### 3.6 Коэффициент загрязнения

**Стандартные категории чистоты (Технический отчёт ISO 281):**

| Категория | Описание | Коэффициент eC |
|-----------|----------|----------------|
| **Высокая чистота** | Фильтрация частиц β > 200, герметичные подшипники | 1,0 |
| **Нормальная чистота** | Типичные промышленные условия, базовое уплотнение | 0,8 - 0,9 |
| **Лёгкое загрязнение** | Некоторое проникновение частиц | 0,5 - 0,7 |
| **Типичное загрязнение** | Обычная промышленная среда | 0,3 - 0,5 |
| **Сильное загрязнение** | Жёсткая среда, абразивные частицы | 0,1 - 0,3 |
| **Очень сильное** | Интенсивное загрязнение | < 0,1 |

**Загрязнение влияет на aISO через снижение эффективности смазки.**

## 4. Практические примеры расчёта долговечности

### 4.1 Пример 1: Базовый расчёт L₁₀ (шарикоподшипник)

**Дано:**
- Подшипник: 6308 (радиальный шарикоподшипник однорядный)
- C = 55,3 кН
- P = 6,4 кН (из расчёта нагрузки)
- n = 1500 об/мин

**Решение:**

**L₁₀ (обороты):**
```
L₁₀ = (C / P)³
L₁₀ = (55,3 / 6,4)³ = (8,64)³ = 645 млн оборотов
```

**L₁₀h (часы):**
```
L₁₀h = 16667 / n · (C / P)³
L₁₀h = 16667 / 1500 · 645
L₁₀h = 11,11 · 645 = 7167 часов
```

**Интерпретация:**
90% этих подшипников проработают не менее 7167 часов.

### 4.2 Пример 2: Долговечность роликоподшипника

**Дано:**
- Подшипник: 22215 (сферический роликоподшипник)
- C = 240 кН
- P = 37,4 кН
- n = 600 об/мин

**Решение:**

**L₁₀ (обороты):**
```
L₁₀ = (C / P)^(10/3)
L₁₀ = (240 / 37,4)^3,33 = (6,42)^3,33 = 381 млн оборотов
```

**L₁₀h (часы):**
```
L₁₀h = 16667 / 600 · 381
L₁₀h = 27,78 · 381 = 10 584 часа
```

### 4.3 Пример 3: Модифицированная долговечность с коэффициентом надёжности

**Дано:**
- Тот же подшипник, что в Примере 1: L₁₀h = 7167 часов
- Требование: надёжность 95% (L₅)

**Решение:**

```
a₁ = 0,64  (для надёжности 95%)

L₅h = a₁ · L₁₀h
L₅h = 0,64 · 7167 = 4587 часов
```

**Интерпретация:**
95% подшипников проработают не менее 4587 часов (по сравнению с 7167 часами при надёжности 90%).

### 4.4 Пример 4: Модифицированная долговечность с aISO (коэффициент смазки)

**Дано:**
- Базовая долговечность: L₁₀h = 7167 часов
- Рабочая температура: 70°C
- Вязкость масла при 70°C: ν = 32 мм²/с
- Скорость: n = 1500 об/мин
- Подшипник: 6308 (d = 40, D = 90 мм)

**Решение:**

**Шаг 1: Расчёт dm**
```
dm = (d + D) / 2 = (40 + 90) / 2 = 65 мм
```

**Шаг 2: Расчёт n·dm**
```
n·dm = 1500 · 65 = 97 500 мм·об/мин
```

**Шаг 3: Определение эталонной вязкости ν₁**

Из таблицы (интерполяция между 50 000 и 100 000):
```
ν₁ ≈ 4,5 мм²/с
```

**Шаг 4: Расчёт κ**
```
κ = ν / ν₁ = 32 / 4,5 = 7,1
```

**Шаг 5: Оценка aISO**

При κ = 7,1 (отличная смазка), чистые условия, умеренная нагрузка:
```
aISO ≈ 8 - 12  (консервативная оценка: 10)
```

**Шаг 6: Модифицированная долговечность**
```
L₁₀m = aISO · L₁₀h
L₁₀m = 10 · 7167 = 71 670 часов
```

**Интерпретация:**
При отличной смазке долговечность подшипника увеличивается в 10 раз.

**Примечание:** Каталоги производителей или программное обеспечение обеспечивают более точные расчёты aISO.

### 4.5 Пример 5: Комбинированные коэффициенты надёжности и ISO

**Дано:**
- Базовая долговечность: L₁₀h = 10 000 часов
- Требование: надёжность 99% (L₁)
- Условия эксплуатации: aISO = 5 (хорошая смазка, чистота)

**Решение:**

```
a₁ = 0,25  (для L₁, надёжность 99%)

L₁m = a₁ · aISO · L₁₀h
L₁m = 0,25 · 5 · 10 000
L₁m = 12 500 часов
```

**Интерпретация:**
- Базовая долговечность 90%: 10 000 часов
- Только с aISO (надёжность 90%): 50 000 часов
- С надёжностью 99%, хорошие условия: 12 500 часов

**Примечание:** Более высокое требование надёжности снижает долговечность, но хорошие условия компенсируют это.

### 4.6 Пример 6: Переменная нагрузка и скорость

**Дано:**
- Подшипник работает в 3 режимах:
  - Режим A: PA = 5 кН, nA = 1200 об/мин, 40% времени
  - Режим B: PB = 8 кН, nB = 1800 об/мин, 50% времени
  - Режим C: PC = 12 кН, nC = 2400 об/мин, 10% времени
- Подшипник: C = 48 кН (шарикоподшипник)

**Решение:**

**Метод: Эквивалентная нагрузка и скорость**

**Шаг 1: Расчёт эквивалентной нагрузки**

```
Peq³ = (qA · PA³ + qB · PB³ + qC · PC³)

Где q = доля времени

Peq³ = 0,40 · 5³ + 0,50 · 8³ + 0,10 · 12³
Peq³ = 0,40 · 125 + 0,50 · 512 + 0,10 · 1728
Peq³ = 50 + 256 + 172,8 = 478,8

Peq = (478,8)^(1/3) = 7,83 кН
```

**Шаг 2: Расчёт средней скорости**

```
navg = qA · nA + qB · nB + qC · nC
navg = 0,40 · 1200 + 0,50 · 1800 + 0,10 · 2400
navg = 480 + 900 + 240 = 1620 об/мин
```

**Шаг 3: Расчёт долговечности**

```
L₁₀h = 16667 / 1620 · (48 / 7,83)³
L₁₀h = 10,29 · (6,13)³
L₁₀h = 10,29 · 230,3 = 2370 часов
```

## 6. Вероятность выживания

### 6.1 Распределение Вейбулла

**Функция вероятности выживания:**

```
S(L) = exp[-(L / L₁₀)^(1/e)]
```

Где:
- **S(L)** = вероятность выживания до долговечности L
- **e** = показатель степени наклона Вейбулла
- **L₁₀** = характеристическая долговечность

Для подшипниковой стали: e ≈ 1,5

### 6.2 Таблица надёжности

**Вероятность того, что подшипник проработает до различных долговечностей:**

| Долговечность | Надёжность (%) | Обозначение |
|---------------|----------------|-------------|
| **0,05 · L₁₀** | 99,9% | — |
| **0,1 · L₁₀** | 99,5% | — |
| **0,25 · L₁₀** | 99% | L₁ |
| **0,64 · L₁₀** | 95% | L₅ |
| **1,0 · L₁₀** | **90%** | **L₁₀** |
| **3,0 · L₁₀** | 60% | — |
| **5,0 · L₁₀** | 50% | L₅₀ (средняя долговечность) |
| **10 · L₁₀** | 35% | — |
| **20 · L₁₀** | 20% | — |

**Ключевая информация:**

Средняя долговечность (L₅₀) ≈ **5 × L₁₀**

Это означает: половина подшипников проработает в 5 раз дольше, чем номинал L₁₀.

## 7. Факторы, влияющие на фактическую долговечность

### 7.1 Положительные факторы (увеличивают долговечность)

**Смазка:**
- Высоковязкое масло (κ > 4): +500% до +2000%
- Синтетические масла: +20% до +50%
- Правильная фильтрация (β > 200): +100% до +300%

**Условия эксплуатации:**
- Лёгкие нагрузки (P < 0,1·C): +1000% до неограниченного
- Более низкая скорость: улучшает смазочную плёнку
- Стабильная температура: предотвращает деградацию смазки
- Чистая среда: предотвращает абразивный износ

**Факторы конструкции:**
- Высококачественная сталь (вакуумная дегазация): +20% до +50%
- Керамические тела качения: +300% до +1000%
- Улучшенная чистота поверхности: +20% до +100%

### 7.2 Отрицательные факторы (уменьшают долговечность)

**Проблемы со смазкой:**
- Недостаточная смазка (κ < 0,4): -90% и более
- Загрязнение: -50% до -90%
- Загрязнение водой: -80% до -95%
- Неправильная вязкость: -50% до -80%

**Условия эксплуатации:**
- Высокая температура (>120°C): см. коэффициенты снижения
- Вибрация и удары: -20% до -60%
- Несоосность: -30% до -70%
- Неправильный монтаж: -50% до -90%

**Условия окружающей среды:**
- Коррозионная атмосфера: -50% до -90%
- Прохождение электрического тока: -80% до -95%
- Влажность: -30% до -70%

## 8. Стратегия расчёта долговечности

### 8.1 Стадия проектирования

**Шаг 1: Определить требуемый ресурс**
- Тип применения → Таблица 5.1 или 5.2
- Часы работы в год
- Желаемый интервал замены

**Шаг 2: Выбрать уровень надёжности**
- Стандартное оборудование → L₁₀
- Важные компоненты → L₅
- Критическая безопасность → L₁

**Шаг 3: Рассчитать требуемую C**

```
C_требуемая = P · (L_требуемая / L₁₀_целевая)^(1/p)
```

Где p = 3 (шарики) или 10/3 (ролики)

**Шаг 4: Выбрать подшипник**
- Выбрать подшипник с C ≥ C_требуемая
- Проверить размер, скорость, температурные пределы
- Проверить статическую безопасность s₀

### 8.2 Стадия верификации

**Рассчитать фактическую долговечность:**

```
L₁₀m = a₁ · aISO · (C / P)^p · (10⁶ / (60·n))
```

**Сравнить с требованием:**
- L₁₀m ≥ L_требуемая → ОК
- L₁₀m < L_требуемая → Выбрать больший подшипник или улучшить условия

### 8.3 Планирование технического обслуживания

**Использовать рассчитанную долговечность для:**
- Графиков превентивного обслуживания
- Инвентаризации запасных частей
- Ожидаемых интервалов замены
- Оценок MTBF (среднее время между отказами)

**Соотношение с MTBF:**

```
MTBF ≈ 5 × L₁₀h  (средняя долговечность для e ≈ 1,5)
```

## 9. Специальные вопросы

### 9.1 Комбинации подшипников

**Тандемная компоновка:**
```
L₁₀_общая = L₁₀_одиночного / 2^(1/p)
```

**Параллельная компоновка (распределение нагрузки):**

Каждый подшипник несёт часть нагрузки → увеличенная общая долговечность.

### 9.2 Переменные нагрузки (рабочий цикл)

**Общий метод:**

Расчёт эквивалентной нагрузки на основе спектра нагрузок:

```
P_eq^p = (1/N_общее) · Σ(Ni · Pi^p)
```

Где:
- Ni = число оборотов при нагрузке Pi
- N_общее = общее число оборотов

### 9.3 Долговечность с температурной корректировкой

**Для T > 120°C:**

```
C_скорр = C · f_темп
L₁₀_скорр = (C_скорр / P)^p
```

Температурные коэффициенты снижения из документа по номинальным нагрузкам.

## 12. Резюме

### 12.1 Ключевые формулы

**Шарикоподшипники:**
```
L₁₀h = 16 667 / n · (C / P)³
```

**Роликоподшипники:**
```
L₁₀h = 16 667 / n · (C / P)^3,33
```

**Модифицированная долговечность:**
```
L₁₀m = a₁ · aISO · L₁₀h
```

### 12.2 Критические факторы

1. **Точность нагрузки:** Использовать правильные коэффициенты X, Y
2. **Смазка:** Определяет aISO (коэффициент от 1 до 50+)
3. **Чистота:** Значительное влияние на фактическую долговечность
4. **Требование надёжности:** L₁₀, L₅ или L₁ в зависимости от критичности применения
5. **Условия эксплуатации:** Температура, скорость, соосность

### 12.3 Практические советы

- **Проектировать консервативно:** Использовать L₅ или L₁ для критически важных применений
- **Внимательно учитывать aISO:** Хорошая смазка = улучшение долговечности в 5-10 раз
- **Планировать обслуживание:** L₁₀ — это надёжность 90%, а не 100%
- **Мониторить условия:** Вибрационный анализ выявляет ранние отказы
- **Документировать допущения:** Для будущей верификации и улучшения

# 9.4. Уплотнения и РТИ

## Назначение

Справочная информация о резинотехнических изделиях (РТИ) и уплотнениях, применяемых совместно с подшипниками для защиты от загрязнений и утечек смазки.

## Ключевые вопросы

- Какие типы уплотнений используются в подшипниковых узлах?
- Чем отличаются манжеты, сальники, кольца круглого сечения (О-rings)?
- Как выбрать уплотнение для конкретных условий (температура, среда, давление)?
- Какие материалы РТИ применяются (NBR, FKM, PTFE)?

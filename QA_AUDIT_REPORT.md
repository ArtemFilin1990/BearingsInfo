## 🔧 RECOMMENDED STANDARDS

### Standard 1: Структура README файла

```markdown
# [Номер]. [Название]

## Назначение

[1-2 предложения - что описывает этот раздел]

## Ключевые вопросы

- Вопрос 1?
- Вопрос 2?
- Вопрос 3?
- Вопрос 4?

## Содержание

### Подраздел 1

[Текст с таблицами, формулами, примерами]

### Подраздел 2

[Текст]

## См. также

- [Связанный раздел 1](../путь/)
- [Связанный раздел 2](../путь/)

## Таблицы/данные

- [CSV таблица](/data/csv/файл.csv)
- [Схема](/schemas/файл.yaml)

## Источники

- ГОСТ XXXXX-YYYY "Полное название стандарта"
- ISO XXXXX:YYYY "Rolling bearings — ..."
- [Производитель] Catalogue (Year)

---

*Последнее обновление: ДД.ММ.ГГГГ*
```

### Standard 2: Формат цитирования

**ГОСТ:**
```
ГОСТ 520-2002 "Подшипники качения. Общие технические условия"
```

**ISO:**
```
ISO 281:2007 "Rolling bearings — Dynamic load ratings and rating life"
```

**DIN:**
```
DIN 625-1:2010 "Rolling bearings — Deep groove ball bearings"
```

**Каталоги:**
```
SKF General Catalogue (2023)
FAG Rolling Bearings Catalogue WL 41520 (2020)
```

### Standard 3: Именование таблиц

```markdown
| Параметр | Обозначение | Единица | Значение | Примечания |
|----------|-------------|---------|----------|------------|
| Диаметр внутренний | d | мм | 25 | Номинальный |
```

**Правила:**
- Левое выравнивание для текста: `|---|`
- Правое выравнивание для чисел: `|---:|`
- Центральное для символов: `|:---:|`
- Пробелы вокруг `|`

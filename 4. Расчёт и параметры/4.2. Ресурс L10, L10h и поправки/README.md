# 4.2. Ресурс L10, L10h и поправки

## Назначение

Методика расчета номинального ресурса подшипников (L10, L10h) и применение поправочных коэффициентов для учета реальных условий эксплуатации.

## Ключевые вопросы

- Что такое номинальный ресурс L10 и как он определяется?
- Чем отличается L10 (в млн. оборотов) от L10h (в часах работы)?
- Какие поправочные коэффициенты применяются при расчете ресурса?
- Как учитывать влияние смазки, загрязнений, температуры на ресурс подшипника?

- **Определение номинального ресурса L10**: 
  - L10 — ресурс, при котором выходит из строя 10% подшипников из партии
  - Формула расчета по ISO 281:2007 и ГОСТ 18855-2013
- **Расчет L10h (ресурс в часах)**: пересчет из оборотов с учетом частоты вращения
- **Базовая динамическая грузоподъемность C**: основной параметр для расчета ресурса
- **Поправочные коэффициенты**:
  - a1 — коэффициент надежности (для других вероятностей отказа, например L5, L50)
  - aISO — поправка на условия смазки и загрязнения (ISO 281:2007)
  - Температурные поправки
  - Коэффициенты для специальных материалов и покрытий
- **Примеры расчетов**: типовые задачи на определение ресурса

# 8.2. Высокие и низкие температуры

## Назначение

Описание конструктивных особенностей, материалов и применения подшипников качения, предназначенных для работы при экстремальных температурах. Раздел охватывает высокотемпературные подшипники (до +350°C и выше), низкотемпературные и криогенные подшипники (до −196°C и ниже), а также специальные смазочные материалы для экстремальных условий.

## Ключевые вопросы

- Какие температурные диапазоны считаются экстремальными для подшипников?
- Какие материалы используются для высокотемпературных подшипников?
- Какие смазочные материалы применяются при экстремальных температурах?
- Как обозначаются подшипники для экстремальных температур?
- В каких отраслях применяются такие подшипники?
- Какие особенности монтажа и эксплуатации подшипников при экстремальных температурах?

## Содержание

### Температурные диапазоны и классификация

#### Стандартные рабочие температуры

**Обычные подшипники (сталь ШХ15 + стандартная смазка):**
- Рабочий диапазон: **−30°C ... +120°C**
- Кратковременно (до 10 часов): **−40°C ... +150°C**

**Ограничения стандартных подшипников:**
- При t > +120°C: деградация пластичных смазок
- При t > +150°C: снижение твёрдости стали, потеря размерной стабильности
- При t < −30°C: загустевание смазки, риск хрупкого разрушения

#### Экстремальные температуры

**Высокотемпературные:**
- **Умеренно высокие:** +150°C ... +200°C
- **Высокие:** +200°C ... +300°C
- **Особо высокие:** +300°C ... +500°C
- **Сверхвысокие:** > +500°C (специальные керамические)

**Низкотемпературные:**
- **Умеренно низкие:** −40°C ... −60°C
- **Низкие:** −60°C ... −100°C
- **Криогенные:** −100°C ... −196°C (жидкий азот)
- **Сверхкриогенные:** < −196°C (жидкий гелий −269°C)

### Высокотемпературные подшипники

#### Проблемы при высоких температурах

**1. Материалы:**
- Снижение твёрдости стали (отпуск)
- Изменение размеров (температурное расширение)
- Окисление и обезуглероживание поверхности
- Коррозия

**2. Смазка:**
- Испарение масла
- Окисление и полимеризация
- Потеря смазывающей способности
- Коксование (образование нагара)

**3. Зазоры:**
- Уменьшение зазора при нагреве (риск заклинивания)
- Необходимость увеличенных начальных зазоров

#### Материалы для высокотемпературных подшипников

**1. Стали повышенной теплостойкости**

**Сталь 95Х18-Ш (ГОСТ 801-78) / AISI 440C:**
- Рабочая температура: до **+200°C** непрерывно, кратковременно до **+250°C**
- Твёрдость: HRC 58–60
- Коррозионная стойкость: высокая
- Стабильность размеров: хорошая
- Применение: пищевая, химическая промышленность, печи

**Сталь с азотированием (Nitrided steel):**
- Рабочая температура: до **+300°C**
- Твёрдость поверхности: HV 700–900
- Азотированный слой глубиной 0,2–0,5 мм
- Применение: турбокомпрессоры, печи, сушилки

**Инструментальная сталь М50 (AISI M50):**
- Состав: 0,8% C, 4% Cr, 4,5% Mo, 1% V
- Рабочая температура: до **+315°C**
- Твёрдость: HRC 60–65
- Размерная стабильность: отличная
- Применение: авиационные двигатели, турбины

**Сталь М50NiL:**
- Модификация М50 с низким содержанием углерода и добавкой никеля
- Рабочая температура: до **+350°C**
- Вязкость: выше, чем у М50
- Применение: подшипники газотурбинных двигателей

**2. Керамические материалы**

**Нитрид кремния Si₃N₄:**
- Рабочая температура: до **+800°C** (в воздушной среде)
- Коэффициент термического расширения: 3,2×10⁻⁶ /°C (в 3,5 раза меньше стали)
- Плотность: 3,2 г/см³ (в 2,5 раза меньше стали)
- Твёрдость: HV 1500–1800
- Химическая стойкость: высокая
- Применение: вакуумные печи, турбины, космическая техника

**Карбид кремния SiC:**
- Рабочая температура: до **+1000°C**
- Применение: сверхвысокотемпературные применения

**Оксид циркония ZrO₂:**
- Рабочая температура: до **+600°C**
- Применение: агрессивные среды при высоких температурах

**3. Композитные и твердосплавные материалы**

**Стеллиты (кобальтовые сплавы):**
- Рабочая температура: до **+400°C**
- Высокая износостойкость
- Применение: подшипники скольжения при высоких температурах

#### Смазочные материалы для высоких температур

**1. Синтетические масла**

**Полиальфаолефины (PAO):**
- Рабочий диапазон: −40°C ... **+150°C**
- Применение: универсальные подшипники с расширенным температурным диапазоном

**Сложные эфиры (Ester-based):**
- Рабочий диапазон: −50°C ... **+180°C**
- Биоразлагаемые
- Применение: пищевая, экологически чувствительные зоны

**Полиалкиленгликоли (PAG):**
- Рабочий диапазон: −40°C ... **+200°C**
- Применение: высокотемпературные редукторы

**Перфторполиэфиры (PFPE, например Krytox, Fomblin):**
- Рабочий диапазон: −60°C ... **+260°C**, кратковременно до **+300°C**
- Химическая инертность: абсолютная
- Негорючие, совместимы с кислородом
- Применение: космическая техника, химическая промышленность, вакуумное оборудование
- Недостатки: очень высокая стоимость

**2. Высокотемпературные пластичные смазки**

**Литиевые смазки с синтетической основой:**
- Рабочий диапазон: −30°C ... **+150°C**
- Примеры: Литол-24, Shell Alvania EP-LF2
- Применение: общее машиностроение

**Смазки на основе полимочевины (Polyurea):**
- Рабочий диапазон: −40°C ... **+180°C**
- Примеры: Mobil Polyrex EM, SKF LGHQ 3
- Долговечность: очень высокая
- Применение: электродвигатели, подшипники с длительным межсмазочным интервалом

**Смазки на основе бентонита (Bentonite clay):**
- Рабочий диапазон: −20°C ... **+200°C**, кратковременно до **+250°C**
- Примеры: Mobilux EP 111, Castrol Spheerol EPL 2
- Применение: печи, сушилки, конвейеры горячих материалов

**Смазки на основе PFPE:**
- Рабочий диапазон: −60°C ... **+260°C**
- Примеры: Krytox GPL 205, Fomblin Y VAC
- Применение: вакуумное оборудование, химическая промышленность, космос

**Смазки на основе перфторалкилполиэфиров (PFAE):**
- Рабочий диапазон: −70°C ... **+288°C**
- Радиационная стойкость
- Применение: ядерная промышленность

**3. Твёрдые смазочные покрытия**

**Дисульфид молибдена (MoS₂):**
- Рабочий диапазон: −180°C ... **+350°C** (в инертной среде)
- В воздухе: до **+400°C** с окислением
- Коэффициент трения: 0,03–0,05
- Применение: сухое трение, вакуум, высокие температуры

**Дисульфид вольфрама (WS₂):**
- Рабочий диапазон: −270°C ... **+650°C** (в воздухе)
- Устойчивость к окислению выше, чем у MoS₂
- Применение: аэрокосмическая техника

**Графит:**
- Рабочий диапазон: до **+450°C** (в воздухе), до **+600°C** (в инертной среде)
- Требует наличия влаги или газов для смазывания
- Не работает в вакууме!

**Политетрафторэтилен (PTFE, тефлон):**
- Рабочий диапазон: −200°C ... **+260°C**
- Коэффициент трения: 0,04–0,1
- Применение: пищевая промышленность, химическая стойкость

**Нитрид бора (BN):**
- Рабочий диапазон: до **+800°C** (в инертной среде)
- Применение: сверхвысокотемпературные применения

**DLC (Diamond-Like Carbon, алмазоподобный углерод):**
- Рабочий диапазон: −180°C ... **+300°C**
- Твёрдость: HV 1000–3000
- Коэффициент трения: 0,05–0,15
- Применение: прецизионные подшипники, вакуумное оборудование

#### Конструктивные особенности

**1. Увеличенный радиальный зазор**
- Компенсация теплового расширения
- Обычно группа C3, C4, C5 (по ISO)
- Расчёт зазора с учётом ΔT

**2. Упрочнённые сепараторы**
- Латунные (до +200°C)
- Из жаропрочной стали (до +300°C)
- Полиимидные (PEEK, до +260°C)
- Керамические (Si₃N₄, до +800°C)

**3. Защита от окисления**
- Покрытия: никель, хром, серебро, золото
- Атмосфера: инертный газ, вакуум

**4. Уплотнения**
- Металлические лабиринтные (до +300°C)
- Графитовые (до +500°C)
- Без уплотнений (для t > +250°C)

#### Применение высокотемпературных подшипников

**1. Промышленные печи и сушилки:**
- Конвейеры термообработки (до +300°C)
- Печи обжига керамики (до +350°C)
- Сушилки древесины, бумаги (до +200°C)

**Типовые подшипники:**
- Стандартные стальные с высокотемпературной смазкой (до +200°C)
- Специальные стальные с жаропрочной сталью и твёрдой смазкой (до +350°C)

**2. Турбокомпрессоры:**
- Турбины автомобильных двигателей (до +250°C)
- Промышленные турбокомпрессоры (до +300°C)

**Типовые подшипники:**
- Радиально-упорные шариковые, сталь М50 или керамика, смазка PFPE

**3. Стекольная промышленность:**
- Конвейеры горячего стекла (до +300°C)
- Машины формования стеклотары (до +250°C)

**Типовые подшипники:**
- Роликовые цилиндрические с охлаждением, высокотемпературная смазка

**4. Металлургия:**
- Роликовые конвейеры для горячего проката (до +300°C)
- Транспортёры слябов (до +200°C)

**Типовые подшипники:**
- Роликовые цилиндрические усиленные, водяное охлаждение, смазка Bentonite

**5. Авиационные и газотурбинные двигатели:**
- Подшипники компрессора (до +250°C)
- Подшипники турбины (до +350°C, с охлаждением)

**Типовые подшипники:**
- Прецизионные радиально-упорные, сталь М50 или М50NiL, смазка PFPE

**6. Космическая техника:**
- Механизмы ориентации солнечных панелей (−150°C ... +150°C)
- Приводы антенн спутников

**Типовые подшипники:**
- Керамические гибридные, твёрдая смазка MoS₂ или PFPE

### Низкотемпературные и криогенные подшипники

#### Проблемы при низких температурах

**1. Материалы:**
- Снижение ударной вязкости (хрупкое разрушение)
- Сжатие материалов (изменение зазоров)
- Конденсация и замерзание влаги

**2. Смазка:**
- Загустевание смазки (увеличение вязкости)
- Затвердевание пластичных смазок
- Потеря подвижности (высокий момент пуска)

**3. Зазоры:**
- Увеличение зазора при охлаждении
- Необходимость уменьшенных начальных зазоров

#### Материалы для низкотемпературных подшипников

**1. Стали с повышенной хладостойкостью**

**Нержавеющая сталь AISI 440C (95Х18-Ш):**
- Рабочая температура: до **−60°C**
- Ударная вязкость: сохраняется при низких температурах
- Коррозионная стойкость: высокая
- Применение: холодильное оборудование, криогенная техника (умеренные температуры)

**Аустенитная нержавеющая сталь AISI 316 (08Х17Н13М2):**
- Рабочая температура: до **−196°C** (жидкий азот)
- Немагнитная
- Ударная вязкость: отличная
- Применение: криогенные насосы, жидкий азот, медицинское оборудование

**Сталь 12Х18Н10Т (аналог AISI 321):**
- Рабочая температура: до **−253°C** (жидкий водород)
- Применение: космические ракетные двигатели

**2. Керамические материалы**

**Нитрид кремния Si₃N₄:**
- Рабочая температура: до **−269°C** (жидкий гелий)
- Коэффициент термического расширения: низкий (стабильность размеров)
- Хрупкость: ниже, чем у оксидной керамики
- Применение: криогенное оборудование, сверхпроводящие системы

**3. Полимеры**

**Полиимиды (PEEK, PI):**
- Рабочая температура: до **−100°C**
- Сохраняют пластичность
- Применение: сепараторы для умеренно низких температур

**PTFE (тефлон):**
- Рабочая температура: до **−200°C**
- Применение: сухое трение в криогенных условиях

#### Смазочные материалы для низких температур

**1. Низкотемпературные масла**

**Синтетические масла (PAO, Ester):**
- Рабочий диапазон: **−60°C** ... +150°C
- Температура застывания: до −70°C
- Применение: арктическое оборудование, холодильные машины

**Силиконовые масла:**
- Рабочий диапазон: **−90°C** ... +200°C
- Низкая вязкость при низких температурах
- Применение: криогенная техника (умеренные температуры)

**Перфторполиэфиры (PFPE):**
- Рабочий диапазон: **−90°C** ... +260°C
- Не затвердевают при низких температурах
- Применение: вакуумное криогенное оборудование

**2. Низкотемпературные пластичные смазки**

**Синтетические низкотемпературные смазки:**
- Рабочий диапазон: **−60°C** ... +150°C
- Примеры: Mobil Arctic SHC 224, Shell Gadus S2 A320 2
- Применение: арктическая техника, холодильные установки

**Смазки на основе PFPE:**
- Рабочий диапазон: **−90°C** ... +260°C
- Примеры: Krytox GPL 205, Fomblin Y VAC
- Применение: криогенные насосы, вакуумная техника

**3. Твёрдые смазочные покрытия**

**MoS₂:**
- Рабочий диапазон: **−180°C** ... +350°C
- Применение: вакуум + криогенные температуры

**WS₂:**
- Рабочий диапазон: **−270°C** ... +650°C
- Применение: космос, криогенные системы

**PTFE:**
- Рабочий диапазон: **−200°C** ... +260°C
- Применение: сухое трение, пищевая промышленность

**DLC:**
- Рабочий диапазон: **−180°C** ... +300°C
- Применение: вакуумное криогенное оборудование

**4. Без смазки (dry running)**

**Для глубокого криогенного охлаждения (< −100°C):**
- Обычные смазки замерзают
- Используют керамические подшипники с твёрдой смазкой или без неё
- Применение: жидкий азот, жидкий гелий

#### Конструктивные особенности

**1. Уменьшенный радиальный зазор**
- Компенсация термического сжатия
- Обычно группа C2 или CN (по ISO)
- Расчёт зазора с учётом низких температур

**2. Материалы колец и тел качения**
- Нержавеющая аустенитная сталь (для t < −60°C)
- Керамика Si₃N₄ (для t < −196°C)

**3. Сепараторы**
- Полиимидные (PEEK) для −100°C
- Полнокерамические (Si₃N₄) для < −196°C
- PTFE для −200°C

**4. Уплотнения**
- Обычно без уплотнений (смазки работают плохо)
- Лабиринтные уплотнения
- Внешние уплотнительные системы

#### Применение низкотемпературных и криогенных подшипников

**1. Холодильное оборудование:**
- Компрессоры холодильных машин (до −60°C)
- Вентиляторы морозильных камер (до −40°C)

**Типовые подшипники:**
- Стандартные с низкотемпературной смазкой

**2. Криогенная техника:**
- Насосы для жидкого азота (−196°C)
- Насосы для жидкого кислорода (−183°C)
- Насосы для сжиженного природного газа (−162°C, LNG)

**Типовые подшипники:**
- Нержавеющая сталь 316 или керамика Si₃N₄, смазка PFPE или твёрдая смазка

**3. Космическая техника:**
- Механизмы ориентации спутников (в тени: −150°C)
- Криогенные топливные насосы ракет (−253°C, жидкий водород)

**Типовые подшипники:**
- Керамические, твёрдая смазка MoS₂ или WS₂

**4. Медицинское оборудование:**
- МРТ (сверхпроводящие магниты охлаждаются жидким гелием, −269°C)
- Криохирургические инструменты

**Типовые подшипники:**
- Керамические, без смазки или PTFE

**5. Научное оборудование:**
- Криостаты
- Ускорители частиц (сверхпроводящие магниты)
- Телескопы с охлаждаемыми детекторами

**Типовые подшипники:**
- Полностью керамические или керамические гибридные

**6. Арктическая и морская техника:**
- Буровые установки в Арктике (до −60°C)
- Ледоколы
- Ветрогенераторы в северных широтах

**Типовые подшипники:**
- Нержавеющие с низкотемпературной смазкой Arctic-grade

### Расчёт зазоров для экстремальных температур

#### Формула изменения зазора

```
ΔS = α × ΔT × d / 2
```

Где:
- `ΔS` — изменение радиального зазора, мкм
- `α` — коэффициент линейного расширения материала, 1/°C
  - Сталь: 11,5×10⁻⁶ 1/°C
  - Алюминий: 23×10⁻⁶ 1/°C
  - Керамика Si₃N₄: 3,2×10⁻⁶ 1/°C
- `ΔT` — изменение температуры, °C (относительно монтажа)
- `d` — диаметр отверстия подшипника, мм

#### Пример 1: Высокая температура

**Условия:**
- Подшипник 6308 (d=40 мм)
- Температура монтажа: +20°C
- Рабочая температура: +200°C
- Начальный зазор: CN (нормальный) = 9 мкм (среднее значение)
- Внутреннее кольцо — сталь, нагревается сильнее
- ΔT = +180°C

**Расчёт уменьшения зазора:**
```
ΔS = 11,5×10⁻⁶ × 180 × 40 / 2 = 41,4 мкм (уменьшение!)
```

**Рабочий зазор:**
```
S_работ = 9 − 41,4 = −32,4 мкм (отрицательный → заклинивание!)
```

**Решение:** Использовать увеличенный зазор C4 (начальный ~28 мкм):
```
S_работ = 28 − 41,4 = −13,4 мкм (всё ещё риск!)
```

**Правильное решение:** Зазор C5 (~48 мкм) или специальный расчёт с учётом посадок и температуры наружного кольца.

#### Пример 2: Низкая температура

**Условия:**
- Подшипник 6210 (d=50 мм)
- Температура монтажа: +20°C
- Рабочая температура: −60°C
- Начальный зазор: CN = 11 мкм
- ΔT = −80°C

**Расчёт увеличения зазора:**
```
ΔS = 11,5×10⁻⁶ × (−80) × 50 / 2 = −23 мкм (увеличение зазора на 23 мкм)
```

**Рабочий зазор:**
```
S_работ = 11 + 23 = 34 мкм (увеличенный зазор → снижение точности, шум)
```

**Решение:** Использовать уменьшенный зазор C2 (начальный ~5 мкм):
```
S_работ = 5 + 23 = 28 мкм (приемлемо)
```

### Специальные исполнения и модификации

#### Подшипники с внешним охлаждением/нагревом

**Конструкция:**
- Каналы для циркуляции охлаждающей/нагревающей жидкости в корпусе
- Термоизоляция
- Датчики температуры

**Применение:**
- Прокатные станы (охлаждение водой при t > +200°C)
- Криогенные насосы (подогрев для предотвращения обледенения)

#### Подшипники с термобарьерами

**Конструкция:**
- Теплоизолирующие вставки между подшипником и источником тепла/холода
- Керамические прокладки

**Применение:**
- Турбины (изоляция подшипников от горячих газов)
- Криогенное оборудование (минимизация теплопритока)

#### Подшипники для термоциклирования

**Требования:**
- Устойчивость к многократным циклам нагрев-охлаждение
- Отсутствие остаточных деформаций
- Стабильность размеров

**Материалы:**
- Нержавеющая сталь (лучше переносит термоциклы, чем ШХ15)
- Керамика (минимальное расширение)

**Применение:**
- Космические аппараты (день-ночь: +150°C / −150°C)
- Испытательное оборудование

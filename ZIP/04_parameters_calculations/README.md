# 04 Параметры и расчёты

Назначение: Расчёты нагрузки, частоты вращения, зазора, предварительного натяга и компоновки подшипников.

## Содержание раздела
- Расчёты грузоподъёмности и долговечности
- Ограничения частоты вращения и тепловые ограничения
- Определения зазора и предварительного натяга
- Факторы компоновки и примечания по применению
- Расчётные таблицы и примеры

## Указатель

### Основные документы

1. **[04_01_load_ratings.md](04_01_load_ratings.md)** — Грузоподъёмность и расчёты нагрузок
   - Базовая статическая грузоподъёмность (C₀) и базовая динамическая грузоподъёмность (C)
   - Эквивалентная статическая нагрузка (P₀) и эквивалентная динамическая нагрузка (P)
   - Коэффициенты нагрузки (X, Y) для различных типов подшипников
   - Расчёты статического коэффициента запаса прочности
   - Практические примеры для шариковых, роликовых, конических и сферических подшипников

2. **[04_02_life_calculations.md](04_02_life_calculations.md)** — Расчёты долговечности подшипников
   - Концепция и формулы базовой номинальной долговечности L₁₀
   - Долговечность L₁₀h в часах работы
   - Расчёт модифицированной долговечности по ISO 281 (коэффициенты a₁, aISO)
   - Уровни надёжности (L₁₀, L₅, L₁)
   - Параметр условий смазывания (κ)
   - Требования к сроку службы в зависимости от применения
   - Расчёты для переменных нагрузок и частот вращения

3. **[04_03_speed_limits.md](04_03_speed_limits.md)** — Ограничения частоты вращения и тепловые аспекты
   - Частота вращения для условий теплового равновесия (nref) и тепловая частота вращения (nth)
   - Скоростной параметр (n·dm) и его применение
   - Факторы, влияющие на ограничения частоты вращения (нагрузка, смазывание, уплотнения, конструкция)
   - Повышение температуры и момент трения
   - Ограничения частоты вращения по типам подшипников
   - Решения для высокоскоростных подшипников (керамические гибриды, современные системы смазывания)

4. **[04_04_clearance_preload.md](04_04_clearance_preload.md)** — Внутренний зазор и предварительный натяг
   - Определения радиального и осевого внутреннего зазора
   - Группы зазоров (C2, CN, C3, C4, C5) по ГОСТ и ISO
   - Влияние посадок на зазор (расчёты при монтаже)
   - Влияние температуры на зазор
   - Методология расчёта рабочего зазора
   - Концепции и методы предварительного натяга (жёсткий и упругий предварительный натяг)
   - Предварительный натяг для радиально-упорных и конических роликовых подшипников
   - Когда использовать зазор или предварительный натяг

## Примечания по использованию

### Для конструкторов
1. Начните с **04_01_load_ratings.md** для расчёта эквивалентных нагрузок
2. Переходите к **04_02_life_calculations.md** для проверки долговечности подшипника
3. Проверьте **04_03_speed_limits.md** для определения скоростных возможностей
4. Используйте **04_04_clearance_preload.md** для выбора посадок и зазоров

### Для инженеров по обслуживанию
- Используйте расчёты долговечности для планирования интервалов замены
- Контролируйте температуры и сравнивайте с прогнозируемыми значениями
- Понимайте требования к зазорам при замене подшипников
- Применяйте руководства по диагностике для эксплуатационных проблем

### Для студентов
- Изучайте фундаментальные концепции в каждом документе
- Прорабатывайте практические примеры
- Понимайте взаимосвязи между нагрузкой, частотой вращения, зазором и долговечностью
- Учитесь применять стандарты ГОСТ и ISO

# 1.5. Классификация подшипников

## Назначение

Систематизация подшипников по различным конструктивным и функциональным признакам для правильного выбора и применения.

## Ключевые вопросы

- Какие существуют типы подшипников по принципу работы?
- Как классифицируются подшипники по воспринимаемым нагрузкам?
- Какие бывают подшипники по количеству рядов тел качения?
- Как различаются подшипники по способности компенсировать перекосы?

## Содержание

Подшипники классифицируются по следующим основным признакам:

### По принципу работы

- **Качения** - основной тип подшипников, где используется качение тел между кольцами
- **Скольжения** - подшипники, работающие на принципе скольжения поверхностей

### По типу тел качения

- **Шариковые** - используют шарики в качестве тел качения
- **Роликовые** - используют ролики различной формы:
  - Цилиндрические
  - Конические
  - Сферические (бочкообразные)
  - Игольчатые

### По воспринимаемым нагрузкам

- **Радиальные** - воспринимают преимущественно радиальные нагрузки
- **Радиально-упорные** - воспринимают комбинированные радиальные и осевые нагрузки
- **Упорно-радиальные** - воспринимают преимущественно осевые нагрузки с небольшой радиальной составляющей
- **Упорные** - воспринимают только осевые нагрузки
- **Комбинированные** - специальные конструкции для сложных нагрузок
- **Линейного перемещения** - для линейных направляющих

### По количеству рядов тел качения

- **Однорядные** - один ряд тел качения
- **Двухрядные** - два ряда тел качения
- **Многорядные** - три и более рядов тел качения

### По способности компенсировать перекосы валов

- **Самоустанавливающиеся** - могут компенсировать угловые перекосы валов
- **Несамоустанавливающиеся** - требуют точного соосного монтажа

### По степени защиты

- С одной защитной шайбой
- С двумя защитными шайбами
- С односторонним уплотнением
- С двухсторонним уплотнением
- Открытые (без защиты)

### По конструкции сепаратора

- **Штампованный** - изготовлен штамповкой из листовой стали
- **Массивный** - механически обработанный из цельного материала (латунь, сталь, полимер)
- Другие специальные конструкции

### По способам осевого крепления и фиксации

- Стопорное кольцо
- Фланец
- Упорный борт
- Закрепительная втулка
- Стяжная втулка
- Другие варианты крепления

### По комплектующим деталям

- Без внутреннего кольца
- Без наружного кольца
- Без колец
- Без сепаратора (полнокомплектные)

### По назначению

- **Общего назначения** - стандартные подшипники для типовых применений
- **Специальные** - подшипники для особых условий эксплуатации

> **Примечание:** Наряду со стандартными конструкциями изготавливается большое количество подшипников специальных конструкций, использование которых в каждом отдельном случае требует согласования с изготовителем.

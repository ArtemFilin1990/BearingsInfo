# 🎓 Вводный курс для новичков

![Уровень](<https://img.shields.io/badge/уровень-начальный-green.svg>)
![Продолжительность](<https://img.shields.io/badge/продолжительность-4--6_часов-blue.svg>)

> Систематический курс для тех, кто только начинает работать с подшипниками

## 📋 О курсе

Этот курс разработан специально для **новых сотрудников** и **студентов**, которым необходимо быстро освоить основы работы с подшипниками качения.

### 🎯 Цели курса

После прохождения курса вы сможете:
- ✅ Понимать устройство и принцип работы подшипников
- ✅ Различать основные типы подшипников
- ✅ Читать и расшифровывать обозначения по ГОСТ и ISO
- ✅ Находить нужную информацию в каталогах
- ✅ Понимать основные технические характеристики

### 👥 Целевая аудитория

- 🆕 Новые сотрудники отдела продаж
- 📚 Студенты технических специальностей
- 🔧 Начинающие инженеры
- 📦 Специалисты по закупкам

# 6.7. Протокол диагностики: шаблоны

## Назначение

Шаблоны и чек-листы для систематической диагностики отказавших подшипников и документирования результатов.

## Ключевые вопросы

- Как правильно провести диагностику отказавшего подшипника?
- Какие данные необходимо собрать и задокументировать?
- Как определить первопричину отказа по совокупности признаков?
- Какие рекомендации дать для предотвращения повторных отказов?

[[TBD]]

Раздел находится в разработке. Планируется включить:

- **Шаблон протокола диагностики отказа подшипника**:
  - Общие данные: обозначение подшипника, производитель, дата установки, наработка
  - Условия эксплуатации: нагрузка, скорость, температура, среда
  - Описание узла: тип оборудования, схема установки, посадки
  - Визуальный осмотр: фото повреждений, описание дефектов
  - Тип дефекта: питтинг, задиры, трещины, коррозия, электроэрозия и т.д.
  - Диагноз: первопричина отказа (недостаток смазки, перегрузка, загрязнения и т.д.)
  - Рекомендации: меры по предотвращению повторного отказа
- **Чек-лист диагностики**:
  - Проверка смазки (наличие, состояние, тип)
  - Проверка посадок и монтажа
  - Проверка герметичности уплотнений
  - Проверка на загрязнения
  - Проверка на электроэрозию
  - Проверка режимов работы
- **Примеры заполненных протоколов** для типичных отказов
- **Матрица «Дефект → Причина → Решение»**

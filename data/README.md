**Версия:** 1.0  
**Дата:** 2026-01-20

*Объединяет данные из репозиториев Baza и bearing-api + новая справочная система*

Создать единый источник достоверной информации для:

## ⭐ Ключевые улучшения (v1.0)

### 1. Мастер-каталог
**master_catalog.csv** — единая точка входа для всех подшипников:
- Все стандарты: ГОСТ ↔ ISO ↔ Бренды
- Полные размеры: d, D, B, r
- Вес и категория
- Статус (Active/Obsolete)

### 2. Система аналогов
Четыре таблицы для полного покрытия:
- **gost_to_iso.csv** — ГОСТ → ISO
- **iso_to_gost.csv** — ISO → ГОСТ (обратная)
- **import_analogs.csv** — импортные аналоги (SKF, FAG, NSK, NTN, KOYO)
- **additional_designations.csv** — суффиксы и модификаторы

**Важно**: Условные аналоги помечены, ограничения указаны!

### 3. База производителей
Расширенный справочник по регионам:
- СНГ: ГПЗ, СПЗ, ВПЗ, МПЗ и др.
- Европа: SKF, FAG, INA, NSK Europe, NKE, Timken
- Азия: NSK, NTN, KOYO, Nachi, NMB
- Китай: ZWZ, HRB, LYC, C&U

С указанием:
- Уровня качества (Премиум/Индустриальный/Бюджетный)
- Специализации
- Контактов

### 4. SQL схема
**bearings_db_schema.sql** — готовая к использованию схема PostgreSQL:
- 8 основных таблиц
- Индексы для быстрого поиска
- Представления (views) для типовых запросов
- Функции для валидации и поиска аналогов
- Комментарии на русском языке

## Описание разделов

### 📥 inbox/
**Назначение**: Входящие файлы для автоматического импорта

Источник: bearing-api

Содержит:
- Загруженные архивы с данными
- Файлы, ожидающие обработки
- Временные файлы импорта

Обработка:
```bash
python api/scripts/unpack_and_classify.py
```

### 📊 csv/
**Назначение**: Структурированные данные в CSV формате

Источник: Baza (43,000+ записей)

#### csv/gost/
Данные по стандартам ГОСТ:
- `bearings.csv` - подшипники по ГОСТ
- `dimensions.csv` - размеры
- `series.csv` - серии подшипников
- `tolerances.csv` - допуски и посадки

#### csv/iso/
Данные по стандартам ISO:
- `bearings.csv` - подшипники по ISO
- `dimensions.csv` - размеры
- `prefixes.csv` - префиксы обозначений
- `suffixes.csv` - суффиксы обозначений

#### csv/analogs/
Таблицы аналогов и взаимозаменяемости:
- `gost_iso.csv` - соответствие ГОСТ ↔ ISO
- `units.csv` - подшипниковые узлы
- `housings.csv` - корпуса

#### csv/brands/
Данные о производителях:
- `brands.csv` - список производителей и брендов

#### csv/reports/
Сводные отчеты и агрегированные данные

### 📋 schemas/
**Назначение**: JSON схемы для валидации данных

Источник: Baza

Содержит:
- Схемы структуры данных
- Правила валидации
- Определения форматов

### 📂 sources/ (в корне репозитория)
**Назначение**: Исходные данные в различных форматах

Источник: Baza

Содержит:
- Исходные файлы производителей
- Сканы каталогов
- Справочные материалы
- Сырые данные до обработки

См. также: [sources/README.md](../sources/README.md)

## Формат данных

### CSV файлы

Кодировка: UTF-8
Разделитель: `,` (запятая)
Заголовки: первая строка

Пример структуры bearings.csv:
```csv
designation,type,d,D,B,manufacturer,standard
6205,Radial Ball Bearing,25,52,15,SKF,ISO
ГОСТ 8338-75,Шариковый радиальный,25,52,15,ГПЗ,ГОСТ
```

### JSON схемы

Формат: JSON Schema Draft 7
Валидация: используется для проверки корректности данных

## Использование

### Для разработчиков

Импорт в PostgreSQL:
```bash
python api/scripts/import_to_postgres.py
```

Чтение в Python:
```python
import pandas as pd

# Чтение данных ГОСТ
bearings = pd.read_csv('data/csv/gost/bearings.csv')

# Чтение аналогов
analogs = pd.read_csv('data/csv/analogs/gost_iso.csv')
```

### Для API

API автоматически использует данные из этой структуры:
```bash
# Запуск API сервера
cd api
python main.py
```

### Для обработки новых данных

1. Поместите файлы в `inbox/`
2. Запустите обработку:
```bash
python api/scripts/unpack_and_classify.py
```
3. Импортируйте в БД:
```bash
python api/scripts/import_to_postgres.py
```

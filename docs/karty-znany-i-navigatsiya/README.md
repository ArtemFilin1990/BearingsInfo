## 👥 Навигация по ролям

### 1. 💼 Менеджер по продажам

**Ваши основные задачи:**
- Консультация клиентов
- Подбор аналогов
- Оформление заказов

**Рекомендуемый путь обучения:**

```
📚 Начало
   ↓
🎓 Вводный курс [4-6 часов]
   ├─ Модуль 1: Основы (понимание продукта)
   ├─ Модуль 2: Обозначения (расшифровка запросов клиентов)
   └─ Модуль 4: Каталоги (поиск информации)
   ↓
🛠️ Практические руководства
   ├─ Расшифровка маркировки
   ├─ Подбор аналога
   ├─ Определение типа по фото
   └─ Оформление заказа
   ↓
🛠️ Инструменты
   ├─ Таблицы соответствий ГОСТ-ISO
   ├─ Индекс артикулов
   └─ Быстрый справочник по производителям
```

**Ключевые ресурсы:**
- 📖 [Расшифровка маркировки](<../prakticheskie-rukovodstva/01_Расшифровка_маркировки.md>)
- 📖 [Подбор аналога](<../prakticheskie-rukovodstva/04_Подбор_аналога.md>)
- 📊 [Таблицы соответствий](<../instrumenty-i-spravochniki/Таблицы_соответствий.md>)
- 🔍 [Индекс артикулов](../EXTRACTED_KNOWLEDGE_INDEX.md)

**Частые задачи:**
- ❓ Клиент спрашивает аналог → [Подбор аналога](<../prakticheskie-rukovodstva/04_Подбор_аналога.md>)
- ❓ Клиент называет неполное обозначение → [Расшифровка](<../prakticheskie-rukovodstva/01_Расшифровка_маркировки.md>)
- ❓ Нужно найти в каталоге → [Работа с каталогами](../../data/katalogi/README.md)

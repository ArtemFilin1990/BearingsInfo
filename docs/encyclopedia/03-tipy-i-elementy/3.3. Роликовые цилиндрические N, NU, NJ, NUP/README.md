# 3.3. Роликовые цилиндрические: N, NU, NJ, NUP

## Назначение

Описание конструктивных особенностей, маркировки и применения цилиндрических роликовых подшипников с различными конфигурациями бортов (рёбер). Раздел охватывает типы N, NU, NJ, NUP и их двухрядные варианты, предназначенные для восприятия радиальных и ограниченных осевых нагрузок при высоких скоростях вращения.

## Ключевые вопросы

- В чём различия между типами N, NU, NJ и NUP по конструкции бортов?
- Какие осевые нагрузки могут воспринимать подшипники типов NJ и NUP?
- Когда применяют однорядные и двухрядные цилиндрические роликоподшипники?
- Как обозначаются цилиндрические роликоподшипники по ГОСТ и ISO?
- Каковы преимущества и ограничения цилиндрических роликовых подшипников?
- Какие требования к монтажу и осевой фиксации для каждого типа?

## Содержание

### Конструкция и классификация

Цилиндрические роликовые подшипники — тип подшипников качения с телами качения в форме цилиндрических роликов. Основное отличие от шариковых — **линейный контакт** ролика с дорожкой качения, что обеспечивает:
- Высокую радиальную грузоподъёмность
- Жёсткость под нагрузкой
- Способность работы при высоких скоростях (до 80% предельной частоты вращения)

**Классификация по типу бортов (ГОСТ 8338-2014, ISO 15):**

| Тип | Внутреннее кольцо | Наружное кольцо | Борта | Осевая фиксация |
|-----|-------------------|-----------------|-------|-----------------|
| **N** | Без бортов | 2 борта | Борта на наружном кольце | Свободное перемещение внутреннего кольца |
| **NU** | 2 борта | Без бортов | Борта на внутреннем кольце | Свободное перемещение наружного кольца |
| **NJ** | 2 борта | 1 борт | Борт на наружном + 2 на внутреннем | Фиксация в одном направлении |
| **NUP** | 2 борта + съёмный борт | Без бортов | 2 борта + съёмный борт (шайба) | Фиксация в обоих направлениях |

### Типы и модификации

#### Тип N (без бортов на внутреннем кольце)
**Обозначение:** N 2ХХ, N 3ХХ (ГОСТ), N 2ХХ (ISO)

**Конструкция:**
- Внутреннее кольцо гладкое, без бортов
- Наружное кольцо с двумя направляющими бортами
- Сепаратор латунный, полиамидный или стальной штампованный

**Применение:**
- Узлы с осевым перемещением внутреннего кольца (температурное расширение валов)
- Парная установка с фиксирующим подшипником (например, радиально-упорным)
- Плавающие опоры редукторов, электродвигателей

**Пример:** N 310 (ГОСТ 8338), N 310 (ISO)

#### Тип NU (без бортов на наружном кольце)
**Обозначение:** 2ХХ, 3ХХ, 4ХХ (ГОСТ), NU 2ХХ (ISO)

**Конструкция:**
- Внутреннее кольцо с двумя бортами
- Наружное кольцо гладкое
- Наиболее распространённый тип цилиндрических роликоподшипников

**Применение:**
- Универсальные радиальные опоры
- Узлы с осевым перемещением наружного кольца (плавающие опоры в корпусе)
- Высоконагруженные электродвигатели, насосы, редукторы

**Пример:** 42726 (ГОСТ), NU 2226 (ISO)

#### Тип NJ (с одним бортом на наружном кольце)
**Обозначение:** 2ХХ1ХХ (ГОСТ), NJ 2ХХ (ISO)

**Конструкция:**
- Внутреннее кольцо с двумя бортами
- Наружное кольцо с одним бортом
- Воспринимает осевую нагрузку в одном направлении

**Применение:**
- Фиксирующие опоры валов (осевая нагрузка в одном направлении)
- Комбинация с подшипником типа NU на противоположной опоре
- Коробки передач, шпиндели станков

**Осевая нагрузка:** До 50% от динамической радиальной грузоподъёмности C

**Пример:** 42212 (ГОСТ), NJ 212 (ISO)

#### Тип NUP (с двумя бортами + съёмная шайба)
**Обозначение:** 2ХХ1ХХК (ГОСТ), NUP 2ХХ (ISO)

**Конструкция:**
- Внутреннее кольцо с двумя бортами
- Наружное кольцо с одним бортом
- Съёмная упорная шайба (кольцо) с противоположной стороны
- Воспринимает осевую нагрузку в обоих направлениях

**Применение:**
- Локализующие опоры (полная осевая фиксация вала)
- Замена радиально-упорных подшипников при умеренных осевых нагрузках
- Приводы конвейеров, центробежные насосы

**Осевая нагрузка:** До 50% от C в каждом направлении

**Пример:** 42212К (ГОСТ), NUP 212 (ISO)

### Двухрядные цилиндрические роликоподшипники

**Типы:**
- **NNU** — двухрядный, без бортов на наружном кольце
- **NNJ** — двухрядный с одним бортом на наружном кольце
- **NN** — двухрядный, без бортов на внутреннем кольце

**Обозначение ГОСТ:** 32ХХХ, 42ХХХ, 52ХХХ  
**Обозначение ISO:** NNU 30ХХ, NN 30ХХ

**Преимущества двухрядных:**
- Удвоенная радиальная грузоподъёмность
- Повышенная жёсткость узла
- Компактность по сравнению с двумя однорядными

**Применение:**
- Главные опоры прокатных станов
- Тяжёлые редукторы и коробки передач
- Опоры роторов мощных электродвигателей

### Маркировка и обозначение

#### По ГОСТ 3189-89, ГОСТ 8338-2014

**Структура обозначения:**
```
[X] [YY] [ZZ] [A] [B] [C]
│   │    │    │   │   └─ Доп. знаки (зазор, точность)
│   │    │    │   └───── Суффикс (K — съёмная шайба)
│   │    │    └─────────── Номер типа (1 — NJ, отсутствует — NU)
│   │    └────────────────── Размерная серия + номер диаметра
│   └─────────────────────── Серия диаметров (2, 3, 4)
└──────────────────────────── Префикс (N — без бортов на внутреннем)
```

**Примеры:**
- `42206` — NU 206 (внутренний диаметр 30 мм, серия диаметров 02)
- `42212` — NJ 212 (внутренний диаметр 60 мм, тип NJ)
- `42212К` — NUP 212 (съёмная шайба)
- `N310` — N 310 (без бортов на внутреннем кольце)

#### По ISO 15, ISO 355

**Структура обозначения:**
```
[Type] [Series][Size]
   │      │      └──── Номер размера (06, 12, 20...)
   │      └─────────── Серия диаметров и ширины (2, 3, 22, 23)
   └────────────────── Тип (N, NU, NJ, NUP, NNU, NN)
```

**Примеры:**
- `NU 2206` — тип NU, серия 22, размер 06 (d=30 мм)
- `NJ 312` — тип NJ, серия 3, размер 12 (d=60 мм)
- `NUP 2312` — тип NUP со съёмной шайбой
- `NNU 4924` — двухрядный, серия 49

### Технические характеристики

**Материалы:**
- Кольца: сталь ШХ15 (ГОСТ), 100Cr6 (ISO), закалка HRC 58–65
- Ролики: сталь ШХ15, закалка HRC 60–66
- Сепараторы: латунь ЛЦ16-04, полиамид PA66, сталь 08кп (штамповка)

**Точность изготовления:**
- По ГОСТ: P0 (нормальный), P6, P5, P4, P2
- По ISO: Normal (P0), Class 6, Class 5, Class 4, Class 2

**Рабочие зазоры:**
- Стандартный (CN / Normal)
- C2 (меньше нормального)
- C3 (больше нормального)
- C4, C5 (увеличенные)

**Диапазон скоростей:**
- Смазка пластичная: 0,5–0,7 от предельной n
- Смазка циркуляционная: 0,7–0,85 от n
- Масляный туман: до 0,9–0,95 от n

### Преимущества и недостатки

**Преимущества:**
| Критерий | Описание |
|----------|----------|
| Радиальная грузоподъёмность | На 30–50% выше шариковых при тех же габаритах |
| Жёсткость | Высокая радиальная жёсткость благодаря линейному контакту |
| Скорость | Высокие скорости вращения (сепаратор снижает трение) |
| Долговечность | Увеличенный ресурс при радиальных нагрузках |
| Осевое перемещение | Типы N, NU допускают осевое перемещение колец |

**Недостатки:**
| Критерий | Описание |
|----------|----------|
| Осевая нагрузка | Типы N, NU не воспринимают; NJ, NUP — ограниченно (до 50% C) |
| Перекосы | Чувствительность к перекосам осей (требуется соосность) |
| Шум | Выше уровень шума по сравнению с шариковыми (особенно стальной сепаратор) |
| Стоимость | Дороже шариковых подшипников того же размера |

### Применение и примеры

**Отрасли промышленности:**
- **Электродвигатели:** Опоры роторов мощностью от 5 кВт
- **Редукторы и коробки передач:** Опоры валов с зубчатыми колёсами
- **Станки:** Шпиндельные узлы, опоры столов
- **Насосы и компрессоры:** Центробежные насосы, винтовые компрессоры
- **Прокатное оборудование:** Опоры рабочих валков, клетей
- **Железнодорожный транспорт:** Буксы локомотивов (двухрядные NNU, NN)

**Типовые схемы установки:**

1. **Плавающая опора (NU):**
   - NU в качестве плавающей опоры (осевое перемещение наружного кольца)
   - Фиксирующая опора — радиально-упорный подшипник на противоположном конце вала

2. **Локализующая опора (NJ):**
   - NJ фиксирует вал в одном направлении
   - NU на противоположной опоре

3. **Полная фиксация (NUP):**
   - NUP фиксирует вал в обоих направлениях
   - Возможна парная установка двух подшипников NUP

4. **Двухрядная опора (NNU):**
   - Заменяет два однорядных NU
   - Применяется при высоких радиальных нагрузках и требовании компактности

### Рекомендации по выбору

**Критерии выбора типа:**

| Условие | Рекомендуемый тип | Обоснование |
|---------|-------------------|-------------|
| Только радиальная нагрузка | NU | Универсальность, низкая стоимость |
| Осевое перемещение вала требуется | N или NU | Компенсация температурных расширений |
| Осевая нагрузка в одном направлении | NJ | Борт на наружном кольце удерживает ролики |
| Осевая фиксация в обоих направлениях | NUP | Съёмная шайба фиксирует вал |
| Очень высокие радиальные нагрузки | NNU, NN (двухрядные) | Удвоенная грузоподъёмность |
| Высокие скорости (>5000 об/мин) | Латунный или PA66 сепаратор | Снижение трения и нагрева |
| Умеренные скорости, тяжёлые нагрузки | Стальной сепаратор | Прочность сепаратора |

**Монтаж и эксплуатация:**
- Посадка на вал: обычно j6, k6 (вращающееся кольцо), h6 (неподвижное)
- Посадка в корпус: H7, H8
- Смазка: пластичная (литиевая 2-я группа NLGI) или масло (ISO VG 68–220)
- Осевая фиксация: стопорное кольцо, торцевая крышка, распорные втулки

### Сравнение с другими типами подшипников

| Характеристика | Цилиндрические роликовые | Шариковые радиальные | Радиально-упорные шариковые | Конические роликовые |
|----------------|--------------------------|----------------------|-----------------------------|----------------------|
| Радиальная нагрузка | Очень высокая | Средняя | Высокая | Очень высокая |
| Осевая нагрузка | Ограниченная (NJ, NUP) | Средняя | Высокая | Высокая |
| Скорость | Высокая | Очень высокая | Высокая | Средняя |
| Жёсткость | Высокая | Средняя | Высокая | Очень высокая |
| Допуск перекоса | Низкий | Средний | Низкий | Очень низкий |
| Цена | Высокая | Низкая | Средняя | Высокая |

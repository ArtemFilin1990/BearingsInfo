# 3.4. Роликовые конические

## Назначение

Описание конструкции, принципов работы, классификации и применения конических роликоподшипников. Раздел охватывает однорядные и многорядные конические подшипники, методы их установки, регулировки и расчёта для восприятия комбинированных радиальных и осевых нагрузок.

## Ключевые вопросы

- Чем отличается конструкция конических роликоподшипников от цилиндрических?
- Что такое угол конуса и как он влияет на восприятие осевых нагрузок?
- Как маркируются конические подшипники по ГОСТ и ISO?
- Какие схемы установки (X, O, тандем) используются для конических подшипников?
- Как регулируется зазор (преднатяг) в конических роликоподшипниках?
- В каких отраслях и механизмах применяются конические подшипники?

## Содержание

### Конструкция и принцип работы

Конические роликоподшипники — подшипники качения с коническими роликами и дорожками качения, образующими конические поверхности. Все образующие конусов (оси роликов, дорожки качения) пересекаются в одной точке — вершине конуса.

**Основные элементы:**
- **Внутреннее кольцо (конус)** — коническая дорожка качения, большой борт
- **Наружное кольцо (чашка)** — коническое кольцо, отделяемое от комплекта
- **Конические ролики** — с профилем конуса, контактируют по линии
- **Сепаратор** — штампованный (сталь) или латунный, удерживает ролики
- **Большой борт** внутреннего кольца — центрирует ролики, смазывается торцом ролика

**Принцип работы:**
1. Под нагрузкой возникает **контактная линия** между роликом и дорожками качения
2. Радиальная нагрузка создаёт **осевую составляющую** силы (распирание колец)
3. Чем больше **угол конуса α**, тем выше доля осевой нагрузки
4. Необходима **парная установка** или упор для восприятия осевой составляющей

**Геометрические параметры:**
- **Угол конуса α** (контактный угол): обычно 10°–30°
  - Малый угол (10°–15°): в основном радиальная нагрузка
  - Средний угол (15°–20°): универсальные
  - Большой угол (25°–30°): преимущественно осевая нагрузка

### Классификация конических роликоподшипников

#### По числу рядов

**1. Однорядные (наиболее распространённые)**
- Обозначение ГОСТ: 7ХХХ, 27ХХХ, 67ХХХ
- Обозначение ISO: 302ХХ, 303ХХ, 320ХХ, 322ХХ, 323ХХ, 329ХХ, 330ХХ, 331ХХ, 332ХХ
- Разборная конструкция (внутреннее и наружное кольца независимы)
- Требуют парной установки для восприятия радиальных и осевых нагрузок

**2. Двухрядные**
- Обозначение ГОСТ: 697ХХХ, 27697ХХХ
- Обозначение ISO: TDO, TDI (double-row)
- Компактнее двух однорядных
- Воспринимают радиальные и осевые нагрузки в обоих направлениях

**3. Четырёхрядные**
- Применение: прокатные станы, тяжёлая промышленность
- Обозначение: FC, FCD (Four-row Cylindrical)
- Очень высокая грузоподъёмность в компактном исполнении

#### По углу конуса

| Тип | Угол α | Применение | Пример серии |
|-----|--------|------------|--------------|
| Малый угол | 10°–15° | Преимущественно радиальная нагрузка, высокие скорости | ISO 302, 303 |
| Средний угол | 15°–20° | Сбалансированные радиальные и осевые нагрузки | ISO 320, 322, 323 |
| Большой угол | 25°–30° | Высокие осевые нагрузки, низкие скорости | ISO 329, 330, 331 |

### Маркировка и обозначение

#### По ГОСТ 27365-87, ГОСТ 333-79

**Структура обозначения:**
```
[Prefix] [X] [YYYY] [Suffix]
    │     │    │       └──── Доп. знаки (точность, зазор)
    │     │    └─────────── Номер размера (0000–9999)
    │     └──────────────── Серия (7 — коническая однорядная)
    └────────────────────── Префикс (2, 6 — серии диаметра/ширины)
```

**Примеры ГОСТ:**
- `7206` — однорядный конический, размер 06 (d=30 мм)
- `7512` — однорядный конический, размер 12 (d=60 мм)
- `27516` — увеличенная серия (внешний диаметр)
- `697316` — двухрядный конический
- `7520А` — размер 20, класс точности А (повышенный)

#### По ISO 355:2007

**Структура обозначения:**
```
[Series] [Size]
   │       └──── Номер размера (00–99)
   └──────────── Серия (302, 303, 320, 322, 323, 329, 330, 331, 332)
```

**Примеры ISO:**
- `30206` — серия 302 (лёгкая), размер 06 (d=30 мм)
- `32012` — серия 320 (средняя), размер 12 (d=60 мм)
- `33116` — серия 331 (тяжёлая), размер 16 (d=80 мм)
- `T2ED045` — двухрядный (Timken)
- `TDO` — двухрядный (ISO/Timken обозначение)

**Производители используют собственные обозначения:**
- **Timken:** система дюймовых обозначений (LM, HM, JM серии)
- **SKF:** стандарт ISO + суффиксы
- **FAG, NSK, NTN:** ISO + собственные префиксы

### Технические характеристики

**Материалы:**
- Кольца: сталь ШХ15, 100Cr6 (закалка HRC 58–64)
- Ролики: сталь ШХ15 (HRC 60–65)
- Сепаратор: штампованная сталь 08кп, латунь ЛЦ16К4

**Классы точности:**
- По ГОСТ: P0 (нормальный), P6, P5, P4, P2
- По ISO: Normal, Class 6, Class 5, Class 4

**Преимущества:**
| Параметр | Описание |
|----------|----------|
| Грузоподъёмность | Очень высокая радиальная и осевая (выше шариковых и цилиндрических) |
| Жёсткость | Высокая благодаря линейному контакту роликов |
| Восприятие нагрузок | Комбинированная радиально-осевая нагрузка |
| Разборность | Независимая установка внутреннего и наружного колец |
| Регулировка зазора | Возможность преднатяга для повышения жёсткости |

**Недостатки:**
| Параметр | Описание |
|----------|----------|
| Скорость | Ниже, чем у шариковых и цилиндрических роликовых |
| Сложность установки | Требуется регулировка зазора (преднатяга) |
| Осевая нагрузка обязательна | Нельзя использовать без фиксации осевой нагрузки |
| Точность монтажа | Требуется высокая точность посадочных мест |
| Шум | Выше, чем у шариковых подшипников |

### Схемы установки конических подшипников

Конические роликоподшипники всегда устанавливаются **парами** или с **упором**, так как под радиальной нагрузкой возникает осевая составляющая силы.

#### 1. Схема «X» (враспор)

**Описание:** Широкие торцы конусов обращены наружу (друг от друга)

```
  ╱╲        ╱╲
 ╱  ╲ вал  ╱  ╲
╱────╲────╱────╲
     Fr←→Fr
  ←Fa    Fa→
```

**Характеристики:**
- Высокая радиальная и осевая жёсткость
- Возможен регулируемый преднатяг (увеличение жёсткости)
- Чувствительность к тепловому расширению вала

**Применение:**
- Коробки передач автомобилей
- Ступицы колёс грузовых автомобилей
- Шпиндели станков (умеренная скорость)

**Регулировка:** Осевым перемещением одного кольца (регулировочная гайка, шайбы)

#### 2. Схема «O» (в растяжку)

**Описание:** Широкие торцы конусов обращены друг к другу

```
  ╲╱        ╲╱
   ╲  вал  ╱
────╲────╱────
  Fa→  ←Fa
    ←Fr→
```

**Характеристики:**
- Меньшая чувствительность к тепловому расширению (зазор увеличивается)
- Восприятие опрокидывающих моментов
- Меньшая жёсткость, чем схема «X»

**Применение:**
- Дифференциалы автомобилей
- Редукторы конвейеров
- Железнодорожные буксы

#### 3. Схема «Тандем» (последовательная)

**Описание:** Два или более подшипника установлены рядом в одном направлении

```
  ╱╲╱╲
 ╱    ╲ вал
╱──────╲
  Fr→
```

**Характеристики:**
- Очень высокая осевая грузоподъёмность в одном направлении
- Суммируется грузоподъёмность обоих подшипников

**Применение:**
- Осевые опоры валков прокатных станов
- Винтовые прессы
- Тяжёлые осевые нагрузки

### Регулировка зазора и преднатяга

**Цели регулировки:**
- Устранение радиального зазора (повышение точности, жёсткости)
- Создание преднатяга (дополнительная жёсткость, компенсация износа)
- Компенсация теплового расширения

**Методы регулировки:**

| Метод | Описание | Применение |
|-------|----------|------------|
| Гайка на резьбе вала | Осевое перемещение внутреннего кольца | Ступицы колёс, шпиндели |
| Регулировочные шайбы | Набор калиброванных шайб (толщина 0,05–0,5 мм) | Редукторы, коробки передач |
| Дистанционные втулки | Фиксированная толщина между подшипниками | Конвейеры, промышленные редукторы |
| Пружинное поджатие | Тарельчатые пружины, поджимные гайки | Компенсация износа, теплового расширения |

**Величины преднатяга:**
- **Нулевой зазор:** для точных механизмов (станки)
- **Лёгкий преднатяг:** 0,01–0,02 мм (высокоточные шпиндели)
- **Средний преднатяг:** 0,02–0,05 мм (коробки передач)
- **Сильный преднатяг:** 0,05–0,10 мм (тяжёлые условия, ударные нагрузки)

**Контроль регулировки:**
- Момент проворачивания (динамометрический ключ)
- Осевой люфт (индикатор часового типа)
- Температура в работе (не выше 70–80°C для пластичной смазки)

### Применение конических роликоподшипников

**Отрасли и механизмы:**

| Отрасль | Применение | Типовая схема |
|---------|------------|---------------|
| **Автомобилестроение** | Ступицы колёс грузовиков, полуоси, дифференциалы, коробки передач | X, O |
| **Железнодорожный транспорт** | Буксы вагонов, локомотивов | O |
| **Металлургия** | Прокатные станы, валки, редукторы главных приводов | Тандем, двухрядные |
| **Горнодобывающая** | Конвейеры, дробилки, барабаны экскаваторов | O, тандем |
| **Станкостроение** | Шпиндели токарных, фрезерных станков (средние скорости) | X |
| **Сельхозтехника** | Редукторы комбайнов, тракторов, шкивы | X, O |
| **Строительная техника** | Редукторы кранов, поворотные платформы, ходовые тележки | O |

**Примеры типовых узлов:**

1. **Ступица колеса грузовика:**
   - Схема «X» (два однорядных конических подшипника)
   - Регулировка гайкой на цапфе оси
   - Смазка: пластичная литиевая (NLGI 2)

2. **Редуктор конвейера:**
   - Схема «O» (осевая фиксация, компенсация расширения)
   - Регулировка шайбами
   - Смазка: масло ISO VG 220

3. **Шпиндель станка:**
   - Схема «X» с преднатягом
   - Точность P5
   - Смазка: масляный туман или циркуляция

### Сравнение с другими типами подшипников

| Параметр | Конические роликовые | Радиально-упорные шариковые | Цилиндрические роликовые | Сферические роликовые |
|----------|----------------------|-----------------------------|--------------------------|-----------------------|
| Радиальная нагрузка | Очень высокая | Высокая | Очень высокая | Максимальная |
| Осевая нагрузка | Высокая | Высокая | Низкая (NJ, NUP) | Средняя |
| Комбинированная нагрузка | Отлично | Хорошо | Удовлетворительно (NJ, NUP) | Отлично |
| Скорость | Средняя | Высокая | Высокая | Низкая |
| Жёсткость | Очень высокая | Высокая | Высокая | Средняя |
| Допуск перекоса | Очень низкий | Низкий | Низкий | Высокий |
| Разборность | Да | Нет | Нет | Нет |
| Регулировка зазора | Да | Ограниченно (комплекты) | Нет | Нет |
| Цена | Высокая | Средняя | Высокая | Очень высокая |

### Рекомендации по выбору и эксплуатации

**Выбор типа конического подшипника:**

| Условие | Рекомендация |
|---------|--------------|
| Высокая радиальная + умеренная осевая | Однорядные, средний угол (15°–20°) |
| Преимущественно осевая нагрузка | Большой угол (25°–30°), схема тандем |
| Очень высокие нагрузки, компактность | Двухрядные, четырёхрядные |
| Требуется высокая жёсткость | Схема «X» с преднатягом |
| Температурное расширение вала | Схема «O» |
| Точность вращения | Класс P5, преднатяг, схема «X» |

**Монтаж и обслуживание:**
- **Посадки:** внутреннее кольцо k6, m6 (вращающееся); наружное кольцо H7, H8 (неподвижное)
- **Смазка:** пластичная литиевая NLGI 2 (ступицы), масло ISO VG 150–320 (редукторы)
- **Регулировка:** проводить в сборе, контроль момента проворачивания
- **Температура:** контролировать в обкатке (не выше 70–80°C для пластичной смазки)
- **Замена:** менять комплектом (внутреннее + наружное кольцо), не комбинировать разные бренды

**Типовые ошибки:**
- Установка подшипников разных производителей в одну опору (разные углы конуса)
- Избыточный преднатяг (перегрев, снижение ресурса)
- Недостаточная смазка большого борта (износ торцов роликов)
- Неправильная посадка (перекос осей, нарушение контакта)

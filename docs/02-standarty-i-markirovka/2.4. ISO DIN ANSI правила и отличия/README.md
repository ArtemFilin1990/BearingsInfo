# 2.4. ISO/DIN/ANSI: правила и отличия

## Назначение

Сравнительный анализ международных систем обозначения подшипников качения: ISO (Международная организация по стандартизации), DIN (Немецкий институт стандартов) и ANSI/ABMA (Американский национальный институт стандартов / Американская ассоциация производителей подшипников). Документ раскрывает ключевые различия в методологии кодирования, префиксах, суффиксах и правилах интерпретации обозначений.

## Ключевые вопросы

- В чём заключаются основные различия между ISO, DIN и ANSI системами обозначения?
- Как преобразовать обозначение подшипника из одного стандарта в другой?
- Какие уникальные суффиксы и префиксы используются в каждой системе?
- Как определить размеры подшипника по обозначению в разных стандартах?
- Какие системы являются взаимозаменяемыми, а какие требуют адаптации?

## Содержание

### 1. Общая структура обозначений

#### ISO 15 (актуальная редакция ISO 15:2017)
**Структура:** `[Префикс] - Базовое обозначение - [Суффикс]`

```
Пример: 6305-2RS1/C3
│       │    │    │└─ Суффикс радиального зазора
│       │    │    └── Суффикс уплотнения
│       │    └─────── Серия ширины (средняя)
│       └──────────── Диаметр отверстия (d = 25 мм)
└──────────────────── Тип подшипника (радиальный шариковый однорядный)
```

**Базовая структура:**
- **Цифра 1** — тип подшипника (6 = радиальный шариковый однорядный)
- **Цифра 2** — серия ширины (3 = средняя)
- **Цифра 3** — серия наружного диаметра (0 = сверхлёгкая, 2 = лёгкая, 3 = средняя)
- **Цифры 4-5** — код диаметра отверстия (05 = 25 мм, делится на 5)

#### DIN (традиционная немецкая система, интегрирована в ISO)
**Особенность:** Германия с 1970-х годов перешла на ISO, но многие производители сохраняют исторические DIN-обозначения.

```
DIN 625: Радиальные шариковые подшипники однорядные
DIN 628: Радиальные шариковые подшипники двухрядные
DIN 711: Радиальные роликовые подшипники цилиндрические
```

**Главное отличие:** DIN использовал отдельные стандарты для каждого типа подшипника, ISO унифицировал систему.

#### ANSI/ABMA 20-2015 (Американская система)
**Структура:** Граничные размеры (Boundary Plan) вместо кодов

```
Пример: 306 (ANSI) ≈ 6306 (ISO)
│       │└─ Серия (0 = extra-light, 2 = light, 3 = medium, 4 = heavy)
│       └── Код диаметра отверстия (06 = 30 мм)
└──────── Тип опущен (предполагается однорядный радиальный)
```

**Уникальные черты ANSI:**
- Классы точности: ABEC-1, ABEC-3, ABEC-5, ABEC-7, ABEC-9 (аналог ISO P0, P6, P5, P4, P2)
- Граничные планы (Boundary Plans): определяют взаимозаменяемость габаритных размеров
- Дюймовые размеры: R2, R4, R6 (вместо метрических)

### 4. Преобразование обозначений между стандартами

#### Пример 1: Радиальный шариковый подшипник

| **Стандарт** | **Обозначение** | **Описание**                                                 |
|--------------|-----------------|--------------------------------------------------------------|
| ISO          | 6305-2RS1/C3    | d=25 мм, D=62 мм, B=17 мм, два уплотнения, зазор C3          |
| DIN          | 625-2RS-C3      | Аналогичен ISO (современный DIN = ISO)                       |
| ANSI         | 305-2RS-W64     | d=25 мм, серия 3, два уплотнения, увеличенный зазор          |

**Правило преобразования:**
- ISO `6305` → ANSI `305` (удалить префикс типа "6")
- Суффиксы обычно совпадают (2RS, 2Z), но зазор может кодироваться по-разному

#### Пример 2: Конический роликовый подшипник

| **Стандарт** | **Обозначение** | **Описание**                                                 |
|--------------|-----------------|--------------------------------------------------------------|
| ISO          | 32310           | d=50 мм, D=110 мм, T=29.25 мм                                |
| DIN          | 32310 A         | Аналогичен ISO, "A" — угол конуса α=12°                      |
| ANSI         | T7FC050         | Дюймовая серия, T = тип, 050 = 0.5 inch bore                |

**Важно:** Конические подшипники ANSI часто имеют **дюймовые размеры** и не совпадают с ISO/DIN!

#### Пример 3: Цилиндрический роликовый подшипник

| **Стандарт** | **Обозначение** | **Описание**                                                 |
|--------------|-----------------|--------------------------------------------------------------|
| ISO          | NU 2216 ECP     | d=80 мм, D=140 мм, B=33 мм, конструкция NU (борт на НК), P5  |
| DIN          | NU 2216 E       | Аналогичен ISO, "E" — оптимизированная конструкция           |
| ANSI         | NU-2216-M       | Аналогичен ISO, "M" — латунный сепаратор                     |

### 6. Уникальные особенности каждой системы

#### ISO (ISO 15, ISO 355, ISO 492, ISO 5593)
**Преимущества:**
- Унифицированная глобальная система
- Чёткая структура кодирования
- Интеграция всех типов подшипников в единую номенклатуру

**Недостатки:**
- Сложность для новичков (многосимвольные коды)
- Необходимость запоминания серий (00, 02, 03, 04)

**Уникальные элементы:**
- Префиксы для специальных конструкций: `E` (усиленный), `C` (угол контакта), `QJ` (четырёхточечный)
- Суффиксы материала клетки: `TN9` (полиамид), `TVPB` (полиамид, направленный стекловолокном)

#### DIN (интегрирован в ISO с 1980-х)
**Историческое значение:**
- Основа для разработки ISO 15
- Используется в технической документации немецких производителей (FAG, INA, Schaeffler)

**Уникальные элементы:**
- Отдельные стандарты по типам: DIN 625 (шариковые), DIN 711 (цилиндрические)
- Обозначение конструктивных углов: `A` = 12°, `B` = 15° (для конических)

#### ANSI/ABMA (американская система)
**Преимущества:**
- Простота для базовых подшипников (трёхзначные коды)
- Граничные планы (Boundary Plans) гарантируют взаимозаменяемость

**Недостатки:**
- Меньшая детализация (нет чёткой системы суффиксов)
- Сосуществование метрических и дюймовых обозначений

**Уникальные элементы:**
- ABEC-классы точности (1, 3, 5, 7, 9)
- Дюймовые подшипники: `R` (radial inch), `R2` = 1/8", `R4` = 1/4"
- Boundary Plans: определяют габариты для взаимозаменяемости (AFBMA Std 20)

### 7. Практические примеры преобразования

#### Задача 1: ISO → ANSI
**Дано:** ISO обозначение `6208-2Z/C3`

**Решение:**
1. Убрать префикс типа "6" → `208`
2. Суффикс `2Z` аналогичен ANSI `ZZ`
3. Зазор `C3` → ANSI `W64` (расширенный)

**Результат:** ANSI `208-ZZ-W64`

#### Задача 2: ANSI → ISO
**Дано:** ANSI обозначение `310-ABEC5`

**Решение:**
1. Добавить префикс "6" для радиального шарикового → `6310`
2. `ABEC5` = ISO `P5`

**Результат:** ISO `6310/P5`

#### Задача 3: DIN → ISO
**Дано:** DIN обозначение `NU 2220 E.M1.C3`

**Решение:**
1. Базовое обозначение идентично → `NU 2220`
2. `E` = оптимизированная конструкция (ISO: `E`)
3. `M1` = латунный сепаратор (ISO: `M`)
4. `C3` = радиальный зазор (ISO: `C3`)

**Результат:** ISO `NU 2220 EM/C3`

### 9. Рекомендации по выбору стандарта

#### Когда использовать ISO:
- Международные проекты с поставщиками из разных стран
- Документация должна соответствовать ЕС нормам
- Необходима максимальная детализация (суффиксы, точность, материалы)

#### Когда использовать DIN:
- Работа с немецкими производителями (FAG, INA, Schaeffler)
- Историческая документация требует DIN-обозначений
- Проекты в Германии, Австрии, Швейцарии

#### Когда использовать ANSI:
- Проекты в США, Канаде
- Дюймовые размеры предпочтительны
- Простота обозначения важнее детализации
- Граничные планы (Boundary Plans) критичны для взаимозаменяемости

### 11. Часто встречающиеся ошибки при преобразовании

#### Ошибка 1: Прямое копирование суффиксов
**Неправильно:** ISO `6308-2RS1` → ANSI `308-2RS1`
**Правильно:** ANSI `308-2RS` (ANSI не использует "1" в суффиксе)

#### Ошибка 2: Игнорирование дюймовых размеров ANSI
**Неправильно:** Заменить дюймовый ANSI `R8-ZZ` на ISO `6308-2Z`
**Правильно:** `R8` = d = 1/2" = 12.7 мм (не существует прямого ISO аналога)

#### Ошибка 3: Путаница в классах точности
**Неправильно:** ISO `P5` = ANSI `ABEC-5` (правильно)
**Неправильно:** ISO `P4` = ANSI `ABEC-4` (не существует ABEC-4!)
**Правильно:** ISO `P4` = ANSI `ABEC-7`

#### Ошибка 4: Неучет конструктивных различий
**Пример:** Конический подшипник ISO `30310` имеет метрические размеры, ANSI `T7FC110` — дюймовые. Прямая замена невозможна без проверки габаритов!

### 12. Алгоритм преобразования ISO ↔ ANSI ↔ DIN

```
ШАГ 1: Определить базовый тип подшипника
- Радиальный шариковый: ISO 6xxx → ANSI xxx (удалить "6")
- Конический роликовый: проверить дюймовость!
- Цилиндрический: префиксы совпадают (NU, N, NJ)

ШАГ 2: Преобразовать диаметр отверстия
- Для d ≥ 20 мм: ISO "xx" × 5 = d (мм), ANSI аналогично
- Для d < 20 мм: ISO "00"=10 мм, "01"=12 мм, "02"=15 мм, "03"=17 мм
- ANSI дюймовые: R8 = 1/2" = 12.7 мм (таблица преобразования)

ШАГ 3: Преобразовать суффиксы
- Уплотнения: ISO 2RS1 = ANSI 2RS = DIN 2RS
- Зазор: ISO C3 = ANSI W64 = DIN C3
- Точность: ISO P5 = ANSI ABEC-5 = DIN P5

ШАГ 4: Проверить габариты (d, D, B) в каталогах
- Убедиться, что размеры совпадают в пределах допусков
- Для конических проверить углы конусов!

ШАГ 5: Уточнить у производителя
- Специфичные суффиксы могут не иметь прямых аналогов
```

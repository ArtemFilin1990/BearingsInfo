# 2.11. Примеры расшифровки обозначений

## Назначение

Практическое руководство по расшифровке обозначений подшипников качения с пошаговыми примерами различной сложности по стандартам ГОСТ и ISO.

## Ключевые вопросы

- Как пошагово расшифровать обозначение подшипника?
- Какой порядок чтения обозначения (префикс, базовое, суффикс)?
- Как определить размеры подшипника по обозначению?
- Как расшифровать сложные обозначения с множественными суффиксами?
- Какие различия в расшифровке ГОСТ и ISO обозначений?
- Как интерпретировать обозначения разных типов подшипников?

## Содержание

### Алгоритм расшифровки обозначения

#### Общий порядок действий

```
Шаг 1: Разделить обозначение на части
        [ПРЕФИКС] - [ОСНОВНОЕ] - [СУФФИКС]

Шаг 2: Расшифровать ПРЕФИКС (справа налево)
        Зазор → Класс точности → Момент → Категория

Шаг 3: Расшифровать ОСНОВНОЕ обозначение (справа налево)
        Диаметр (2 цифры) → Ширина (1) → Диаметр серия (1) → Тип (1-2)

Шаг 4: Расшифровать СУФФИКС (слева направо)
        Конструкция → Материал → Уплотнения → Смазка → Спец. требования

Шаг 5: Определить размеры из справочника или по серии
```

### Уровень 1: Простые обозначения

#### Пример 1.1: **305**

**Дано:** **305**

**Расшифровка:**

**Шаг 1:** Разделение на части
```
Префикс: отсутствует
Основное: 305
Суффикс: отсутствует
```

**Шаг 2:** Префикс отсутствует
- Класс точности: **0** (нормальный, не указывается)
- Зазор: **нормальный** (не указывается)

**Шаг 3:** Основное обозначение **305**
- **0** в начале опущен → тип **0** (шариковый радиальный однорядный)
- Полное обозначение: **0305**
- **3** — серия диаметров (средняя)
- **0** — серия ширины (нормальная)
- **05** — диаметр отверстия: 05 × 5 = **25 мм**

**Шаг 4:** Суффикс отсутствует
- Без уплотнений (открытый)
- Сепаратор стальной (стандартный)

**Шаг 5:** Размеры из справочника
- d = 25 мм
- D = 62 мм (средняя серия)
- B = 17 мм (нормальная ширина)

**Результат:**
> Шариковый радиальный однорядный подшипник, класс точности 0 (нормальный), нормальный зазор, без уплотнений, d = 25 мм, D = 62 мм, B = 17 мм.

---

#### Пример 1.2: **6205**

**Дано:** **6205**

**Расшифровка:**

**Разделение:**
```
Префикс: нет
Основное: 6205
Суффикс: нет
```

**Основное обозначение:**
- **6** — шариковый радиальный однорядный
- **2** — серия диаметров (лёгкая)
- **0** — серия ширины (нормальная)
- **05** — диаметр: 05 × 5 = **25 мм**

**Размеры:**
- d = 25 мм
- D = 52 мм (лёгкая серия)
- B = 15 мм

**Результат:**
> Шариковый радиальный однорядный подшипник лёгкой серии, d = 25 мм, D = 52 мм, B = 15 мм, без уплотнений.

**Сравнение с 305:**
- **305**: D = 62 мм (средняя серия, более тяжёлая)
- **6205**: D = 52 мм (лёгкая серия)

---

#### Пример 1.3: **6308**

**Дано:** **6308**

**Основное обозначение:**
- **6** — шариковый радиальный
- **3** — серия диаметров (средняя)
- **0** — ширина нормальная
- **08** — диаметр: 08 × 5 = **40 мм**

**Размеры:**
- d = 40 мм
- D = 90 мм
- B = 23 мм

**Результат:**
> Шариковый радиальный подшипник средней серии, d = 40 мм, D = 90 мм, B = 23 мм.

### Уровень 2: Обозначения с префиксом

#### Пример 2.1: **5-6205**

**Дано:** **5-6205**

**Разделение:**
```
Префикс: 5
Основное: 6205
Суффикс: нет
```

**Префикс:**
- **5** — класс точности 5 (высокая точность)

**Основное:** (см. пример 1.2)
- Шариковый радиальный, d = 25 мм, D = 52 мм, B = 15 мм

**Результат:**
> Шариковый радиальный подшипник d = 25 мм, **класс точности 5** (высокая), лёгкая серия.

**Применение:** Высокооборотистые электродвигатели, станки, точные механизмы.

---

#### Пример 2.2: **7-6205**

**Дано:** **7-6205**

**Префикс:**
- **7** — радиальный зазор группы 7 (увеличенный, соответствует C3 по ISO)

**Основное:**
- d = 25 мм, D = 52 мм, B = 15 мм

**Результат:**
> Шариковый радиальный подшипник d = 25 мм с **увеличенным зазором** (группа 7 / C3).

**Применение:** Узлы с повышенным нагревом, натяги, высокие температуры.

---

#### Пример 2.3: **7-5-6205**

**Дано:** **7-5-6205**

**Префикс:**
```
7 - 5
│   └─ Класс точности 5
└───── Зазор группы 7
```

**Расшифровка:**
- **7** — увеличенный зазор (C3)
- **5** — класс точности 5 (высокая)
- **6205** — шариковый радиальный, d = 25 мм

**Результат:**
> Шариковый радиальный подшипник d = 25 мм, **класс точности 5**, **зазор C3** (увеличенный).

**Применение:** Высокоскоростные электродвигатели с повышенным нагревом внутреннего кольца.

---

#### Пример 2.4: **6У-7520**

**Дано:** **6У-7520**

**Префикс:**
- **6** — класс точности 6
- **У** — повышенная точность по монтажной высоте (только для конических роликовых)

**Основное:**
- **7** — роликовый конический
- **5** — серия диаметров (тяжёлая)
- **2** — серия ширины (широкая)
- **20** — диаметр: 20 × 5 = **100 мм**

**Результат:**
> Роликовый конический подшипник d = 100 мм, тяжёлая широкая серия, **класс точности 6**, **повышенная точность по монтажной высоте**.

**Применение:** Прецизионные редукторы, станочное оборудование.

### Уровень 3: Обозначения с суффиксом

#### Пример 3.1: **6205-Z**

**Дано:** **6205-Z**

**Разделение:**
```
Основное: 6205
Суффикс: Z
```

**Основное:**
- Шариковый радиальный, d = 25 мм

**Суффикс:**
- **Z** — одно защитное кольцо (бесконтактное, со стороны маркировки)

**Результат:**
> Шариковый радиальный подшипник d = 25 мм с **одним защитным кольцом**.

**Особенности:**
- Защита от крупной пыли
- Момент трения +10% от открытого
- Скорость 95% от максимальной

---

#### Пример 3.2: **6205-ZZ**

**Дано:** **6205-ZZ**

**Суффикс:**
- **ZZ** — два защитных кольца (с обеих сторон)

**Результат:**
> Шариковый радиальный подшипник d = 25 мм с **двумя защитными кольцами**.

**Особенности:**
- Защита с обеих сторон
- Лучше удерживает смазку
- Периодическая смазка всё равно требуется

---

#### Пример 3.3: **6205-2RS**

**Дано:** **6205-2RS**

**Суффикс:**
- **2RS** — два резиновых контактных уплотнения

**Результат:**
> Шариковый радиальный подшипник d = 25 мм с **двумя резиновыми уплотнениями** (герметичный, необслуживаемый).

**Особенности:**
- Полная защита от влаги и пыли
- Заложена смазка на весь срок службы
- Момент трения в 2 раза выше
- Скорость ~65% от максимальной

**Применение:** Влажная и пыльная среда, труднодоступные узлы.

---

#### Пример 3.4: **6205-Е**

**Дано:** **6205-Е**

**Суффикс:**
- **Е** — сепаратор из текстолита

**Результат:**
> Шариковый радиальный подшипник d = 25 мм с **текстолитовым сепаратором**.

**Особенности:**
- Повышенная скорость вращения
- Хорошие антифрикционные свойства
- Температура до +110°C

**Применение:** Высокоскоростные и прецизионные подшипники.

---

#### Пример 3.5: **6205-К**

**Дано:** **6205-К**

**Суффикс:**
- **К** — коническое отверстие (конусность 1:12)

**Результат:**
> Шариковый радиальный подшипник d = 25 мм с **коническим отверстием**.

**Особенности:**
- Упрощённый монтаж/демонтаж
- Регулировка зазора при установке
- Монтаж на конический вал или с втулкой

### Уровень 5: Полные обозначения

#### Пример 5.1: **7-5-6205-2RS-Е-Ш2**

**Дано:** **7-5-6205-2RS-Е-Ш2**

**Полная разборка:**

```
7 - 5 - 6205 - 2RS - Е - Ш2
│   │    │      │     │   └── Специальные требования по шуму
│   │    │      │     └────── Текстолитовый сепаратор
│   │    │      └──────────── Два резиновых уплотнения
│   │    └─────────────────── Основное: d=25мм, лёгкая серия
│   └──────────────────────── Класс точности 5
└──────────────────────────── Зазор группы 7 (C3)
```

**Расшифровка по шагам:**

**Префикс:**
- **7** — увеличенный радиальный зазор (C3, +30%)
- **5** — класс точности 5 (высокая точность)

**Основное:**
- **6** — шариковый радиальный однорядный
- **2** — лёгкая серия (D = 52 мм)
- **0** — нормальная ширина (B = 15 мм)
- **05** — d = 25 мм

**Суффикс:**
- **2RS** — два резиновых контактных уплотнения (герметичный, необслуживаемый)
- **Е** — сепаратор из текстолита (высокая скорость, антифрикционный)
- **Ш2** — специальные требования по уровню шума и вибрации (для электродвигателей)

**Результат:**
> Высокоточный (класс 5) шариковый радиальный подшипник d = 25 мм с увеличенным зазором (C3), герметичный (два резиновых уплотнения), текстолитовый сепаратор, специальные требования по шуму для электродвигателей.

**Применение:**
- Высокоскоростные электродвигатели
- Влажная/пыльная среда
- Повышенный нагрев внутреннего кольца
- Требования к низкому уровню шума

**Эксплуатационные характеристики:**
- Скорость: высокая (класс 5 + текстолит)
- Температура: до +110°C (NBR уплотнения)
- Зазор: увеличенный (компенсирует нагрев и натяг)
- Обслуживание: не требуется (герметичный)
- Шум: пониженный (Ш2)

#### Пример 5.2: **6У-7520А-Б**

**Дано:** **6У-7520А-Б**

**Разборка:**

```
6У - 7520А - Б
│     │      └── Бронзовый сепаратор
│     └───────── Основное + модификация А
└─────────────── Класс точности 6 + повышенная точность по высоте
```

**Префикс:**
- **6** — класс точности 6 (повышенная)
- **У** — повышенная точность по монтажной высоте (только для конических роликовых)

**Основное:**
- **7** — роликовый конический
- **5** — серия диаметров (тяжёлая)
- **2** — серия ширины (широкая)
- **20** — d = 100 мм

**Суффикс:**
- **А** — модифицированная конструкция (изменённый угол контакта)
- **Б** — сепаратор из бронзы (механически обработанный, массивный)

**Результат:**
> Роликовый конический подшипник d = 100 мм, тяжёлая широкая серия, **класс точности 6**, **повышенная точность по монтажной высоте**, **модифицированный угол контакта**, **бронзовый массивный сепаратор**.

**Применение:**
- Прецизионные станочные шпиндели
- Редукторы с высокими нагрузками
- Узлы с точными требованиями к монтажным размерам

**Суффикс:**

> Шариковый радиально-упорный подшипник d = 40 мм, **класс точности 5**, **ограниченный момент трения**, **коническое отверстие**, **бронзовый сепаратор**.

**Применение:**
- Прецизионные шпиндели

### Уровень 6: Специальные типы

#### Пример 6.1: **36205** (радиально-упорный)

**Дано:** **36205**

**Основное:**
- **36** — шариковый радиально-упорный однорядный
- **2** — лёгкая серия
- **05** — d = 25 мм

**Угол контакта:**
- **36ХХХ** → α = 12° (малый угол, преимущественно радиальная нагрузка)
- **46ХХХ** → α = 26° (средний угол, комбинированная нагрузка)
- **66ХХХ** → α = 45° (большой угол, значительная осевая нагрузка)

**Результат:**
> Шариковый радиально-упорный однорядный подшипник d = 25 мм, угол контакта α = 12°.

**Применение:**
- Установка парами (дуплекс, триплекс)
- Восприятие радиальных и осевых нагрузок
- Шпиндели станков

---

#### Пример 6.2: **7208** (конический роликовый)

**Дано:** **7208**

**Основное:**
- **7** — роликовый конический
- **2** — лёгкая серия
- **08** — d = 40 мм

**Особенности конических подшипников:**
- Состоят из **двух комплектов** (внутренний + наружный)
- Продаются отдельно или комплектом
- Обозначение комплекта: **7208К**

**Маркировка комплектов:**
- **7208А** — внутренний комплект (конус + ролики + сепаратор)
- **7208В** — наружное кольцо (чашка)

**Результат:**
> Роликовый конический подшипник d = 40 мм, лёгкая серия.

**Применение:**
- Автомобильные ступицы
- Редукторы
- Узлы с комбинированными нагрузками

---

#### Пример 6.3: **4074115** (игольчатый)

**Дано:** **4074115**

**Разборка:**
```
4 07 41 15
│ │  │  └── Ширина B = 15 мм
│ │  └───── Наружный диаметр D = 41 мм
│ └──────── Тип конструкции (07 — с наружным кольцом)
└────────── Игольчатый подшипник
```

**Основное:**
- **4** — роликовый игольчатый
- **07** — тип конструкции (с наружным кольцом, без внутреннего)
- **41** — D = 41 мм
- **15** — B = 15 мм

**Типы игольчатых подшипников:**
- **404** — только иголки с сепаратором (без колец)
- **407** — с наружным кольцом
- **408** — с наружным и внутренним кольцами

**Результат:**
> Игольчатый подшипник с наружным кольцом, D = 41 мм, B = 15 мм.

**Применение:**
- Узлы с ограниченным радиальным пространством
- Трансмиссии, шарниры, поршневые пальцы

### Типичные ошибки при расшифровке

#### Ошибка 1: Неправильное определение диаметра

**Неправильно:**
- **6205** → d = 5 мм ❌

**Правильно:**
- **6205** → код **05** → d = 05 × 5 = **25 мм** ✅

---

#### Ошибка 2: Путаница в порядке префикса

**Неправильно:**
- **5-7-6205** → класс 5, зазор 7 ❌

**Правильно:**
- **7-5-6205** → зазор 7, класс 5 ✅

**Правило:** Зазор всегда **впереди** класса точности.

---

#### Ошибка 3: Интерпретация типа подшипника

**Неправильно:**
- **305** → тип **3** (роликовый сферический) ❌

**Правильно:**
- **305** = **0305** → тип **0** (шариковый радиальный) ✅

**Правило:** Ноль в начале опускается, но учитывается при расшифровке.

---

#### Ошибка 4: Путаница Z и RS

**Неправильно:**
- **6205-Z** → резиновое уплотнение ❌

**Правильно:**
- **6205-Z** → **защитное кольцо** (стальное, бесконтактное) ✅
- **6205-RS** → **резиновое уплотнение** (контактное) ✅

---

### Алгоритм быстрой расшифровки

**Для опытных пользователей:**

```
1. Найти дефисы → разделить на части
2. Последние 2 цифры × 5 → диаметр d
3. Третья цифра справа → серия D
4. Первые 1-2 цифры → тип подшипника
5. Перед основным (через дефис) → класс точности и зазор
6. После основного (через дефис) → уплотнения, материалы
```

**Пример:** **7-5-6205-2RS-Е**
```
1. Дефисы: 7-5 | 6205 | 2RS-Е
2. 05 → d = 25 мм
3. 2 → лёгкая серия
4. 6 → шариковый радиальный
5. 7 = C3, 5 = класс 5
6. 2RS = герметичный, Е = текстолит
```
**Итог:** Высокоточный (P5) шариковый d=25мм, зазор C3, герметичный, текстолитовый сепаратор.

## 🚀 Как использовать

### Для обучения
1. Начните с [Вводного курса](<Вводный_курс_для_новичков/README.md>)
2. Изучите теорию в [Part I](part-i/README.md) и [Part II](part-ii/README.md)
3. Практикуйтесь с [Учебником](<Учебник/README.md>)
4. Проверяйте знания в [Тестах](<Тесты/README.md>)

### Для справки
1. Используйте [Инструменты и справочники](<Инструменты_и_справочники/README.md>)
2. Ищите информацию в [Каталогах](<Каталоги/README.md>)
3. Консультируйтесь с [Part III](part-iii/README.md) по стандартам
4. Проверяйте [Номенклатуру](<номенклатура/README.md>)

### Для работы
1. Читайте [Практические руководства](<Практические_руководства/README.md>)
2. Используйте [Part IV](part-iv/README.md) для сопутствующих изделий
3. Обращайтесь к [Приложениям](appendix/README.md) за справочными данными

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ArtemFilin1990/BearingsInfo.git
   cd BearingsInfo
   ```

2. **Начните с вводного курса:**  
   Ознакомьтесь с **[Вводным курсом для новичков](Вводный_курс_для_новичков/)** для понимания основ

3. **Используйте навигацию:**  
   Используйте **[Карты знаний](Карты_знаний_и_навигация/)** для поиска нужной информации

4. **Изучите стандарты:**  
   Раздел **[Стандарты и маркировка](#2-стандарты-и-маркировка-ядро-справочника)** — ключевой для понимания обозначений

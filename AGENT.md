# AI Agent Instructions

Этот файл содержит инструкции для AI-агентов, работающих с репозиторием BearingsInfo.

## Назначение репозитория

База знаний о подшипниках: классификация, обозначения, аналоги, бренды, стандарты.

## Структура

- `data/` — структурированные данные (CSV)
- `docs/bearings/` — документация по подшипникам
- `sources/` — исходные данные и скрипты парсинга
- `scripts/` — утилиты для обработки данных

## Правила работы

1. Следовать с��руктуре директорий, определенной в `.github/workflows/ci.yml`
2. Все технические документы должны содержать ссылки на источники (ГОСТ, ISO, DIN)
3. Использовать скрипт `scripts/update_repo.py` для нормализации данных
4. Избегать дубликатов в `data/nomenclature.csv` (проверка по паре Brand + Product Name)
5. Валидировать изменения через `scripts/validate/run_validations.py`

## Технические требования

- Python 3.11+
- Кодировка UTF-8 для всех текстовых файлов
- Относительные ссылки в Markdown

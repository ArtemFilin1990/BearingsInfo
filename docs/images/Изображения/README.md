## 📄 Форматы файлов

Поддерживаемые форматы изображений:

| Формат | Использование | Описание |
|--------|---------------|----------|
| **JPG/JPEG** | 📷 Фотографии | Фотографии подшипников, оборудования, дефектов |
| **PNG** | 📐 Схемы | Схемы, диаграммы, логотипы с прозрачностью |
| **GIF** | 🎬 Анимация | Анимированные схемы (при наличии) |

### Соглашения об именовании

Файлы именуются по схеме:
```
[номер_статьи]_[описание].[расширение]
```

**Примеры:**
- `1_osnovye_razmery_podshipnika.jpg` - основные размеры подшипника
- `23_konstr_bearing_2306.jpg` - конструкция подшипника 2306
- `102_oil_seal_11.jpg` - сальник (изображение 11)

### Ссылки на изображения

В документах Markdown используется синтаксис:

```markdown
![Описание изображения](<../Изображения/название_файла.jpg>)
```

**Пример:**
```markdown
![Основные размеры подшипника](<../Изображения/1_osnovye_razmery_podshipnika.jpg>)
```

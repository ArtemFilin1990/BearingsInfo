# 5.5. Диагностика в эксплуатации

## Назначение

Раздел описывает методы и средства диагностики технического состояния подшипников в процессе эксплуатации оборудования без разборки узлов. Цель — раннее выявление дефектов, прогнозирование остаточного ресурса и предотвращение аварийных отказов.

## Ключевые вопросы

- Какие методы диагностики подшипников существуют?
- Как интерпретировать показания вибрации, температуры, шума?
- Когда необходимо проводить диагностику?
- Какое оборудование используется для диагностики?
- Как определить тип и стадию дефекта по диагностическим признакам?
- Как оценить остаточный ресурс подшипника?

## Содержание

### 1. Основные методы диагностики

#### 1.1. Вибрационная диагностика

**Принцип:**  
Подшипники генерируют характерные вибрационные сигналы, меняющиеся при появлении дефектов. Анализ вибрации позволяет выявить повреждения на ранних стадиях.

**Измеряемые параметры:**
- **Виброскорость (RMS):** общий уровень вибрации, мм/с
- **Виброускорение:** высокочастотные компоненты, м/с² или g
- **Виброперемещение:** низкочастотная вибрация, мкм
- **Спектр вибрации:** частотный анализ сигнала
- **Огибающая спектра (envelope):** детектирование ударных импульсов
- **Пик-фактор (Crest Factor):** отношение пикового значения к RMS

**Контролируемые частоты:**
- **BPFO (Ball Pass Frequency Outer):** дефекты наружного кольца
- **BPFI (Ball Pass Frequency Inner):** дефекты внутреннего кольца
- **BSF (Ball Spin Frequency):** дефекты тел качения
- **FTF (Fundamental Train Frequency):** дефекты сепаратора

**Формулы для расчета характерных частот:**

```
BPFO = (n/2) × (1 - (Bd/Pd) × cos α) × fr
BPFI = (n/2) × (1 + (Bd/Pd) × cos α) × fr
BSF = (Pd/2Bd) × (1 - (Bd/Pd)² × cos² α) × fr
FTF = (1/2) × (1 - (Bd/Pd) × cos α) × fr
```

где:
- n — число тел качения
- Bd — диаметр тела качения
- Pd — диаметр центров тел качения
- α — угол контакта
- fr — частота вращения вала

**Оборудование:**
- Виброметры (SKF CMVA, Fluke 805, Pruftechnik)
- Анализаторы вибрации (SKF Microlog, CSI 2140)
- Стационарные системы мониторинга (Bently Nevada, SKF IMx)
- Датчики вибрации (акселерометры, виброскоростные)

#### 1.2. Температурная диагностика

**Принцип:**  
Повышение температуры подшипника указывает на возрастание трения, недостаток смазки или перегрузку.

**Измерение температуры:**
- **Контактные датчики:** термопары, термосопротивления (Pt100, Pt1000)
- **Бесконтактные:** инфракрасные пирометры
- **Тепловизоры:** для распределения температуры по корпусу

**Нормативные значения:**
- **Норма:** температура корпуса на 20-40°C выше окружающей среды
- **Допустимо:** до 60-70°C выше окружающей среды
- **Критично:** более 80°C выше окружающей среды
- **Аварийно:** абсолютная температура более 120-130°C (для обычных подшипников)

**Причины перегрева:**
- Недостаток смазки или ее избыток
- Загрязнение смазки
- Повышенная нагрузка
- Несоосность валов
- Слишком большой натяг при посадке
- Дефекты дорожек качения

#### 1.3. Акустическая диагностика (шумовая)

**Принцип:**  
Подшипники излучают характерный шум, изменяющийся при появлении дефектов.

**Методы:**
- **Субъективная оценка:** опытный механик определяет изменения на слух
- **Стетоскоп механический:** прослушивание через стержень
- **Электронный стетоскоп:** с усилением и фильтрацией
- **Ультразвуковая диагностика:** детектирование высокочастотного шума (20-100 кГц)

**Характеристики шума:**

| Состояние | Описание шума |
|-----------|---------------|
| Исправный | Равномерный тихий шелест |
| Недостаток смазки | Шипящий, скребущий звук |
| Износ | Постоянный шум, увеличивающийся со временем |
| Точечный дефект | Периодические щелчки, стуки |
| Отслоение | Рокот, грохот |
| Загрязнение | Хруст, скрежет |

**Оборудование:**
- Ультразвуковые детекторы (UE Systems Ultraprobe, SDT Ultrasound)
- Электронные стетоскопы
- Шумомеры

#### 1.4. Масляная диагностика (триботехническая)

**Принцип:**  
Анализ смазочного материала и частиц износа в нем позволяет выявить развивающиеся дефекты.

**Методы анализа:**
- **Спектральный анализ:** определение химического состава частиц износа
- **Ферромагнитный анализ:** подсчет и размер металлических частиц
- **Подсчет частиц:** гранулометрический анализ
- **Анализ формы частиц:** микроскопия (срезы, усталость, истирание)
- **Определение воды в масле:** метод Карла Фишера
- **Класс чистоты:** по ISO 4406 или NAS 1638

**Периодичность отбора проб:**
- Обкатка нового оборудования: каждые 100-200 часов
- Нормальная эксплуатация: каждые 500-1000 часов
- При появлении симптомов: внеочередной отбор

**Критерии:**
- Норма: единичные частицы размером < 10 мкм
- Внимание: частицы 10-50 мкм в количестве > 100 на 1 мл
- Критично: частицы > 50 мкм, блестящие пластинки (усталостное выкрашивание)

#### 1.5. Измерение осевого зазора

**Принцип:**  
Увеличение осевого зазора указывает на износ дорожек качения и тел качения.

**Методы:**
- Щуповой: измерение щупами
- Индикаторный: с использованием индикатора часового типа
- Измерение осевого смещения при нагружении

**Нормативы:**
- Новый подшипник: зазор согласно группе (C2, CN, C3, C4)
- Допустимый износ: увеличение зазора до 30-50%
- Критический износ: увеличение более чем в 2 раза

#### 1.6. Измерение электрического сопротивления

**Принцип:**  
При нормальной работе подшипник изолирован масляной пленкой (высокое сопротивление). Падение сопротивления указывает на разрушение масляной пленки.

**Применение:**
- Контроль состояния смазки
- Выявление металлического контакта (задиры)
- Диагностика электроэрозии

**Оборудование:**
- Мегаомметры
- Специализированные приборы (SKF TKED 1)

### 3. Стратегии диагностики

#### 3.1. Периодический контроль

**Применение:** стандартное оборудование без критических последствий отказа

**Периодичность:**
- Ежесменно: визуальный осмотр, контроль температуры (рукой или пирометром)
- Еженедельно: вибрация (портативным виброметром)
- Ежемесячно: полная вибродиагностика (спектральный анализ)
- Ежеквартально: анализ масла (при наличии маслосистемы)

**Документация:**
- Журнал обхода оборудования
- Тренды вибрации
- Протоколы анализа масла

#### 3.2. Постоянный мониторинг

**Применение:** критическое оборудование, высокие последствия отказа

**Реализация:**
- Стационарные датчики вибрации и температуры
- Автоматическая передача данных в систему мониторинга
- Автоматическая сигнализация при превышении порогов
- Непрерывная запись трендов

**Системы:**
- SKF IMx, Enlight
- Emerson AMS Suite
- Bently Nevada System 1
- Brüel & Kjær Vibro

#### 3.3. Диагностика по состоянию (CBM)

**Принцип:** техническое обслуживание и замена выполняются на основе фактического состояния, а не по регламенту.

**Преимущества:**
- Продление срока службы исправных подшипников
- Предотвращение внезапных отказов
- Оптимизация затрат на ТОиР

**Этапы:**
1. Установление базовых значений (новое оборудование)
2. Периодический контроль параметров
3. Сравнение с базовыми и нормативными значениями
4. Принятие решения о продолжении эксплуатации или замене

### 4. Диагностика типовых дефектов

#### 4.1. Недостаточная смазка

**Признаки:**
- Повышение температуры на 10-20°C
- Рост высокочастотной вибрации
- Шипящий звук
- Изменение цвета масла (потемнение)

**Действия:**
- Проверить уровень смазки
- Добавить смазку (для подшипников с возможностью дополнительной смазки)
- Заменить смазку при загрязнении
- Проверить систему смазки

#### 4.2. Несоосность (перекос)

**Признаки:**
- Повышенная вибрация на частоте 1× и 2× оборотной
- Осевая вибрация
- Неравномерный нагрев подшипников на противоположных концах вала
- Характерный рокот

**Действия:**
- Проверить центровку валов (лазерный центровщик)
- Проверить перпендикулярность торца к оси вала
- Откорректировать центровку

#### 4.3. Дисбаланс ротора

**Признаки:**
- Вибрация на частоте 1× оборотной (синхронная)
- Преобладает радиальная вибрация
- Может меняться при изменении скорости

**Действия:**
- Балансировка ротора
- Проверка крепления деталей на валу

#### 4.4. Дефекты дорожек качения

**Признаки:**
- Периодические импульсы на частотах BPFO или BPFI
- Увеличение пик-фактора
- Щелчки при вращении
- Локальный перегрев

**Действия:**
- Планирование замены подшипника
- Усиленный контроль

#### 4.5. Дефекты тел качения

**Признаки:**
- Импульсы на частоте BSF
- Шум при вращении
- Увеличение температуры

**Действия:**
- Замена подшипника в ближайшее ТО

#### 4.6. Дефекты сепаратора

**Признаки:**
- Нестабильная вибрация на частоте FTF и гармониках
- Металлический стук
- Неравномерный шум

**Действия:**
- Срочная замена (высокий риск разрушения)

### 5. Прогнозирование остаточного ресурса

#### 5.1. Стадии деградации подшипника

**Стадия 1 - Нормальная работа (90-95% ресурса):**
- Стабильная вибрация
- Нормальная температура
- Равномерный шум

**Стадия 2 - Начало дефектообразования (95-98% ресурса):**
- Появление импульсов на характерных частотах
- Небольшое повышение высокочастотной вибрации
- Остаточный ресурс: несколько месяцев

**Стадия 3 - Развитие дефекта (98-99.5% ресурса):**
- Рост амплитуд на характерных частотах
- Повышение общей вибрации
- Появление шума
- Остаточный ресурс: недели

**Стадия 4 - Критическое состояние (> 99.5% ресурса):**
- Резкое увеличение вибрации
- Значительный перегрев
- Громкий шум, стуки
- Остаточный ресурс: дни/часы

**Стадия 5 - Катастрофический отказ:**
- Разрушение подшипника
- Возможное повреждение смежных узлов

#### 5.2. Методы прогнозирования

**Трендовый анализ:**
- Построение графиков изменения параметров во времени
- Экстраполяция тренда до порогового значения
- Оценка времени до необходимости замены

**Анализ скорости деградации:**
- Измерение темпа роста вибрации (dB/месяц)
- Быстрый рост (> 6 dB/месяц) — ускоренная деградация
- Медленный рост (< 3 dB/месяц) — нормальное старение

**P-F интервал (Potential failure to Functional failure):**
- Время от обнаружения потенциального дефекта до функционального отказа
- Для подшипников обычно составляет от 2 недель до 6 месяцев

### 6. Практические рекомендации

#### 6.1. Чек-лист ежедневного обхода

- [ ] Визуальный осмотр (отсутствие течей смазки, загрязнений)
- [ ] Проверка температуры рукой (для малонагруженных узлов) или пирометром
- [ ] Прослушивание шума (есть ли посторонние звуки)
- [ ] Проверка вибрации рукой на корпусе (для крупного оборудования)
- [ ] Запись аномалий в журнал обхода
- [ ] Сравнение с предыдущими показаниями

#### 6.2. Чек-лист вибродиагностики (еженедельно/ежемесячно)

- [ ] Подготовка оборудования (стабильный режим работы, прогрев)
- [ ] Установка датчика в стандартной точке замера
- [ ] Измерение виброскорости (RMS)
- [ ] Измерение виброускорения (для высокочастотных дефектов)
- [ ] Снятие спектра вибрации
- [ ] Снятие спектра огибающей (envelope)
- [ ] Анализ характерных частот (BPFO, BPFI, BSF, FTF)
- [ ] Расчет пик-фактора
- [ ] Сравнение с базовыми значениями и нормами
- [ ] Запись в базу данных, построение трендов
- [ ] Оценка состояния и прогноз
- [ ] Рекомендации по дальнейшей эксплуатации

#### 6.3. Чек-лист тепловизионного обследования

- [ ] Проверка эмиссионной способности поверхности (обычно ε = 0.85-0.95)
- [ ] Съемка в установившемся тепловом режиме
- [ ] Фиксация температуры окружающей среды
- [ ] Съемка всех подшипников узла для сравнения
- [ ] Анализ распределения температуры (горячие точки)
- [ ] Сравнение температур симметричных подшипников
- [ ] Запись термограмм с привязкой к оборудованию
- [ ] Выявление перегретых подшипников
- [ ] Планирование корректирующих действий

### 8. Обучение и квалификация

**Уровни квалификации вибродиагностов (ISO 18436):**

- **Категория I:** техник по мониторингу (сбор данных)
- **Категория II:** аналитик (анализ данных, выявление дефектов)
- **Категория III:** диагност-эксперт (сложная диагностика, прогнозирование)
- **Категория IV:** специалист высшей квалификации (разработка программ диагностики)

**Сертификация:**
- ISO 18436-2 (Vibration analysis)
- ISO 18436-3 (Intrusive methods)
- ISO 18436-4 (Field lubricant analysis)

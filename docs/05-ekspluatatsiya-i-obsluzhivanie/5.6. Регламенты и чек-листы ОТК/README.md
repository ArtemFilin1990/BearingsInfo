# 5.6. Регламенты и чек-листы ОТК

## Назначение

Раздел содержит регламенты, процедуры и чек-листы для входного контроля качества (ОТК) подшипников, периодического контроля в процессе эксплуатации и контроля перед монтажом. Обеспечивает единообразие проверок и документирование результатов.

## Ключевые вопросы

- Какие проверки необходимо проводить при входном контроле подшипников?
- Какие инструменты и оборудование требуются для контроля?
- Как документировать результаты контроля?
- Какие критерии приемки и браковки подшипников?
- Как организовать систему периодического контроля в эксплуатации?
- Какие требования к квалификации контролеров?

## Содержание

### 1. Входной контроль подшипников

#### 1.1. Цели входного контроля

- Проверка соответствия полученных подшипников заказу
- Выявление дефектов, полученных при транспортировке
- Проверка качества консервации и упаковки
- Документирование состояния для последующих рекламаций
- Предотвращение установки дефектных подшипников

#### 1.2. Этапы входного контроля

**Этап 1: Приемка партии**
- Проверка целостности транспортной упаковки
- Проверка комплектности поставки
- Сверка с товарно-сопроводительными документами
- Проверка наличия сертификатов качества

**Этап 2: Визуальный контроль упаковки**
- Отсутствие повреждений индивидуальной упаковки
- Соответствие маркировки на упаковке
- Проверка сроков годности консервации
- Отсутствие следов влаги, коррозии снаружи

**Этап 3: Выборочный контроль**
- Вскрытие выборки подшипников (обычно 5-10% партии, но не менее 3 шт.)
- Визуальный осмотр подшипников
- Измерительный контроль (при необходимости)
- Проверка качества смазки (для закрытых подшипников)

**Этап 4: Документирование**
- Оформление акта входного контроля
- Внесение данных в журнал учета
- Присвоение статуса партии (принято/условно принято/отклонено)
- Размещение на складе или оформление рекламации

### 2. Чек-лист входного контроля подшипников

#### 2.1. Проверка документации

**Чек-лист: Документы**

- [ ] Товарная накладная / упаковочный лист
- [ ] Счет-фактура
- [ ] Сертификат качества производителя (при требовании)
- [ ] Паспорт изделия (для крупногабаритных подшипников)
- [ ] Таможенная декларация (для импортных подшипников)
- [ ] Соответствие количества в документах фактическому количеству
- [ ] Соответствие типоразмеров подшипников заказу
- [ ] Наличие штампов и подписей на документах

**Критерии:**
- ✓ Все документы в наличии и корректны → переход к проверке упаковки
- ✗ Отсутствуют обязательные документы → оформление рекламации, приемка на ответственное хранение

#### 2.2. Проверка транспортной упаковки

**Чек-лист: Транспортная упаковка**

- [ ] Целостность ящиков, коробок, контейнеров
- [ ] Отсутствие следов вскрытия упаковки
- [ ] Отсутствие вмятин, проколов, разрывов
- [ ] Отсутствие следов воздействия влаги (промокания, ржавчины)
- [ ] Наличие маркировки на упаковке (тип подшипника, количество, вес)
- [ ] Соответствие маркировки транспортным документам
- [ ] Наличие манипуляционных знаков ("Хрупкое", "Верх", "Беречь от влаги")
- [ ] Отсутствие просыпавшихся частей, посторонних звуков при перемещении

**Критерии:**
- ✓ Упаковка в хорошем состоянии → продолжение контроля
- ⚠ Незначительные повреждения упаковки → отметка в акте, усиленный выборочный контроль
- ✗ Серьезные повреждения → полный контроль партии, фото-фиксация, акт о скрытых дефектах

#### 2.3. Проверка индивидуальной упаковки

**Чек-лист: Индивидуальная упаковка**

- [ ] Целостность индивидуальной упаковки (бумага, полиэтилен, коробка)
- [ ] Наличие маркировки на упаковке (обозначение подшипника)
- [ ] Соответствие маркировки заказу
- [ ] Отсутствие следов коррозии, влаги на упаковке
- [ ] Наличие влагопоглотителя (для длительного хранения)
- [ ] Состояние влагопоглотителя (не насыщен влагой)
- [ ] Отсутствие посторонних запахов (гниение, химикаты)

**Критерии:**
- ✓ Индивидуальная упаковка соответствует требованиям
- ⚠ Незначительные отклонения → отметка, продолжение контроля
- ✗ Нарушена герметичность, следы влаги → вскрытие и проверка состояния подшипника

#### 2.4. Визуальный осмотр подшипника

**Чек-лист: Внешний вид**

- [ ] Отсутствие коррозии на рабочих поверхностях
- [ ] Отсутствие вмятин, забоин на дорожках качения
- [ ] Отсутствие трещин на кольцах
- [ ] Отсутствие царапин, задиров на рабочих поверхностях
- [ ] Целостность сепаратора (нет деформаций, поломок перемычек)
- [ ] Отсутствие вмятин на телах качения
- [ ] Правильность маркировки на кольце подшипника
- [ ] Наличие консервационной смазки (для открытых подшипников)
- [ ] Состояние консервационной смазки (не засохла, не окислилась)
- [ ] Целостность уплотнений (для закрытых подшипников)
- [ ] Отсутствие загрязнений внутри подшипника

**Критерии приемки:**
- ✓ Все пункты соответствуют → подшипник годен
- ⚠ Незначительные косметические дефекты на нерабочих поверхностях → условно годен (использовать в неответственных узлах)
- ✗ Дефекты рабочих поверхностей → брак, не использовать

#### 2.5. Проверка легкости вращения

**Чек-лист: Вращение**

- [ ] Подшипник вращается от руки плавно, без заеданий
- [ ] Отсутствуют стуки, щелчки при медленном вращении
- [ ] Отсутствуют участки повышенного сопротивления
- [ ] Вращение равномерное по всему периметру
- [ ] Отсутствуют посторонние шумы (хруст, скрежет)
- [ ] При вращении нет осевого люфта (сверх нормы)
- [ ] Не заклинивает при легком осевом нагружении

**Методика:**
1. Взять подшипник в руки (в чистых перчатках)
2. Медленно провернуть внутреннее кольцо относительно наружного
3. Прислушаться к шуму и почувствовать равномерность вращения
4. При необходимости промыть керосином и повторить проверку

**Критерии:**
- ✓ Вращение плавное, бесшумное → норма
- ⚠ Незначительное неравномерное сопротивление → допустимо (может быть из-за густой консервации)
- ✗ Заедания, стуки, хруст → брак

#### 2.6. Измерительный контроль (выборочно)

**Чек-лист: Размеры и зазоры**

- [ ] Внутренний диаметр (d) соответствует обозначению ± допуск
- [ ] Наружный диаметр (D) соответствует обозначению ± допуск
- [ ] Ширина (B или C) соответствует обозначению ± допуск
- [ ] Радиальный зазор соответствует группе (C2, CN, C3, C4)
- [ ] Торцовое биение не превышает допустимые значения
- [ ] Радиальное биение не превышает допустимые значения
- [ ] Шероховатость дорожек качения в норме (визуально)

**Оборудование:**
- Штангенциркуль или микрометр
- Индикатор часового типа на стойке
- Щупы для измерения зазора
- Специальные приспособления (при необходимости)

**Нормативы:**
- Допуски по ГОСТ 520-2011 или ISO 492:2014
- Группы радиального зазора по ГОСТ 24810 или ISO 5753-1

**Критерии:**
- ✓ Размеры в пределах допусков → соответствует
- ✗ Отклонения сверх допусков → несоответствие, возврат партии

### 3. Контроль перед монтажом

#### 3.1. Чек-лист предмонтажной подготовки

**Проверка подшипника:**

- [ ] Срок консервации не истек
- [ ] Упаковка не нарушена до момента монтажа
- [ ] Подшипник соответствует проектному обозначению
- [ ] Группа радиального зазора соответствует требованиям (при необходимости)
- [ ] Класс точности соответствует требованиям
- [ ] Сертификат качества в наличии (если требуется)

**Проверка сопряженных деталей:**

- [ ] Вал и корпус очищены от загрязнений, заусенцев
- [ ] Посадочные поверхности без коррозии, задиров
- [ ] Диаметр вала соответствует чертежу (измерен)
- [ ] Диаметр отверстия корпуса соответствует чертежу (измерен)
- [ ] Шероховатость посадочных поверхностей в норме
- [ ] Торцы заплечиков перпендикулярны оси
- [ ] Радиусы галтелей не превышают фасок подшипника
- [ ] Резьбовые отверстия для съемников не заглушены
- [ ] Смазка подготовлена (тип, количество)
- [ ] Инструмент и приспособления для монтажа готовы

**Проверка условий монтажа:**

- [ ] Чистое помещение (минимум пыли)
- [ ] Температура окружающей среды +15...+25°C
- [ ] Наличие чистой ветоши, растворителя
- [ ] Наличие защитных перчаток
- [ ] Наличие индикатора или щупов для контроля
- [ ] Наличие средств нагрева (при необходимости)
- [ ] Наличие пресса или оправок для запрессовки

### 4. Периодический контроль в эксплуатации

#### 4.1. Чек-лист ежесменного обхода

**Оборудование:** фонарик, пирометр (опционально), блокнот

- [ ] Визуальный осмотр узла (нет утечек смазки, загрязнений)
- [ ] Проверка температуры рукой или пирометром
- [ ] Прослушивание шума (нет посторонних звуков)
- [ ] Ощущение вибрации рукой на корпусе
- [ ] Отсутствие запаха перегрева
- [ ] Отсутствие цветов побежалости на корпусе
- [ ] Запись результатов в журнал обхода
- [ ] Сообщение о выявленных аномалиях

**Критерии реакции:**
- ✓ Все параметры в норме → продолжение эксплуатации
- ⚠ Небольшое отклонение (температура +5...10°C, незначительный шум) → усилить контроль, внеплановая вибродиагностика
- ✗ Серьезное отклонение (перегрев > 20°C, сильный шум) → остановка, ревизия

#### 4.2. Чек-лист еженедельной проверки

**Оборудование:** портативный виброметр, пирометр, стетоскоп

- [ ] Измерение виброскорости (RMS) в стандартных точках
- [ ] Измерение температуры подшипника
- [ ] Прослушивание электронным стетоскопом или ультразвуковым детектором
- [ ] Проверка крепления корпуса, фундамента
- [ ] Проверка центровки (визуально, при наличии признаков)
- [ ] Проверка уровня смазки (для узлов с масляной ванной)
- [ ] Сравнение с предыдущими измерениями
- [ ] Построение трендов (если ведется база данных)
- [ ] Запись в журнал вибродиагностики

**Пороговые значения** (для машин класса II по ISO 10816-3):
- Виброскорость < 2.8 мм/с → норма
- Виброскорость 2.8-7.1 мм/с → допустимо, контроль
- Виброскорость > 7.1 мм/с → критично, планировать ремонт

#### 4.3. Чек-лист ежемесячной диагностики

**Оборудование:** анализатор вибрации, тепловизор, маслопробоотборник (при наличии маслосистемы)

- [ ] Полная вибродиагностика со спектральным анализом
- [ ] Анализ спектра огибающей (envelope)
- [ ] Расчет пик-фактора (Crest Factor)
- [ ] Тепловизионная съемка узла
- [ ] Отбор пробы масла (если применимо)
- [ ] Проверка центровки валов (лазерным центровщиком при подозрении на несоосность)
- [ ] Проверка балансировки (при наличии признаков дисбаланса)
- [ ] Анализ характерных частот (BPFO, BPFI, BSF, FTF)
- [ ] Сравнение с базовыми и предыдущими измерениями
- [ ] Оценка остаточного ресурса
- [ ] Оформление протокола диагностики
- [ ] Рекомендации по эксплуатации или ремонту

#### 4.4. Чек-лист перед плановым ремонтом

**Осмотр и демонтаж:**

- [ ] Финальные измерения вибрации и температуры
- [ ] Фиксация состояния узла (фото, видео)
- [ ] Маркировка взаимного положения деталей
- [ ] Аккуратный демонтаж с использованием съемников
- [ ] Недопущение ударов по подшипнику при демонтаже

**Осмотр после демонтажа:**

- [ ] Промывка подшипника в керосине
- [ ] Сушка сжатым воздухом
- [ ] Визуальный осмотр всех элементов
- [ ] Фотофиксация дефектов (при наличии)
- [ ] Проверка вращения (плавность, шум)
- [ ] Измерение радиального зазора
- [ ] Сравнение зазора с новым подшипником
- [ ] Заключение о причине износа/повреждения
- [ ] Оформление дефектной ведомости
- [ ] Решение о повторном использовании или замене

**Критерии повторного использования:**
- ✓ Незначительный равномерный износ, зазор увеличен < 30% → можно использовать в менее нагруженных узлах
- ⚠ Износ 30-50%, начальные дефекты → использовать только после экспертной оценки
- ✗ Износ > 50%, точечные дефекты, трещины, коррозия → обязательная замена

### 6. Требования к персоналу

#### 6.1. Квалификация контролеров ОТК

**Контролер входного контроля:**
- Знание обозначений подшипников по ГОСТ и ISO
- Умение читать технические чертежи
- Навыки работы с измерительным инструментом
- Знание критериев приемки и браковки
- Опыт работы не менее 6 месяцев

**Специалист по вибродиагностике:**
- Сертификация по ISO 18436-2 (категория II или выше)
- Знание методов вибрационной диагностики
- Умение работать с приборами вибродиагностики
- Навыки интерпретации спектров вибрации
- Знание конструкций подшипников и типовых дефектов
- Опыт работы не менее 1 года

#### 6.2. Обучение и аттестация

**Программа обучения контролеров:**
1. Конструкции подшипников (теория)
2. Маркировка и обозначения подшипников
3. Дефекты подшипников и причины их возникновения
4. Методы контроля качества
5. Работа с измерительным инструментом (практика)
6. Оформление документации
7. Итоговая аттестация (тест + практический экзамен)

**Периодичность аттестации:** каждые 3 года

### 7. Оборудование для контроля качества

#### 7.1. Минимальный набор для ОТК

**Для входного контроля:**
- Штангенциркуль ЦифРовой (точность 0.01 мм)
- Микрометр (для точных измерений)
- Набор щупов
- Лупа 10×
- Чистая ветошь, перчатки
- Фонарик
- Этикет-пистолет (для маркировки)

**Для периодического контроля:**
- Портативный виброметр (SKF CMVA, Fluke 805 или аналог)
- Инфракрасный пирометр
- Электронный стетоскоп или ультразвуковой детектор
- Маслопробоотборник (при наличии маслосистем)

**Для углубленной диагностики:**
- Анализатор вибрации (SKF Microlog, CSI 2140 или аналог)
- Тепловизор
- Лазерный центровщик валов
- Прибор для анализа масла (экспресс-анализ)

#### 7.2. Калибровка и поверка

- **Измерительный инструмент:** поверка ежегодно в метрологической службе
- **Виброметры:** калибровка ежегодно с использованием калибратора
- **Пирометры:** поверка ежегодно
- **Тепловизоры:** калибровка согласно инструкции производителя

### 8. Практические рекомендации

#### 8.1. Частые ошибки при контроле

**❌ Ошибки:**
- Вскрытие всех подшипников партии (нарушение консервации)
- Проверка вращения с засохшей консервацией (ошибочная оценка)
- Использование грязного инструмента
- Контроль в неподходящих условиях (холод, пыль)
- Отсутствие документирования результатов
- Субъективная оценка без измерений

**✅ Правильно:**
- Выборочный контроль согласно плану
- Расконсервация перед проверкой вращения
- Чистые перчатки и инструмент
- Контроль в чистом помещении при комнатной температуре
- Строгое документирование всех результатов
- Измерения и сравнение с нормативами

#### 8.2. Организация системы контроля

**Принципы:**
1. **Системность:** регулярность контроля по утвержденному графику
2. **Документирование:** все результаты фиксируются в журналах
3. **Трендовый анализ:** отслеживание изменений параметров во времени
4. **Обратная связь:** информирование руководства и эксплуатационного персонала о результатах
5. **Непрерывное улучшение:** корректировка регламентов на основе опыта

**Внедрение системы:**
- Разработка и утверждение регламентов контроля
- Назначение ответственных лиц
- Обучение и аттестация персонала
- Приобретение необходимого оборудования
- Внедрение системы документооборота
- Периодический аудит системы контроля

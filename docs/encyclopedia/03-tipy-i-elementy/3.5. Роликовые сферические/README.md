# 3.5. Роликовые сферические

## Назначение

Описание конструктивных особенностей, характеристик и применения сферических роликовых подшипников. Раздел охватывает двухрядные самоустанавливающиеся роликоподшипники с бочкообразными роликами, предназначенные для восприятия высоких радиальных и умеренных осевых нагрузок при наличии перекосов и несоосности валов.

## Ключевые вопросы

- Что такое сферические роликовые подшипники и в чём их конструктивные особенности?
- Почему используются бочкообразные ролики вместо цилиндрических?
- Какие нагрузки могут воспринимать сферические роликоподшипники?
- Как обозначаются сферические роликовые подшипники по ГОСТ и ISO?
- В каких случаях применяют сферические роликоподшипники вместо других типов?
- Какие типы сепараторов используются и как они влияют на характеристики?

## Содержание

### Конструкция и принцип работы

**Сферический роликовый подшипник** (англ. *Spherical Roller Bearing*, нем. *Pendelrollenlager*) — двухрядный радиальный подшипник качения с бочкообразными роликами и общей сферической дорожкой качения на наружном кольце.

#### Основные элементы конструкции

1. **Внутреннее кольцо** — с двумя дорожками качения под углом (~8–10°)
2. **Наружное кольцо** — со сферической дорожкой качения
3. **Бочкообразные ролики** — расположены в два ряда
4. **Сепаратор** — латунный (массивный) или стальной (штампованный)

**Ключевая особенность:** Сферическая дорожка качения наружного кольца позволяет внутреннему кольцу с роликами свободно самоустанавливаться, компенсируя перекосы и несоосность до **2–4°**.

### Типы бочкообразных роликов

#### 1. Симметричные бочкообразные ролики
**Конструкция:**
- Ролик имеет одинаковый профиль с обеих сторон
- Образующая — дуга окружности большого радиуса
- Используются в стандартных подшипниках

**Преимущества:**
- Равномерное распределение нагрузки по длине ролика
- Снижение краевых напряжений
- Увеличенный ресурс

#### 2. Асимметричные бочкообразные ролики
**Конструкция:**
- Ролик имеет модифицированный профиль (логарифмический)
- Оптимизированное распределение давления
- Применяются в современных подшипниках высокого класса

**Преимущества:**
- Меньшее трение
- Повышенная грузоподъёмность (+15–20%)
- Сниженный нагрев

### Обозначение по стандартам

#### ГОСТ (ГОСТ 5721-75, ГОСТ 24696-81)

**Структура обозначения сферических роликоподшипников:**

```
3 X X X X X
│ └─┴─┴─┴── Серия диаметров и конструктивное исполнение
└────────── Тип подшипника (3 = роликовые сферические)
```

**Примеры:**
- **3507** — сферический роликовый, d=35 мм, серия диаметров 2 (средняя)
- **3617** — сферический роликовый, d=85 мм, серия диаметров 2
- **3182120** — сферический роликовый, d=100 мм, серия 3 (тяжёлая), конструкция 20

**Конструктивные исполнения (последние две цифры):**
- **00** — стандартная конструкция с латунным сепаратором
- **20** — с коническим отверстием (конусность 1:12)
- **К** — с коническим отверстием (конусность 1:30)

#### ISO (ISO 15:2017)

**Обозначение:**
```
2 X X X X
│ └─┴─┴── Серия диаметров и размер
└──────── Тип (2 = роликовые сферические)
```

**Примеры:**
- **22207** — d=35 мм, серия 2 (лёгкая)
- **22317** — d=85 мм, серия 3 (средняя)
- **23130** — d=150 мм, серия 3
- **23130K** — с коническим отверстием

**Суффиксы:**
- **CC** — улучшенная внутренняя конструкция (увеличенная грузоподъёмность)
- **CA** — латунный массивный сепаратор
- **MB** — массивный латунный сепаратор, центрируемый по роликам
- **E** — усиленная конструкция
- **K** — коническое отверстие 1:12
- **K30** — коническое отверстие 1:30

### Технические характеристики

#### Грузоподъёмность

**Динамическая грузоподъёмность C:**
- Высокая для радиальных нагрузок (в 1,5–2 раза выше шариковых)
- Формула расчёта: ГОСТ 18855-2013 (≈ ISO 281)

**Статическая грузоподъёмность C₀:**
- Очень высокая за счёт линейного контакта роликов с дорожками
- В 3–4 раза выше, чем у радиальных шариковых подшипников того же размера

**Соотношение C₀/C:**
- Для сферических роликовых: **4,5–6,0**
- Для шариковых радиальных: **2,0–2,5**

**Вывод:** Сферические роликоподшипники особенно эффективны при ударных и статических нагрузках.

#### Осевая нагрузка

**Допустимая осевая нагрузка:**
```
F_a ≤ 0,5 × F_r  (при нормальных условиях)
F_a ≤ 0,3 × F_r  (при высоких скоростях)
```

Где:
- `F_a` — осевая нагрузка
- `F_r` — радиальная нагрузка

**Примечание:** При чисто осевой нагрузке сферические роликоподшипники **не работают**. Необходима минимальная радиальная нагрузка.

#### Самоустанавливаемость

**Допустимый угол перекоса:**
- **2–3°** для стандартных конструкций
- **3–4°** для специальных исполнений с увеличенным зазором

**Сравнение с другими типами:**
| Тип подшипника | Допустимый угол перекоса |
|----------------|--------------------------|
| Шариковые радиальные | 0,001–0,005° (практически несамоустанавливающиеся) |
| Роликовые цилиндрические | 0,0005° (не допускают перекосов) |
| Шариковые сферические двухрядные | 2–5° |
| **Роликовые сферические** | **2–4°** |
| Роликовые конические | Только при парной установке, ~0,02° |

#### Скорость вращения

**Предельная частота вращения:**
- Зависит от типа сепаратора, смазки, точности
- Для латунного сепаратора: **n ≤ 0,5–0,6 × n_ref**
- Для стального штампованного: **n ≤ 0,65–0,75 × n_ref**
- Для полиамидного сепаратора: **n ≤ 0,7–0,8 × n_ref**

Где `n_ref` — справочная частота вращения из каталога производителя.

**Пример:**
- Подшипник 22320 (d=100 мм, D=215 мм)
- Справочная частота: n_ref = 2800 об/мин (пластичная смазка)
- Реальная предельная: **n ≤ 1680–1960 об/мин** (в зависимости от условий)

### Сепараторы

#### 1. Латунный массивный сепаратор (ГОСТ: Л, ISO: CA, MB)

**Характеристики:**
- Материал: латунь ЛС59-1
- Центрирование: по наружному кольцу (CA) или по роликам (MB)
- Грузоподъёмность: максимальная
- Скорость: средняя (до 0,6 × n_ref)

**Применение:**
- Тяжёлые условия эксплуатации
- Ударные нагрузки
- Вибрация
- Горнодобывающая промышленность, металлургия

**Преимущества:**
- ✅ Максимальная прочность и жёсткость
- ✅ Хорошая теплопроводность
- ✅ Устойчивость к ударам и вибрации

**Недостатки:**
- ❌ Увеличенная масса
- ❌ Ограниченная скорость вращения
- ❌ Высокая стоимость

#### 2. Стальной штампованный сепаратор (ГОСТ: Ш, ISO: J, JPA)

**Характеристики:**
- Материал: сталь 08кп
- Центрирование: по роликам
- Грузоподъёмность: средняя
- Скорость: повышенная (до 0,75 × n_ref)

**Применение:**
- Электродвигатели
- Вентиляторы
- Насосы
- Общее машиностроение

**Преимущества:**
- ✅ Меньшая масса
- ✅ Более высокая скорость вращения
- ✅ Низкая стоимость

**Недостатки:**
- ❌ Меньшая прочность
- ❌ Чувствительность к ударам

#### 3. Полиамидный сепаратор (ГОСТ: П, ISO: TN, TNHA)

**Характеристики:**
- Материал: армированный полиамид PA66-GF25
- Центрирование: по роликам
- Грузоподъёмность: средняя
- Скорость: максимальная (до 0,8 × n_ref)

**Применение:**
- Высокоскоростные электродвигатели
- Турбомашины
- Современное энергоэффективное оборудование

**Преимущества:**
- ✅ Минимальная масса
- ✅ Максимальная скорость вращения
- ✅ Низкое трение и нагрев
- ✅ Бесшумность
- ✅ Не требует обильной смазки

**Недостатки:**
- ❌ Ограничения по температуре (до +120°C)
- ❌ Чувствительность к химическим средам
- ❌ Средняя стоимость

### Сравнение с другими типами подшипников

| Параметр | Шариковые радиальные | Роликовые цилиндрические | **Роликовые сферические** | Роликовые конические |
|----------|----------------------|--------------------------|---------------------------|----------------------|
| **Радиальная грузоподъёмность** | 1,0 (базовая) | 1,8–2,2 | **2,5–3,5** | 2,0–2,5 |
| **Осевая грузоподъёмность** | 0,5–0,7 | 0,1–0,5 | **0,3–0,5** | 1,0 (высокая) |
| **Самоустанавливаемость** | Нет | Нет | **Да (2–4°)** | Нет |
| **Скорость вращения** | Высокая | Очень высокая | **Средняя** | Средняя |
| **Точность вращения** | Высокая | Средняя | **Средняя** | Средняя |
| **Устойчивость к ударам** | Низкая | Средняя | **Очень высокая** | Высокая |
| **Требования к монтажу** | Высокие | Очень высокие | **Низкие** | Очень высокие |
| **Стоимость** | Низкая | Средняя | **Средняя–высокая** | Средняя |

### Применение

#### Типовые области применения

**1. Горнодобывающая промышленность:**
- Дробилки, мельницы
- Грохоты, сепараторы
- Конвейерные ролики
- Барабаны подъёмных машин

**Требования:** Ударные нагрузки, загрязнение, перекосы → **роликовые сферические идеальны**

**2. Металлургия:**
- Прокатные станы
- Редукторы клетей прокатных станов
- Конвейеры непрерывной разливки
- Смесители, измельчители

**Требования:** Высокие нагрузки, вибрация, перекосы → **сферические роликовые с латунным сепаратором**

**3. Целлюлозно-бумажная промышленность:**
- Дефибрёры
- Измельчители древесины
- Барабаны сушильных машин
- Каландры

**Требования:** Загрязнение, влажность, ударные нагрузки

**4. Вентиляторы и вентиляционное оборудование:**
- Центробежные вентиляторы
- Дутьевые машины
- Дымососы

**Требования:** Перекосы от теплового расширения, вибрация

**5. Редукторы и приводы:**
- Промышленные редукторы
- Мотор-редукторы
- Приводы конвейеров

**Требования:** Высокие радиальные нагрузки, длительный срок службы

**6. Железнодорожный транспорт:**
- Буксы тележек грузовых вагонов
- Редукторы локомотивов

**Требования:** Ударные нагрузки, перекосы, загрязнение

#### Когда НЕ применять сферические роликоподшипники?

❌ **Высокоточные применения:**
- Прецизионные шпиндели станков
- Измерительное оборудование
→ Использовать радиально-упорные или роликовые цилиндрические прецизионные

❌ **Высокие скорости вращения (> 10000 об/мин):**
- Высокоскоростные шпиндели
- Турбины
→ Использовать шариковые радиально-упорные или гибридные керамические

❌ **Преимущественно осевые нагрузки:**
- Упорные узлы
- Вертикальные винты
→ Использовать упорные или радиально-упорные подшипники

❌ **Требования к минимальным габаритам:**
- Миниатюрное оборудование
- Малогабаритные приводы
→ Использовать шариковые радиальные

### Монтаж и эксплуатация

#### Посадки

**Внутреннее кольцо:**
- Циркумференциальная нагрузка: **k6, m6, n6** (натяг)
- Местная нагрузка: **js6, k6** (переходная/легкий натяг)

**Наружное кольцо:**
- Циркумференциальная нагрузка: **M7, N7** (натяг)
- Местная нагрузка: **H7, Js7** (зазор/переходная)
- Плавающая опора: **H8, H9** (зазор)

#### Коническое отверстие (конусность 1:12 или 1:30)

**Преимущества:**
- Простота монтажа на конические шейки валов или на втулки
- Регулировка радиального зазора осевым смещением
- Не требует нагрева подшипника

**Монтаж:**
1. Нанести тонкий слой масла на посадочное место
2. Насадить подшипник на конус
3. Затянуть гайкой или зафиксировать на втулке
4. Контролировать радиальный зазор в процессе затяжки

**Контроль осевого смещения при монтаже:**
- Типовое смещение: **0,1–0,3 мм** для уменьшения зазора на одну группу
- Измеряется по торцу кольца относительно начального положения

#### Смазка

**Пластичная смазка:**
- Литиевые смазки: ГОСТ 21150-87 (Литол-24), DIN 51825-K2K-30
- Заполнение: 30–50% свободного объема
- Интервал пополнения: зависит от скорости и температуры

**Жидкая смазка (масло):**
- Минеральные масла: ISO VG 68–220
- Синтетические масла: для высоких и низких температур
- Способ подачи: циркуляционная, масляный туман, капельная

**Рекомендация:** Для тяжёлых условий (вибрация, удары, загрязнение) — пластичная смазка с герметизацией.

#### Контроль состояния

**Параметры мониторинга:**
- Температура подшипникового узла (норма: +50–70°C)
- Вибрация (анализ спектра для раннего обнаружения дефектов)
- Шум (увеличение шума — признак износа или дефекта смазки)

**Методы:**
- Виброанализ (ISO 10816)
- Термография
- Анализ смазки (ГОСТ 32484-2013)

### Дефекты и причины отказов

| Дефект | Возможная причина | Решение |
|--------|-------------------|---------|
| **Выкрашивание дорожек качения** | Усталость материала, превышение ресурса | Замена подшипника, проверка нагрузки |
| **Отпечатки от роликов (brinelling)** | Статическая перегрузка, удары при монтаже | Использовать правильную технологию монтажа |
| **Перегрев и изменение цвета** | Недостаточная смазка, слишком малый зазор | Проверить смазку и зазор |
| **Износ сепаратора** | Недостаточная смазка, абразивное загрязнение | Улучшить уплотнения, использовать фильтрацию |
| **Трещины на кольцах** | Чрезмерный натяг, удары, перекосы > допустимых | Проверить посадки, монтаж |
| **Коррозия** | Попадание влаги, агрессивной среды | Улучшить уплотнения, использовать нержавеющую сталь |

# 1.8. Источники и верификация

## Назначение

Описание источников информации, используемых в справочнике, методология проверки данных, принципы цитирования и обеспечения достоверности технической информации.

## Ключевые вопросы

- Какие источники используются для заполнения справочника?
- Как проверяется достоверность информации о подшипниках?
- Можно ли доверять данным в справочнике для проектирования?
- Как цитируются стандарты ГОСТ, ISO и каталоги производителей?
- Что делать при обнаружении ошибки или устаревших данных?

## Содержание

### Иерархия источников

Информация в справочнике BearingsInfo основана на **трёхуровневой иерархии достоверности**:

#### Уровень 1: Официальные стандарты (приоритет)

**Государственные стандарты:**
- **ГОСТ** — межгосударственные стандарты СНГ
- **ГОСТ Р** — национальные стандарты РФ
- **ОСТ** — отраслевые стандарты
- **ТУ** — технические условия заводов-изготовителей

**Международные стандарты:**
- **ISO** — International Organization for Standardization
- **DIN** — Deutsche Industrie Norm (Германия)
- **ANSI/ABMA** — American National Standards Institute / American Bearing Manufacturers Association
- **JIS** — Japanese Industrial Standards

#### Уровень 2: Технические каталоги производителей

**Ведущие мировые производители:**
- **SKF** (Швеция) — General Catalogue, Technical Handbooks
- **FAG/INA** (Германия, Schaeffler Group) — Каталоги и инженерные руководства
- **NSK** (Япония) — Technical Data, CAD Data
- **NTN** (Япония) — Bearing Technical Data Sheets
- **Timken** (США) — Engineering Manuals

**Российские производители:**
- ГПЗ-1, ГПЗ-10, СПЗ, ВПЗ — каталоги продукции
- MPZ (Минск, Беларусь) — технические данные

#### Уровень 3: Справочные и учебные материалы

- Специализированная техническая литература
- Учебники по машиностроению
- Отраслевые справочники и руководства

### Принципы верификации данных

#### 1. Перекрёстная проверка (Cross-verification)

Каждый критически важный параметр проверяется **минимум по двум независимым источникам**:

**Пример:** Аналог ГОСТ 180305 ↔ ISO 6305
- Источник 1: ГОСТ 3189-89 "Подшипники шариковые радиальные однорядные. Типы и основные размеры"
- Источник 2: Таблица аналогов SKF General Catalogue
- Источник 3: Справочник "Подшипники качения" (А.И. Орлов)

#### 2. Приоритет первоисточников

- При расхождении данных **приоритет отдаётся официальным стандартам**
- Каталоги производителей используются как вторичный источник
- Учебная литература — только для общих пояснений

#### 3. Указание даты актуальности

Для стандартов и каталогов указывается:
- **Год издания** (например, ГОСТ 520-2002)
- **Версия каталога** (SKF General Catalogue 2023)
- **Дата последней проверки** для онлайн-источников

### Примеры цитирования

#### Стандарты ГОСТ

**Формат:**  
`ГОСТ [номер]-[год] "[название]"`

**Примеры:**
- ГОСТ 520-2002 "Подшипники качения. Общие технические условия"
- ГОСТ 3189-89 "Подшипники шариковые радиальные однорядные"

#### Стандарты ISO

**Формат:**  
`ISO [номер]:[год] "[название]"`

**Примеры:**
- ISO 15:1998 "Rolling bearings — Radial bearings — Boundary dimensions"
- ISO 281:2007 "Rolling bearings — Dynamic load ratings and rating life"

#### Каталоги производителей

**Формат:**  
`[Бренд] [Название каталога] ([год])`

**Примеры:**
- SKF General Catalogue (2023)
- FAG Rolling Bearings Catalogue (2020)
- NSK Technical Data: Ball & Roller Bearings (2022)

### Обработка противоречий

При обнаружении **расхождений между источниками**:

1. **Проверить актуальность:** Стандарты могли быть пересмотрены (ГОСТ 520-89 → ГОСТ 520-2002)
2. **Учесть региональные различия:** ГОСТ ≠ ISO (разные системы обозначений)
3. **Зафиксировать оба значения:** Указать источник для каждого варианта
4. **Запросить уточнение:** Создать Issue в репозитории для проверки

**Пример расхождения:**  
Класс точности подшипника по ГОСТ 520-2002: **класс 0**  
Аналог по ISO 492:2014: **класс Normal (P0)**  
→ Это **не противоречие**, а разные системы обозначений

### Политика обновлений

#### Когда обновляется информация:

- **Выход нового стандарта** (например, ISO 281:2007 заменил ISO 281:1990)
- **Обновление каталогов производителей** (новые серии подшипников)
- **Обнаружение ошибки** пользователем или автоматической проверкой

#### Как сообщить об ошибке:

1. Создать **Issue** в GitHub репозитории с описанием:
   - Где обнаружена ошибка (раздел, файл, строка)
   - В чём заключается ошибка
   - Предлагаемое исправление с указанием источника

2. Предложить **Pull Request** с исправлением и ссылкой на источник

### Ограничения и disclaimer

**Справочник BearingsInfo:**

✅ **Является:**
- Систематизированной справочной информацией
- Образовательным ресурсом
- Инструментом быстрого поиска и кроссреференса

❌ **НЕ является:**
- Заменой официальных стандартов ГОСТ, ISO, DIN
- Гарантией актуальности данных производителей
- Основанием для претензий в случае ошибки проектирования

**Рекомендация:** Для ответственных проектов всегда сверяйтесь с **оригинальными стандартами** и **каталогами производителей**.

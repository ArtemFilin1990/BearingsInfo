# 1.3. Термины и определения RU/EN

## Назначение

Словарь основных терминов и определений, используемых в области подшипников качения и скольжения, с русскими и английскими эквивалентами согласно ГОСТ и ISO.

## Ключевые вопросы

- Какие основные термины используются в технической документации на подшипники?
- Как правильно называются элементы конструкции подшипника на русском и английском?
- Что означают технические термины: радиальная нагрузка, зазор, класс точности?
- Как перевести термины подшипников с русского на английский и обратно?

## Содержание

### Основные термины

| **Русский термин** | **English term** | **Определение** |
|---|---|---|
| Подшипник качения | Rolling bearing | Подшипник, в котором используются тела качения (шарики или ролики) между кольцами |
| Подшипник скольжения | Plain bearing / Sliding bearing | Подшипник, в котором вал скользит по поверхности втулки без тел качения |
| Тело качения | Rolling element | Шарик или ролик, передающий нагрузку между кольцами |
| Внутреннее кольцо | Inner ring | Кольцо, устанавливаемое на вал |
| Наружное кольцо | Outer ring | Кольцо, устанавливаемое в корпус |
| Сепаратор | Cage / Retainer | Элемент, удерживающий тела качения на равном расстоянии |
| Дорожка качения | Raceway | Поверхность кольца, по которой катятся тела качения |

### Типы подшипников

| **Русский термин** | **English term** | **Примечания** |
|---|---|---|
| Шариковый подшипник | Ball bearing | Тела качения — шарики |
| Роликовый подшипник | Roller bearing | Тела качения — ролики |
| Игольчатый подшипник | Needle roller bearing | Ролики с отношением L/D > 3 |
| Радиальный подшипник | Radial bearing | Воспринимает радиальную нагрузку |
| Упорный подшипник | Thrust bearing | Воспринимает осевую (упорную) нагрузку |
| Радиально-упорный подшипник | Angular contact bearing | Воспринимает комбинированную нагрузку |
| Конический роликоподшипник | Tapered roller bearing | Ролики конической формы |
| Сферический роликоподшипник | Spherical roller bearing | Самоустанавливающийся подшипник |

### Параметры и характеристики

| **Русский термин** | **English term** | **Обозначение** |
|---|---|---|
| Внутренний диаметр | Bore diameter | d |
| Наружный диаметр | Outer diameter | D |
| Ширина подшипника | Bearing width | B, T |
| Радиальная нагрузка | Radial load | Fr |
| Осевая нагрузка | Axial load | Fa |
| Динамическая грузоподъёмность | Dynamic load rating | C |
| Статическая грузоподъёмность | Static load rating | C₀ |
| Предельная частота вращения | Limiting speed | n lim |
| Радиальный зазор | Radial internal clearance | - |

### Стандарты и обозначения

| **Русский термин** | **English term** | **Примечания** |
|---|---|---|
| Условное обозначение | Bearing designation | Код подшипника по стандарту |
| Класс точности | Accuracy class / Tolerance class | ГОСТ: 0, 6, 5, 4, 2; ISO: Normal, 6, 5, 4, 2 |
| Размерная серия | Dimension series | Комбинация серии диаметров и ширины |
| Дополнительное обозначение | Suffix | Код уплотнений, зазоров, материалов |
| Аналог | Equivalent / Cross-reference | Соответствующий подшипник другого стандарта |

### Конструктивные элементы

| **Русский термин** | **English term** | **Определение** |
|---|---|---|
| Борт | Rib / Shoulder | Выступ на кольце для удержания тел качения |
| Канавка | Groove | Углубление для установки уплотнения или стопорного кольца |
| Фаска | Chamfer | Скос на торце кольца |
| Уплотнение | Seal | Защита от загрязнений (контактное) |
| Защитная шайба | Shield | Защита от загрязнений (бесконтактное) |
| Закрепительная втулка | Adapter sleeve | Втулка для монтажа на цилиндрический вал |
| Стяжная втулка | Withdrawal sleeve | Втулка для демонтажа подшипника |

### Эксплуатация и обслуживание

| **Русский термин** | **English term** | **Примечания** |
|---|---|---|
| Монтаж | Mounting / Installation | Установка подшипника на вал и в корпус |
| Демонтаж | Dismounting / Removal | Снятие подшипника |
| Посадка | Fit | Характер соединения кольца с валом/корпусом |
| Смазка | Lubrication / Grease | Пластичная или жидкая смазка |
| Предварительный натяг | Preload | Устранение зазора для повышения жёсткости |
| Ревизия | Inspection | Проверка технического состояния |
| Дефект | Defect / Failure | Повреждение подшипника |

### Дефекты и повреждения

| **Русский термин** | **English term** | **Описание** |
|---|---|---|
| Усталостное выкрашивание | Fatigue spalling | Отслоение частиц материала дорожки |
| Износ | Wear | Истирание поверхности |
| Коррозия | Corrosion | Ржавление металла |
| Заедание | Seizure / Galling | Схватывание поверхностей |
| Трещина | Crack | Разрушение материала |
| Вмятина | Indentation / Brinelling | След от удара или перегрузки |

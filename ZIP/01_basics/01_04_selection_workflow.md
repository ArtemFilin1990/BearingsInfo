# Алгоритм выбора подшипников

## Назначение
Данный документ содержит систематический подход к выбору подходящего подшипника для конкретного применения.

## Пошаговый процесс выбора

### Шаг 1: Определение требований применения

#### Анализ нагрузок
**Вопросы для ответа:**
- Какова величина радиальной нагрузки? (Н или кН)
- Какова величина осевой нагрузки? (Н или кН)
- Нагрузка постоянная или переменная?
- Каково направление нагрузки (радиальная, осевая или комбинированная)?
- Есть ли ударные нагрузки или вибрации?

**Расчет:**
```
Эквивалентная нагрузка P = X·Fr + Y·Fa
Где:
  Fr = радиальная нагрузка
  Fa = осевая нагрузка
  X, Y = коэффициенты нагрузки (из каталогов подшипников)
```

#### Требования к скорости
**Вопросы для ответа:**
- Какова рабочая скорость? (об/мин)
- Вращается внутреннее или наружное кольцо?
- Каков требуемый диапазон скоростей?

**Расчет:**
```
Средний диаметр dm = (d + D) / 2
Параметр скорости n·dm (об/мин·мм)
```

#### Ограничения по пространству
**Необходимые измерения:**
- Доступный диаметр вала (d)
- Доступный диаметр отверстия корпуса (D)
- Доступное осевое пространство (B)
- Какие-либо габаритные ограничения?

#### Условия эксплуатации
**Факторы окружающей среды:**
- Диапазон рабочих температур (°C)
- Наличие загрязнений (пыль, вода, химикаты)
- Возможности смазки (пластичная смазка или масло)
- Доступность для обслуживания
- Ожидаемый срок службы

### Шаг 2: Выбор типа подшипника

#### Первичный выбор на основе направления нагрузки

**Чисто радиальная нагрузка:**
- Легкая или умеренная нагрузка → Шариковый радиальный однорядный подшипник
- Тяжелая нагрузка → Цилиндрический роликовый подшипник
- Очень ограниченное пространство → Игольчатый роликовый подшипник
- Ожидается перекос → Шариковый радиальный сферический двухрядный подшипник

**Чисто осевая нагрузка:**
- Легкая или умеренная нагрузка, высокая скорость → Шариковый упорный подшипник
- Тяжелая нагрузка → Цилиндрический роликовый упорный подшипник
- Ожидается перекос → Сферический роликовый упорный подшипник

**Комбинированная радиальная и осевая нагрузка:**
- Fa/Fr < 0,5, высокая скорость → Шариковый радиальный однорядный подшипник
- Fa/Fr > 0,5, требуется точность → Шариковый радиально-упорный подшипник
- Тяжелые нагрузки → Конический роликовый подшипник
- Очень тяжелые нагрузки, перекос → Сферический роликовый подшипник

#### Вторичные соображения

**Если присутствует перекос:**
- Угловой перекос 1,5° - 3° → Шариковый радиальный сферический двухрядный подшипник
- Угловой перекос 1° - 2,5° → Сферический роликовый подшипник

**Если пространство ограничено:**
- Радиальное пространство ограничено → Игольчатый роликовый подшипник
- Осевое пространство ограничено → Тонкостенный подшипник

**Если критична скорость:**
- Очень высокая скорость (n·dm > 500 000) → Шариковый радиальный однорядный, Шариковый радиально-упорный
- Высокая скорость (n·dm > 300 000) → Цилиндрический роликовый подшипник
- Умеренная скорость (n·dm < 300 000) → Конический роликовый, Сферический роликовый подшипник

### Шаг 3: Определение размера подшипника

#### Расчет требуемой грузоподъёмности

**Формула:**
```
C = P · (L₁₀h · n · 60 / 10⁶)^(1/p)

Где:
  C = требуемая динамическая грузоподъёмность (Н)
  P = эквивалентная динамическая нагрузка (Н)
  L₁₀h = требуемый срок службы (часы)
  n = скорость вращения (об/мин)
  p = 3 для шариковых подшипников, 10/3 для роликовых подшипников
```

**Пример:**
- Требуемый срок службы: 20 000 часов
- Скорость: 1500 об/мин
- Эквивалентная нагрузка: 5000 Н
- Тип подшипника: Шариковый радиальный однорядный (p = 3)

```
L₁₀ = 20 000 × 1500 × 60 / 10⁶ = 1800 миллионов оборотов
C = 5000 × (1800)^(1/3) = 5000 × 12,16 = 60 800 Н ≈ 61 кН
```

**Выбрать подшипник из каталога с C ≥ 61 кН**

#### Процесс выбора размера

1. **Начать с диаметра вала** - По возможности использовать стандартные диаметры валов
2. **Проверить каталог** - Найти подшипники с диаметром отверстия d, соответствующим валу
3. **Сравнить грузоподъёмности** - Выбрать подшипник с C ≥ требуемой C
4. **Проверить размеры** - Убедиться, что подшипник помещается в доступное пространство
5. **Проверить предел скорости** - Убедиться, что подшипник может работать на требуемой скорости

### Шаг 4: Проверка выбора

#### Проверка статической нагрузки

**Когда требуется:**
- Медленное вращение или качание
- Частые пуски/остановки
- Тяжелые ударные нагрузки

**Расчет:**
```
P₀ = X₀·Fr + Y₀·Fa ≤ C₀

Где:
  P₀ = эквивалентная статическая нагрузка (Н)
  C₀ = статическая грузоподъёмность (Н)
  X₀, Y₀ = коэффициенты статической нагрузки
```

**Коэффициент безопасности:**
- Плавная работа: S₀ = P₀/C₀ ≤ 0,5
- Нормальная работа: S₀ = P₀/C₀ ≤ 1,0
- Ударные нагрузки: S₀ = P₀/C₀ ≤ 1,5

#### Проверка предела скорости

**Референсная скорость (n_ref):**
- Типичная предельная скорость для смазки пластичной смазкой
- Указана в каталогах подшипников

**Тепловая скорость (n_th):**
- Скорость, при которой достигается тепловое равновесие
- Зависит от метода смазки и охлаждения

**Проверка:**
```
Рабочая скорость ≤ n_ref (для смазки пластичной смазкой)
Рабочая скорость ≤ n_th (для масляной смазки с охлаждением)
```

#### Проверка усталостной долговечности

**Минимально приемлемый срок службы:**
- Бытовые приборы: 300 - 2000 часов
- Сельскохозяйственная техника: 3000 - 6000 часов
- Автомобильная промышленность: 2000 - 5000 часов (непрерывная работа)
- Промышленное оборудование: 20 000 - 30 000 часов (работа 8ч/день)
- Станки: 20 000 - 40 000 часов
- Непрерывная работа: 40 000 - 100 000 часов

### Шаг 5: Выбор варианта подшипника

#### Внутренний зазор

**Опции:**
- **C2** - зазор меньше Нормального
- **Нормальный (CN)** - стандартный зазор
- **C3** - зазор больше Нормального
- **C4** - зазор больше C3
- **C5** - зазор больше C4

**Критерии выбора:**
- Плотные посадки → C3 или C4 (компенсирует уменьшение зазора)
- Высокая температура → C3 или C4 (компенсирует тепловое расширение)
- Требуется предварительный натяг → C2 или меньше
- Нормальные условия → Нормальный (CN)

#### Класс точности

**ГОСТ / ISO / ABEC:**
- **Класс 0 / P0 / ABEC 1** - Общее машиностроение
- **Класс 6 / P6 / ABEC 3** - Умеренная точность
- **Класс 5 / P5 / ABEC 5** - Прецизионные применения
- **Класс 4 / P4 / ABEC 7** - Высокая точность (станки)
- **Класс 2 / P2 / ABEC 9** - Ультрапрецизионные

**Критерии выбора:**
- Стандартное оборудование → Класс 0
- Электродвигатели, насосы → Класс 6
- Шпиндели станков (низкая скорость) → Класс 5
- Шпиндели станков (высокая скорость) → Класс 4
- Ультрапрецизионные шпиндели → Класс 2

#### Уплотнения и защитные шайбы

**Опции:**
- **Открытый** - без защиты, требуется внешнее уплотнение
- **Z** - одна защитная шайба (бесконтактная)
- **ZZ** - две защитные шайбы (бесконтактные)
- **RS** - одно уплотнение (контактное)
- **2RS** - два уплотнения (контактные)

**Критерии выбора:**
- Чистая среда, высокая скорость → Открытый или Z/ZZ
- Пыльная среда → 2RS
- Воздействие воды → 2RS
- Обслуживание не требуется → 2RS (уплотненный и смазанный)
- Возможна повторная смазка → Открытый или Z/ZZ

#### Материал сепаратора

**Опции:**
- **Сталь** - стандарт, экономичный
- **Латунь** - лучший теплоотвод
- **Полиамид** - легкий, низкий уровень шума
- **Фенольный** - высокая температурная стойкость

**Критерии выбора:**
- Стандартные применения → Сталь
- Высокая скорость, малый вес → Полиамид
- Высокая температура → Латунь или Фенольный
- Тихая работа → Полиамид

### Шаг 6: Определение смазки

#### Пластичная смазка

**Когда использовать:**
- Простые требования к уплотнению
- Приемлемы длительные интервалы повторной смазки
- Умеренные скорости (n·dm < 300 000 - 500 000)
- Ограниченный доступ для обслуживания

**Выбор смазки:**
- **На основе лития (Li)** - Общего назначения, -20°C до +120°C
- **Литиевый комплекс (Li-complex)** - Расширенный температурный диапазон, -30°C до +150°C
- **Полимочевина** - Длительный срок службы, высокая температура, -30°C до +180°C
- **Высокотемпературная смазка** - Специальные применения, до +230°C

**Класс NLGI:**
- NLGI 2 - наиболее распространенный, общего назначения
- NLGI 3 - более высокие температуры, вертикальные валы

#### Масляная смазка

**Когда использовать:**
- Высокие скорости (n·dm > 500 000)
- Высокие температуры
- Требуется теплоотвод
- Непрерывная работа с длительным сроком службы

**Методы:**
- **Масляная ванна** - простой, экономичный, низкие и умеренные скорости
- **Циркуляционное масло** - высокие скорости, отвод тепла
- **Масляный туман** - высокие скорости, минимальное трение
- **Масловоздушная** - прецизионные, минимальный расход масла

### Шаг 7: Определение схемы установки

#### Посадка вала

**Вращающееся внутреннее кольцо (типично):**
- Легкие нагрузки → h6, j6
- Нормальные нагрузки → k5, k6, m5, m6
- Тяжелые нагрузки, удары → n6, p6

**Неподвижное внутреннее кольцо:**
- Все нагрузки → g6, h6

#### Посадка корпуса

**Вращающееся наружное кольцо:**
- Легкие нагрузки → k6, m6
- Нормальные нагрузки → n6, p6

**Неподвижное наружное кольцо (типично):**
- Все нагрузки → H7, J7
- Компенсация теплового расширения → G7

#### Осевая фиксация

**Фиксирующий подшипник (фиксирует вал осевым образом):**
- Конический роликовый подшипник
- Радиально-упорный подшипник
- Шариковый радиальный однорядный подшипник с буртиками с обеих сторон

**Свободный подшипник (допускает осевое смещение):**
- Цилиндрический роликовый подшипник (типы NU, N)
- Шариковый радиальный однорядный подшипник с зазором с одной стороны

### Шаг 8: Финальная проверка

#### Контрольный список:
- [ ] Тип подшипника подходит для направления нагрузки
- [ ] Динамическая грузоподъёмность C ≥ требуемой C
- [ ] Статическая грузоподъёмность C₀ достаточна
- [ ] Скорость в пределах допустимой
- [ ] Подшипник помещается в доступное пространство
- [ ] Внутренний зазор соответствует посадкам и температуре
- [ ] Класс точности подходит для применения
- [ ] Уплотнение соответствует окружающей среде
- [ ] Определен метод смазки
- [ ] Определена схема установки
- [ ] Срок службы соответствует требованиям

## Таблицы быстрого выбора

### По типу применения

| Применение | Типичный тип подшипника | Примечания |
|-----------|------------------------|-----------|
| Электродвигатели | Шариковый радиальный однорядный | Серии 6000, 6200 распространены |
| Редукторы | Цилиндрический роликовый, Конический роликовый | Зависит от нагрузки |
| Насосы | Шариковый радиальный однорядный, Радиально-упорный | Учитывать загрязнения |
| Компрессоры | Радиально-упорный, Цилиндрический роликовый | Высокие нагрузки |
| Станки | Радиально-упорный, Цилиндрический роликовый | Высокая точность |
| Автомобильные колеса | Конический роликовый, Шариковый радиальный однорядный | Регулируемые или уплотненные |
| Конвейеры | Сферический шариковый, Сферический роликовый | Перекос распространен |
| Дробилки/Мельницы | Сферический роликовый | Очень тяжелые нагрузки |

### По диапазону скоростей (n·dm)

| Диапазон скоростей | Подходящие типы подшипников |
|-------------------|----------------------------|
| < 100 000 | Все типы |
| 100 000 - 300 000 | Все кроме сферических роликовых |
| 300 000 - 500 000 | Шариковые подшипники, Цилиндрические роликовые |
| 500 000 - 1 000 000 | Шариковые радиальные однорядные, Шариковые радиально-упорные |
| > 1 000 000 | Шариковые радиально-упорные (специальные конструкции) |

### По грузоподъёмности (относительно)

| Уровень нагрузки | Радиальные подшипники | Упорные подшипники |
|-----------------|----------------------|-------------------|
| Очень высокая | Сферический роликовый | Сферический роликовый упорный |
| Высокая | Конический роликовый, Цилиндрический роликовый | Цилиндрический роликовый упорный |
| Умеренная | Шариковый радиальный однорядный (большой) | - |
| Легкая | Шариковый радиальный однорядный (малый) | Шариковый упорный |

# 1.2. Как пользоваться базой

## Назначение

Инструкция по навигации в справочнике BearingsInfo: логика разделов, способы поиска информации, рекомендации по использованию данных и интеграция с другими системами.

## Ключевые вопросы

- Как быстро найти информацию по обозначению подшипника?
- Какие разделы использовать для подбора аналогов?
- Как понять систему нумерации и структуру справочника?
- Где найти данные для экспорта в CSV/JSON?
- Как связаны разделы справочника между собой?

## Содержание

### Структура справочника

Справочник организован по **иерархическому принципу** с нумерацией разделов:

```
1. Подшипники. Общая информация
   ├─ 1.1. Назначение и границы
   ├─ 1.2. Как пользоваться базой
   └─ ...

2. Стандарты и маркировка (ядро справочника)
   ├─ 2.1. Карта стандартов ГОСТ, ISO, DIN, ANSI
   ├─ 2.2. Система обозначений
   └─ ...

3. Типы и элементы
4. Расчёт и параметры
5. Эксплуатация и обслуживание
6. Отказы и диагностика
7. Бренды и производители
8. Специальные исполнения и справка
9. Сопутствующие изделия
```

### Типовые сценарии использования

#### Сценарий 1: Расшифровка обозначения подшипника

**Задача:** Есть маркировка `6205-2RS`, нужно понять её значение.

**Путь решения:**
1. Раздел **2.2. Система обозначений базовая модель** — понимание структуры
2. Раздел **2.11. Примеры расшифровки обозначений** — пошаговый разбор
3. Раздел **2.8. Уплотнения и защита обозначения** — значение суффикса `-2RS`

#### Сценарий 2: Поиск аналога ГОСТ → ISO

**Задача:** Заменить российский подшипник `180305` на импортный аналог.

**Путь решения:**
1. Раздел **2.5. Сопоставление ГОСТ и ISO аналоги** — таблица соответствий
2. Раздел **7. Бренды и производители** — выбор производителя (SKF, FAG, NSK)
3. Данные: `/data/csv/analogs_gost_iso.csv`

#### Сценарий 3: Выбор подшипника для нового проектирования

**Задача:** Подобрать подшипник по параметрам нагрузки, скорости, температуры.

**Путь решения:**
1. Раздел **1.7. Алгоритм выбора и чек-лист ошибок** — общая методика
2. Раздел **3. Типы и элементы** — выбор конструкции (шариковый, роликовый)
3. Раздел **4. Расчёт и параметры** — проверка нагрузки и частоты вращения
4. Раздел **5. Эксплуатация и обслуживание** — подбор смазки и посадок

#### Сценарий 4: Диагностика отказа подшипника

**Задача:** Подшипник вышел из строя, нужно определить причину.

**Путь решения:**
1. Раздел **6.2. Виды дефектов с фото** — визуальная идентификация повреждений
2. Раздел **6.1. Основные причины повреждений** — анализ причин (перегрузка, смазка, монтаж)
3. Раздел **5.5. Диагностика в эксплуатации** — методы контроля состояния

### Навигация по данным

#### Поиск по файлам

- **README.md в каждой папке** — основная информация по теме
- **CSV файлы в `/data/csv/`** — таблицы с данными (размеры, аналоги, бренды)
- **Схемы в `/schemas/`** — структура базы данных (YAML)

#### Использование API

Справочник предоставляет RESTful API для программного доступа:

```bash
# Автодополнение обозначений
curl "http://localhost:8000/autocomplete?q=6205"

# Поиск подшипника
curl "http://localhost:8000/search?q=6205"

# Экспорт в CSV
curl "http://localhost:8000/search/export?q=6205&format=csv" > results.csv
```

См. документацию: `/api/README.md`

#### Работа с данными (CSV/JSON)

Данные можно экспортировать для интеграции с другими системами:

- **CSV таблицы:** `/data/csv/` (UTF-8, разделитель запятая)
- **JSON схемы:** `/schemas/` (структура для импорта в БД)
- **SQL скрипты:** `/sql/` (PostgreSQL)

# Грузоподъёмность и расчёты нагрузок

## Назначение

Данный документ предоставляет исчерпывающую информацию о грузоподъёмности подшипников (Load Ratings), расчётах эквивалентных нагрузок, применении коэффициентов нагрузки для правильного выбора и проверки подшипников. Понимание грузоподъёмности является фундаментальным для инженерного проектирования подшипников и обеспечивает безопасную, надёжную работу.

---

## 1. Основные определения

### 1.1 Базовая статическая грузоподъёмность (C₀ / Basic Static Load Rating)

**Определение (ГОСТ 18854, ISO 76):**

**Базовая статическая грузоподъёмность** (C₀) — это статическая нагрузка, вызывающая общую остаточную деформацию тел качения и дорожек качения, равную **0,0001** (0,01%) диаметра тела качения в наиболее нагруженном контакте.

**Ключевые характеристики:**
- Применяется когда подшипник неподвижен или вращается очень медленно (n < 10 об/мин)
- Представляет грузоподъёмность без вращения
- Критерий остаточной деформации: 0,0001 × Dw (Dw = диаметр шарика/ролика)
- Используется для расчёта статического коэффициента запаса
- Всегда ниже динамической грузоподъёмности для одного и того же подшипника

**Единицы измерения:**
- ГОСТ: килоньютоны (кН)
- ISO: ньютоны (Н) или килоньютоны (кН)
- Каталоги обычно указывают: кН

**Физический смысл:**

При нагрузке C₀ контактное напряжение достигает приблизительно:
- **Шариковые подшипники:** 4600 МПа (напряжение Герца)
- **Роликовые подшипники:** 4000 МПа (напряжение линейного контакта)

Эти уровни напряжения создают допустимую остаточную деформацию для периодической работы.

### 1.2 Базовая динамическая грузоподъёмность (C / Basic Dynamic Load Rating)

**Определение (ГОСТ 18855, ISO 281):**

**Базовая динамическая грузоподъёмность** (C) — это постоянная радиальная нагрузка (для радиальных подшипников) или постоянная осевая нагрузка (для упорных подшипников), которую подшипник теоретически может выдержать в течение номинальной долговечности **1 миллион оборотов** (L₁₀ = 10⁶) с **надёжностью 90%**.

**Ключевые характеристики:**
- Применяется к вращающимся подшипникам под нагрузкой
- Основана на теории усталостной долговечности
- 90% вероятность выживания (10% вероятность отказа)
- Стандартизирована для 1 миллиона оборотов
- Формирует основу для расчётов долговечности

**Концепция номинальной долговечности:**
- **L₁₀ = 1 000 000 оборотов** при нагрузке P = C
- L₁₀ = базовая номинальная долговечность (90% надёжность)
- Материал: сквозь закалённая подшипниковая сталь (≥ 58 HRC)
- Смазка: достаточная, чистая
- Температура: ≤ 120°C

**Физический смысл:**

Динамическая грузоподъёмность представляет сопротивление усталости. Материал подшипника (обычно 100Cr6 / ШХ15) под циклическим контактным напряжением Герца будет развивать подповерхностные усталостные трещины после повторных циклов нагружения.

## 2. Расчёты базовой статической грузоподъёмности

### 2.1 Радиальные шариковые подшипники

**Формула (ГОСТ 18854-94, ISO 76:2006):**

```
C₀ = f₀ · i · Z · Dw² · cos α
```

Где:
- **f₀** = расчётный коэффициент (зависит от геометрии подшипника)
- **i** = число рядов тел качения
- **Z** = число шариков в ряду
- **Dw** = диаметр шарика [мм]
- **α** = номинальный угол контакта [градусы]
- **C₀** = базовая статическая грузоподъёмность [Н]

**Расчётные коэффициенты f₀ для радиальных шариковых подшипников:**

| Тип подшипника | Dw · cos α / Dpw | f₀ |
|--------------|------------------|-----|
| **Однорядный радиально-упорный** | — | 12,3 |
| **Радиальный шариковый (α ≈ 0°)** | Все значения | 12,3 |
| **Радиально-упорный** | ≥ 0,025 | 13,0 |
| **Радиально-упорный** | 0,020 - 0,025 | 12,0 - 13,0 (интерполяция) |
| **Самоустанавливающийся шариковый** | Все значения | 7,0 |

**Dpw** = диаметр центров шариков = (d + D) / 2

### 2.2 Радиальные роликовые подшипники

**Формула для цилиндрических и игольчатых роликоподшипников:**

```
C₀ = 44 · i · Z · lwe · Dw · cos α  [для lwe ≤ Dw]
C₀ = 220 · i · Z · Dw² · cos α      [для lwe > Dw]
```

**Формула для конических роликоподшипников:**

```
C₀ = (f₀ · i · lwe · Dw · cos α) / (1 - 1,5 · tan α)
```

Где:
- **lwe** = эффективная длина контакта ролика [мм]
- **f₀** = 220 для конических роликов
- **α** = угол контакта

**Формула для сферических роликоподшипников:**

```
C₀ = 220 · i · Z · Dw² · cos α
```

Для двухрядных сферических: i = 2 (два ряда)

### 2.3 Упорные шариковые подшипники

**Формула:**

```
C₀a = f₀ · Z · Dw² · sin α
```

Где:
- **C₀a** = базовая статическая осевая грузоподъёмность [Н]
- **f₀** = 26,6 (для упорных шариковых подшипников)
- **sin α** = коэффициент осевой нагрузки

### 2.4 Упорные роликовые подшипники

**Формула (цилиндрические упорные ролики):**

```
C₀a = 220 · Z · lwe · Dw · sin α
```

**Формула (конические упорные ролики):**

```
C₀a = 220 · Z · lwe · Dw · sin α / (1 - 1,5 · tan α)
```

## 3. Расчёты базовой динамической грузоподъёмности

### 3.1 Радиальные шариковые подшипники

**Формула (ISO 281:2007):**

```
C = fc · (i · Z)^(0,7) · Dw^1,8 · (cos α)^0,3
```

Где:
- **fc** = расчётный коэффициент (функция геометрии)
- **i** = число рядов
- **Z** = шариков в ряду
- **Dw** = диаметр шарика [мм]
- **α** = угол контакта

**Типичные значения fc:**
- Однорядный радиальный шариковый: fc ≈ 98 - 106 (зависит от соотношения Dw/Dpw)
- Радиально-упорный: fc ≈ 60 - 100
- Самоустанавливающийся: fc ≈ 50 - 70

*Примечание: Точные значения fc из данных производителя или детальных таблиц ISO 281*

### 3.2 Радиальные роликовые подшипники

**Формула (цилиндрические ролики):**

```
C = fc · (lwe · i · Z)^(7/9) · Dw^(29/27)
```

**Формула (конические ролики):**

```
C = (2/3)^(e) · fc · (lwe · i · Z)^(7/9) · Dw^(29/27) · (cos α)^n
```

Где:
- **e** = показатель распределения нагрузки
- **n** = показатель эффекта угла контакта

### 3.3 Упорные подшипники

**Упорные шариковые подшипники:**

```
Ca = fc · Z^(2/3) · Dw^1,8 · (tan α)^0,3
```

**Упорные роликовые подшипники:**

```
Ca = fc · (lwe · Z)^(7/9) · Dw^(29/27) · (tan α)^n
```

## 4. Эквивалентная статическая нагрузка (P₀)

### 4.1 Определение

**Эквивалентная статическая нагрузка** P₀ — это расчётная постоянная радиальная нагрузка (или осевая нагрузка для упорных подшипников), которая создала бы такое же максимальное контактное напряжение, как и фактическая комбинация нагрузок.

**Назначение:**
- Оценка безопасности подшипника при статических или очень медленных оборотах
- Расчёт статического коэффициента запаса: s₀ = C₀ / P₀
- Проверка пиковых нагрузок, ударных нагрузок, условий пуска

### 4.2 Радиальные подшипники — общая формула

```
P₀ = X₀ · Fr + Y₀ · Fa
```

Где:
- **P₀** = эквивалентная статическая радиальная нагрузка [Н]
- **Fr** = фактическая радиальная нагрузка [Н]
- **Fa** = фактическая осевая нагрузка [Н]
- **X₀** = коэффициент радиальной нагрузки
- **Y₀** = коэффициент осевой нагрузки

### 4.3 Коэффициенты нагрузки для статической нагрузки

**Однорядные радиальные шариковые подшипники (α = 0°):**

| Условие | X₀ | Y₀ |
|-----------|----|----|
| Fa / Fr ≤ 0,8 | 0,6 | 0,5 |
| Fa / Fr > 0,8 | 0,5 | 0,47 |

**Однорядные радиально-упорные шариковые подшипники:**

Функция Fa/(Fr · tan α):

| Fa/(Fr·tan α) | X₀ | Y₀ |
|---------------|----|----|
| 0 - 0,55 | 1 | 0 |
| 0,55 - 1,0 | 0,6 | 0,5 |
| > 1,0 | 0,5 | 0,26·cot α |

**Цилиндрические роликоподшипники (только радиальные):**

```
P₀ = Fr     (X₀ = 1, Y₀ = 0)
```

Не могут воспринимать осевую нагрузку в стандартном исполнении.

**Конические роликоподшипники:**

| Fa/Fr | X₀ | Y₀ |
|-------|----|----|
| ≤ e | 1 | 0 |
| > e | 0,5 | 0,22 · cot α |

Где **e** = граничный коэффициент (обычно 0,3 - 0,4, из каталога)

**Сферические роликоподшипники:**

| Fa/Fr | X₀ | Y₀ |
|-------|----|----|
| ≤ e | 1 | 0 |
| > e | 0,67 | 0,67 · Y (из каталога) |

### 4.4 Минимальная эквивалентная статическая нагрузка

**Важное правило:**

```
P₀ ≥ Fr  (радиальные подшипники)
P₀ ≥ Fa  (упорные подшипники)
```

Даже если расчётное значение P₀ ниже, используйте фактическую радиальную (или осевую) нагрузку как минимум.

### 4.5 Статический коэффициент запаса

**Определение:**

```
s₀ = C₀ / P₀
```

**Рекомендуемые минимальные значения:**

| Применение | s₀ мин |
|-------------|--------|
| **Плавная работа, низкие требования** | 0,5 - 1,0 |
| **Нормальные условия, общее машиностроение** | 1,0 - 1,5 |
| **Высокая надёжность, требуется плавный ход** | 1,5 - 2,5 |
| **Точные применения, минимальная вибрация** | 2,5 - 4,0 |
| **Тяжёлые ударные нагрузки** | 3,0 - 5,0 |

**Примечание:** s₀ < 1 допустимо для лёгких нагрузок без ударов, если плавность хода не критична.

## 5. Эквивалентная динамическая нагрузка (P)

### 5.1 Определение

**Эквивалентная динамическая нагрузка** P — это расчётная постоянная радиальная нагрузка (или осевая нагрузка), которая обеспечила бы такую же долговечность подшипника, как и фактическая комбинация нагрузок в реальных условиях эксплуатации.

**Назначение:**
- Расчёт номинальной долговечности подшипника L₁₀
- Сравнение различных подшипников
- Проверка грузоподъёмности

### 5.2 Радиальные подшипники — общая формула

```
P = X · Fr + Y · Fa
```

Где:
- **P** = эквивалентная динамическая радиальная нагрузка [Н]
- **Fr** = фактическая радиальная нагрузка [Н]
- **Fa** = фактическая осевая нагрузка [Н]
- **X** = коэффициент радиальной нагрузки (динамический)
- **Y** = коэффициент осевой нагрузки (динамический)

**Минимальное значение:**

```
P ≥ Fr (для радиальных подшипников)
```

### 5.3 Коэффициенты нагрузки для динамической нагрузки

#### Однорядные радиальные шариковые подшипники

**Расчётный параметр:**

```
fa = Fa / C₀
e = f(fa)  [из таблиц]
```

**Коэффициенты нагрузки:**

| Условие | X | Y |
|-----------|---|---|
| Fa / Fr ≤ e | 1 | 0 |
| Fa / Fr > e | 0,56 | Y (из таблицы) |

**Таблица: значения e и Y для радиальных шариковых подшипников:**

| fa | e | Y (Fa/Fr > e) |
|----|---|---------------|
| 0,025 | 0,22 | 2,30 |
| 0,04 | 0,24 | 1,99 |
| 0,07 | 0,27 | 1,71 |
| 0,13 | 0,31 | 1,45 |
| 0,25 | 0,37 | 1,23 |
| 0,50 | 0,44 | 1,05 |

*Интерполируйте для промежуточных значений*

#### Однорядные радиально-упорные шариковые подшипники

**Для угла контакта α = 15°:**

| Fa/(Fr·tan α) | X | Y |
|---------------|---|---|
| ≤ 1,14 | 1 | 0 |
| > 1,14 | 0,56 | 1,68 |

**Для угла контакта α = 25°:**

| Fa/(Fr·tan α) | X | Y |
|---------------|---|---|
| ≤ 0,95 | 1 | 0 |
| > 0,95 | 0,56 | 1,42 |

**Для угла контакта α = 40°:**

| Fa/(Fr·tan α) | X | Y |
|---------------|---|---|
| ≤ 0,76 | 1 | 0 |
| > 0,76 | 0,56 | 1,07 |

#### Цилиндрические роликоподшипники (стандартные)

```
P = Fr     (X = 1, Y = 0)
```

*Нет грузоподъёмности по осевой нагрузке в стандартном исполнении*

#### Конические роликоподшипники

**Одиночный подшипник:**

| Fa/Fr | X | Y |
|-------|---|---|
| ≤ e | 1 | 0 |
| > e | 0,4 | Y (из каталога) |

**e** = обычно 0,3 - 0,4 (от производителя)
**Y** = зависит от угла контакта (обычно 1,5 - 2,5)

**Спаренные подшипники (компоновка X или O):**

Необходимо учитывать индуцированные осевые нагрузки. Расчёт более сложный, требует итеративного решения или программного обеспечения производителя.

#### Сферические роликоподшипники

**Общая формула:**

| Fa/Fr | X | Y |
|-------|---|---|
| ≤ e | 1 | 0 |
| > e | 0,67 | Y (из каталога) |

**Типичные значения Y:** 2,5 - 4,5 (зависит от серии подшипника)

**Значения e:** обычно 0,22 - 0,30

## 6. Практические примеры расчётов

### 6.1 Пример 1: Радиальный шариковый подшипник — простая радиальная нагрузка

**Дано:**
- Подшипник: 6208 (d = 40 мм, D = 80 мм, B = 18 мм)
- Данные каталога: C = 32,0 кН, C₀ = 17,0 кН
- Радиальная нагрузка: Fr = 2500 Н
- Осевая нагрузка: Fa = 0 Н

**Решение:**

Так как Fa = 0:
```
P = Fr = 2500 Н = 2,5 кН
```

**Статическая проверка:**
```
P₀ = Fr = 2500 Н = 2,5 кН
s₀ = C₀ / P₀ = 17,0 / 2,5 = 6,8
```

Отличный статический запас (s₀ > 1).

### 6.2 Пример 2: Радиальный шариковый подшипник — комбинированная нагрузка

**Дано:**
- Подшипник: 6308 (d = 40 мм, D = 90 мм, B = 23 мм)
- Данные каталога: C = 55,3 кН, C₀ = 31,0 кН
- Радиальная нагрузка: Fr = 5000 Н
- Осевая нагрузка: Fa = 2000 Н
- Частота вращения: n = 1500 об/мин

**Решение — статическая нагрузка:**

Шаг 1: Вычислить соотношение Fa/Fr
```
Fa / Fr = 2000 / 5000 = 0,4
```

Шаг 2: Сравнить с 0,8
```
0,4 < 0,8 → Использовать X₀ = 0,6, Y₀ = 0,5
```

Шаг 3: Вычислить P₀
```
P₀ = X₀ · Fr + Y₀ · Fa
P₀ = 0,6 · 5000 + 0,5 · 2000
P₀ = 3000 + 1000 = 4000 Н = 4,0 кН
```

Шаг 4: Статический запас
```
s₀ = C₀ / P₀ = 31,0 / 4,0 = 7,75
```

Отличный статический запас.

**Решение — динамическая нагрузка:**

Шаг 1: Вычислить fa
```
fa = Fa / C₀ = 2000 / 31000 = 0,065
```

Шаг 2: Из таблицы (интерполяция между 0,04 и 0,07):
```
e ≈ 0,26
Y ≈ 1,8
```

Шаг 3: Проверить Fa/Fr относительно e
```
Fa / Fr = 0,4 > e (0,26)
```

Следовательно использовать: X = 0,56, Y = 1,8

Шаг 4: Вычислить P
```
P = X · Fr + Y · Fa
P = 0,56 · 5000 + 1,8 · 2000
P = 2800 + 3600 = 6400 Н = 6,4 кН
```

**Номинальная долговечность:**
```
L₁₀ = (C / P)³ миллионов оборотов
L₁₀ = (55,3 / 6,4)³ = (8,64)³ = 645 миллионов оборотов
```

**Часы работы:**
```
L₁₀h = (10⁶ / (60 · n)) · L₁₀
L₁₀h = (10⁶ / (60 · 1500)) · 645
L₁₀h = (1000000 / 90000) · 645 = 7167 часов
```

### 6.3 Пример 3: Радиально-упорный шариковый подшипник (α = 25°)

**Дано:**
- Подшипник: 7308 BEGAP (одиночный, α = 25°)
- Данные каталога: C = 53,0 кН, C₀ = 36,0 кН
- Радиальная нагрузка: Fr = 6000 Н
- Осевая нагрузка: Fa = 4000 Н

**Решение — динамическая нагрузка:**

Шаг 1: Вычислить Fa / (Fr · tan α)
```
tan 25° = 0,466
Fa / (Fr · tan α) = 4000 / (6000 · 0,466) = 4000 / 2796 = 1,43
```

Шаг 2: Сравнить с границей (0,95 для α = 25°)
```
1,43 > 0,95
```

Следовательно: X = 0,56, Y = 1,42

Шаг 3: Вычислить P
```
P = X · Fr + Y · Fa
P = 0,56 · 6000 + 1,42 · 4000
P = 3360 + 5680 = 9040 Н = 9,04 кН
```

**Примечание:** Высокая осевая нагрузка создаёт значительную эквивалентную нагрузку.

### 6.4 Пример 4: Конический роликоподшипник

**Дано:**
- Подшипник: 32208 (d = 40 мм, D = 80 мм, T = 24,75 мм)
- Данные каталога: C = 69,0 кН, C₀ = 64,0 кН
- Угол контакта: α ≈ 13,5° (типичный для серии 302)
- Радиальная нагрузка: Fr = 8000 Н
- Осевая нагрузка: Fa = 3000 Н
- Данные каталога: e = 0,35, Y = 1,7

**Решение — динамическая нагрузка:**

Шаг 1: Вычислить Fa / Fr
```
Fa / Fr = 3000 / 8000 = 0,375
```

Шаг 2: Сравнить с e
```
0,375 > 0,35 (e)
```

Следовательно: X = 0,4, Y = 1,7

Шаг 3: Вычислить P
```
P = X · Fr + Y · Fa
P = 0,4 · 8000 + 1,7 · 3000
P = 3200 + 5100 = 8300 Н = 8,3 кН
```

**Статическая проверка:**

Для статической (Fa/Fr = 0,375 > e):
```
X₀ = 0,5, Y₀ = 0,22 · cot(13,5°)
cot(13,5°) = 1 / tan(13,5°) = 1 / 0,240 = 4,17
Y₀ = 0,22 · 4,17 = 0,92

P₀ = 0,5 · 8000 + 0,92 · 3000
P₀ = 4000 + 2760 = 6760 Н = 6,76 кН

s₀ = C₀ / P₀ = 64,0 / 6,76 = 9,5
```

Отличный статический запас.

### 6.5 Пример 5: Сферический роликоподшипник

**Дано:**
- Подшипник: 22215 CCK/W33 (d = 75 мм, D = 130 мм, B = 31 мм)
- Данные каталога: C = 240 кН, C₀ = 265 кН
- Радиальная нагрузка: Fr = 20000 Н
- Осевая нагрузка: Fa = 8000 Н
- Данные каталога: e = 0,24, Y = 3,0

**Решение:**

Шаг 1: Проверить Fa / Fr
```
Fa / Fr = 8000 / 20000 = 0,4
```

Шаг 2: Сравнить с e
```
0,4 > 0,24 (e)
```

Следовательно: X = 0,67, Y = 3,0

Шаг 3: Вычислить P
```
P = X · Fr + Y · Fa
P = 0,67 · 20000 + 3,0 · 8000
P = 13400 + 24000 = 37400 Н = 37,4 кН
```

**Примечание:** Сферические роликоподшипники имеют высокие коэффициенты Y, что делает их эффективными для комбинированных нагрузок.

## 7. Специальные соображения

### 7.1 Распределение нагрузки в многоподшипниковых компоновках

**Тандемная компоновка (II, ↑↑):**
- Оба подшипника воспринимают осевую нагрузку одного направления
- Общая грузоподъёмность = сумма индивидуальных грузоподъёмностей
- Равномерное распределение нагрузки при идентичных подшипниках

**Компоновка спина к спине (O, ↔):**
- Подшипники противостоят друг другу
- Могут воспринимать двунаправленные осевые нагрузки
- Обеспечивает жёсткость к моменту
- Распределение нагрузки зависит от предварительного натяга

**Компоновка лицом к лицу (X, →←):**
- Менее жёсткая чем спина к спине
- Подходит для широко разнесённых подшипников
- Меньшая грузоподъёмность по моменту

### 7.2 Ударные и импульсные нагрузки

**Динамическая нагрузка с ударами:**

```
P = fs · P_номинальная
```

Где fs = коэффициент удара:

| Характер нагрузки | fs |
|----------------|-----|
| Плавная работа | 1,0 - 1,2 |
| Нормальные условия | 1,2 - 1,5 |
| Лёгкие удары | 1,5 - 2,0 |
| Умеренные удары | 2,0 - 2,5 |
| Тяжёлые удары | 2,5 - 3,5 |

### 7.3 Неопределённость направления нагрузки

Если направление нагрузки изменяется:
- Используйте наихудшую комбинацию
- Учитывайте максимально возможную нагрузку
- Применяйте дополнительный коэффициент запаса (1,2 - 1,5)

### 7.4 Влияние температуры на грузоподъёмность

**Коэффициенты снижения при высокой температуре:**

| Рабочая температура | Коэффициент снижения |
|-----------------------|------------------|
| ≤ 120°C | 1,0 |
| 150°C | 0,95 |
| 200°C | 0,85 |
| 250°C | 0,70 |
| 300°C | 0,55 |

**Скорректированная грузоподъёмность:**
```
C_фактическая = C_каталог · f_темп
```

## 9. Краткая справка и резюме

### Краткое руководство по выбору

**Для статических нагрузок или медленного вращения (n < 10 об/мин):**
1. Вычислите P₀ используя коэффициенты статической нагрузки
2. Проверьте s₀ = C₀ / P₀ ≥ требуемого минимума
3. Убедитесь, что остаточная деформация приемлема

**Для вращающихся подшипников:**
1. Вычислите P используя коэффициенты динамической нагрузки
2. Вычислите требуемую C на основе желаемой долговечности
3. Выберите подшипник с C ≥ требуемой C
4. Проверьте статический запас s₀ для пусковых/ударных нагрузок

### Таблица коэффициентов нагрузки — резюме

| Тип подшипника | Чисто радиальная | Комбинированная нагрузка |
|--------------|-------------|---------------|
| **Радиальный шариковый** | X=1, Y=0 | См. таблицы (X=0,56 или 1) |
| **Радиально-упорный** | X=1, Y=0 | X=0,56, Y=f(α) |
| **Цилиндрический роликовый** | X=1, Y=0 | X=1, Y=0 (нет осевой) |
| **Конический роликовый** | X=1, Y=0 | X=0,4, Y=каталог |
| **Сферический роликовый** | X=1, Y=0 | X=0,67, Y=каталог |

### Критические напоминания

1. **Всегда используйте P ≥ Fr** (минимальное правило)
2. **Проверяйте как статическую, так и динамическую** грузоподъёмность
3. **Учитывайте ударные нагрузки** (умножайте на fs)
4. **Проверяйте температурные пределы** (снижайте C если T > 120°C)
5. **Используйте каталожные данные** когда доступны (более точны чем формулы)

## 10. Заключение

Расчёты грузоподъёмности и эквивалентной нагрузки составляют основу выбора подшипников. Правильное применение:
- Статической грузоподъёмности (C₀) → предотвращает остаточную деформацию
- Динамической грузоподъёмности (C) → обеспечивает достаточную усталостную долговечность
- Коэффициентов нагрузки (X, Y) → преобразует фактические нагрузки в эквивалентные
- Коэффициентов запаса → обеспечивает конструктивный запас

Понимание и правильное применение этих принципов обеспечивает надёжную, долговечную работу подшипников во всех применениях.

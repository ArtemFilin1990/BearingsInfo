# 2.3. ГОСТ: правила формирования обозначения

## Назначение

Подробное описание правил формирования условных обозначений подшипников качения по ГОСТ 3189-89, структуры кодов, последовательности записи и особенностей маркировки различных типов подшипников.

## Ключевые вопросы

- Какова последовательность записи обозначения подшипника по ГОСТ?
- Какие элементы входят в префикс и суффикс обозначения?
- Как правильно записать обозначение подшипника с несколькими дополнительными параметрами?
- Какие правила применяются для обозначения разных типов подшипников?
- Как формируется обозначение для невзаимозаменяемых подшипников?
- Какие отличия в обозначениях современных и старых стандартов ГОСТ?

## Содержание

### Основной стандарт

**ГОСТ 3189-89** — «Подшипники шариковые и роликовые. Система условных обозначений»

**Действие:** Межгосударственный стандарт, применяется в России и странах СНГ

**Дата введения:** 01.01.1991

**Заменённые стандарты:** ГОСТ 3189-75

### Общая структура обозначения

Условное обозначение подшипника качения состоит из:

```
ПРЕФИКС - ОСНОВНОЕ ОБОЗНАЧЕНИЕ - СУФФИКС
```

#### Полная форма записи

```
[Категория][Момент][Класс точности][Зазор] - [Осн. обозначение] - [Конструкция][Материал][Уплотнения][Спец. требования]
```

**Пример полного обозначения:**
```
А 5 7 - 6205 - 2RS Е Ш2
│ │ │   │      │   │  └─ Специальные требования (шум/вибрация)
│ │ │   │      │   └──── Материал сепаратора
│ │ │   │      └──────── Уплотнения
│ │ │   └─────────────── Основное обозначение
│ │ └─────────────────── Зазор
│ └───────────────────── Класс точности
└─────────────────────── Категория

Читается: "А пять семь тире шесть две ноль пять тире два эр эс е ша два"
```

### Структура основного обозначения

Основное обозначение состоит из **3-7 цифр**:

```
XX Y Z ZZ
│  │ │ └─ Внутренний диаметр (2 цифры)
│  │ └─── Серия ширины (1 цифра)
│  └───── Серия диаметров (1 цифра)
└──────── Тип подшипника (0, 1 или 2 цифры)
```

#### Коды типов подшипников (первые 1-2 цифры)

| Код | Тип подшипника | ГОСТ |
|-----|----------------|------|
| **0** | Шариковый радиальный однорядный | ГОСТ 8338 |
| **1** | Шариковый радиальный двухрядный сферический | ГОСТ 5720 |
| **2** | Роликовый с короткими цилиндрическими роликами | ГОСТ 8328 |
| **3** | Роликовый двухрядный сферический | ГОСТ 24696 |
| **4** | Роликовый игольчатый | ГОСТ 4060 |
| **5** | Роликовый с витыми роликами | — |
| **6** | Шариковый радиальный однорядный | ГОСТ 8338 |
| **7** | Роликовый конический | ГОСТ 27365 |
| **8** | Шариковый упорный | ГОСТ 7872 |
| **9** | Роликовый упорный | ГОСТ 6874 |
| **36** | Шариковый радиально-упорный однорядный | ГОСТ 831 |
| **46** | Шариковый радиально-упорный двухрядный | ГОСТ 832 |
| **66** | Шариковый радиально-упорный с четырёхточечным контактом | — |

**Примечание:** Код **"0"** в начале обозначения обычно **опускается**.

**Примеры:**
- **305** = **0305** (шариковый радиальный однорядный)
- **6205** (код "6" не опускается)

#### Серии диаметров и ширин

**Серия диаметров** (третья цифра справа):

| Серия | D (наружный диаметр) | Применение |
|-------|---------------------|------------|
| **8, 1** | Особо лёгкая | Миниатюрные, приборы |
| **9, 2** | Лёгкая | Стандартное применение |
| **0, 3** | Средняя | Повышенные нагрузки |
| **4** | Тяжёлая | Тяжёлые нагрузки |
| **5** | Особо тяжёлая | Экстремальные нагрузки |

**Серия ширины** (вторая цифра справа):

| Серия | B (ширина) | Применение |
|-------|-----------|------------|
| **7, 8, 9** | Узкая | Ограниченное осевое пространство |
| **0, 1** | Нормальная | Стандартное применение |
| **2, 3, 4** | Широкая | Повышенные осевые нагрузки |

#### Обозначение диаметра отверстия (две последние цифры)

**Правило для d = 20-495 мм:**
```
d (мм) = код × 5
```

| Код | d, мм | Код | d, мм | Код | d, мм |
|-----|-------|-----|-------|-----|-------|
| 00 | 10 | 04 | 20 | 10 | 50 |
| 01 | 12 | 05 | 25 | 12 | 60 |
| 02 | 15 | 06 | 30 | 16 | 80 |
| 03 | 17 | 08 | 40 | 20 | 100 |

**Исключения для d = 10-17 мм:**
- **00** → 10 мм
- **01** → 12 мм
- **02** → 15 мм
- **03** → 17 мм

**Для d < 10 мм:**
Указывается через дробь: **618/8** (d = 8 мм)

**Для d > 500 мм:**
Указывается полностью через дробь: **6/530** (d = 530 мм)

### Префикс: знаки перед основным обозначением

Префикс указывает дополнительные характеристики и записывается **перед** основным обозначением **через дефис**.

#### Последовательность записи префикса

```
[Категория] [Момент] [Класс точности] [Зазор] - ОСНОВНОЕ_ОБОЗНАЧЕНИЕ
```

**Важно:** Порядок записи **строго регламентирован**.

#### 1. Категория подшипника

Обозначается **заглавной буквой** (А, В, С и т.д.).

| Обозначение | Описание |
|-------------|----------|
| **А** | Категория А (специальные требования) |
| **В** | Категория В (особые условия эксплуатации) |
| **С** | Категория С (повышенная надёжность) |

**Применение:** Для подшипников с особыми техническими требованиями.

**Пример:** **А-6205** → подшипник категории А

#### 2. Момент сопротивления вращению

Обозначается буквой **М** или **Т** с цифрой.

| Обозначение | Описание |
|-------------|----------|
| **М** | Ограниченный момент сопротивления вращению |
| **Т** | Малый момент трения |
| **Т1, Т2, Т3** | Различные уровни момента трения |

**Пример:** **М-6205** → подшипник с ограниченным моментом трения

#### 3. Класс точности

Обозначается **цифрой** или **буквой**.

**Классы точности** (в порядке повышения):
```
8 → 7 → 0 (норм.) → 6Х → 6 → 5 → 4 → Т → 2
```

**Правила:**
- Класс **0** (нормальный) **не указывается**
- Указывается перед основным обозначением

| Класс | Обозначение | Точность |
|-------|-------------|----------|
| 0 | не указывается | Нормальная |
| 6 | **6**-6205 | Повышенная |
| 5 | **5**-6205 | Высокая |
| 4 | **4**-6205 | Прецизионная |
| Т | **Т**-6205 | Особо прецизионная |
| 2 | **2**-6205 | Сверхпрецизионная |

**Дополнительное обозначение:**
- **У** после класса точности — повышенная точность по монтажной высоте (для конических роликовых)

**Пример:** **6У-7520** → конический роликовый, класс 6, повышенная точность по высоте

#### 4. Радиальный зазор

Обозначается **цифрой** (1-9).

**Группы зазоров** (в порядке увеличения):
```
1 → 6 → 2 → нормальная → 7 → 8 → 9
```

**Правила:**
- Нормальная группа **не указывается**
- Указывается перед классом точности

| Группа | Относительный зазор | Применение |
|--------|-------------------|------------|
| 6 | −30% | Высокая жёсткость, точность |
| нормальная | 0% (эталон) | Стандартные условия |
| 7 | +30% | Натяги, нагрев |
| 8 | +60% | Высокие температуры |
| 9 | +100% | Экстремальные условия |

**Примеры:**
- **6205** → нормальный зазор
- **7-6205** → увеличенный зазор (группа 7)
- **7-5-6205** → зазор 7, класс точности 5

### Суффикс: знаки после основного обозначения

Суффикс указывает конструктивные особенности и записывается **после** основного обозначения **через дефис**.

#### Последовательность записи суффикса

```
ОСНОВНОЕ_ОБОЗНАЧЕНИЕ - [Конструкция] [Материал сепаратора] [Уплотнения] [Смазка] [Спец. требования]
```

#### 1. Конструктивные изменения

| Обозначение | Описание |
|-------------|----------|
| **К** | Коническое отверстие (конусность 1:12) |
| **К30** | Коническое отверстие (конусность 1:30) |
| **Р** | Канавка и отверстия для смазки на наружном кольце |
| **Р1** | Канавка и отверстия для смазки на внутреннем кольце |
| **У** | Усиленное исполнение |
| **А** | Модифицированная конструкция (вариант А) |
| **В** | Модифицированная конструкция (вариант В) |
| **Ш** | Расширенное внутреннее кольцо |

**Примеры:**
- **6205-К** → коническое отверстие
- **6205-Р** → канавка для смазки на наружном кольце

#### 2. Материал сепаратора

**Правило:** Стальной сепаратор **не обозначается** (стандартный вариант).

| Обозначение | Материал | Описание |
|-------------|----------|----------|
| — | Сталь | Стандартный (не указывается) |
| **Б** | Бронза | Безоловянистая бронза |
| **Б1** | Бронза | Оловянная бронза |
| **Д** | Алюминиевый сплав | Лёгкие сплавы |
| **Д1** | Алюминиевый сплав | Модификация 1 |
| **Е** | Текстолит | Хлопчатобумажная ткань + смола |
| **Е1** | Текстолит | Модификация 1 |
| **Е5** | Полиамид | Стеклонаполненный полиамид |
| **Л** | Латунь | Латунь обычная |
| **Л1** | Латунь | Модификация 1 |
| **Г** | Чугун | Серый чугун |

**Примеры:**
- **6205-Е** → сепаратор из текстолита
- **6205-Е5** → сепаратор из полиамида
- **6205-Б** → сепаратор из бронзы

#### 3. Уплотнения и защита

##### Защитные шайбы (бесконтактные)

| Обозначение | Описание |
|-------------|----------|
| **Н** | Одна защитная шайба (со стороны маркировки) |
| **2Н** | Две защитные шайбы (с обеих сторон) |

**Материал:** Стальной лист, штампованный

**Зазор:** 0,2-0,5 мм между шайбой и кольцом (бесконтактное)

##### Защитные кольца (бесконтактные)

| Обозначение | Описание |
|-------------|----------|
| **Z** | Одно защитное кольцо (со стороны маркировки) |
| **ZZ (2Z)** | Два защитных кольца (с обеих сторон) |

**Материал:** Стальной лист, штампованный и закреплённый в канавке наружного кольца

**Зазор:** 0,2-0,4 мм (бесконтактное)

##### Резиновые уплотнения (контактные)

| Обозначение | Описание |
|-------------|----------|
| **RS** | Одно резиновое уплотнение (со стороны маркировки) |
| **2RS** | Два резиновых уплотнения (с обеих сторон) |
| **RSН** | Одно резиновое уплотнение (низкий момент трения) |
| **2RSН** | Два резиновых уплотнения (низкий момент трения) |
| **RSL** | Одно резиновое уплотнение с низким моментом |
| **2RSL** | Два резиновых уплотнения с низким моментом |

**Материал:** Резина (NBR — акрилонитрил-бутадиеновая)

**Контакт:** Контактное уплотнение (губка прилегает к кольцу)

**Примеры:**
- **6205-Z** → одно защитное кольцо
- **6205-ZZ** → два защитных кольца
- **6205-RS** → одно резиновое уплотнение
- **6205-2RS** → два резиновых уплотнения

#### 4. Смазка

| Обозначение | Описание |
|-------------|----------|
| **С** | Подшипник со смазкой (консистентная смазка) |
| **С1** | Смазка типа 1 |
| **С17** | Смазка типа 17 (высокотемпературная) |

**Примечание:** Тип смазки указывается цифрой после буквы **С**.

**Пример:** **6205-2RS-С17** → два уплотнения, высокотемпературная смазка

#### 5. Специальные требования

##### Требования по шуму и вибрации

| Обозначение | Описание |
|-------------|----------|
| **Ш** | Пониженный уровень шума |
| **Ш1** | Особо низкий уровень шума |
| **Ш2** | Специальные требования по шуму (для электродвигателей) |

##### Температурная стойкость

| Обозначение | Описание |
|-------------|----------|
| **Ю** | Повышенная температурная стабильность размеров |
| **Т** | Термостабилизированные кольца |

##### Материал колец и тел качения

| Обозначение | Описание |
|-------------|----------|
| **Х** | Высокохромистая сталь ШХ15 |
| **Х15** | Хромистая сталь 95Х18 (нержавеющая) |
| **Ц** | Цементируемая сталь |
| **Ю** | Подшипниковая сталь с улучшенными свойствами |

**Примеры:**
- **6205-Ш** → пониженный уровень шума
- **6205-Ш2** → для электродвигателей (специальные требования)

### Комбинирование обозначений

#### Правила комбинирования

1. **Префикс:** записывается в **строгом порядке** слева направо
2. **Суффикс:** записывается в порядке важности характеристик
3. **Дефисы:** разделяют префикс, основное обозначение и суффикс

#### Примеры комбинированных обозначений

**Пример 1:**
```
7-5-6205-2RS-Е-Ш2
```

**Расшифровка:**
- **7** — зазор группы 7 (увеличенный)
- **5** — класс точности 5
- **6205** — шариковый радиальный, лёгкая серия, d = 25 мм
- **2RS** — два резиновых уплотнения
- **Е** — текстолитовый сепаратор
- **Ш2** — специальные требования по шуму

**Пример 2:**
```
6У-7520-А
```

**Расшифровка:**
- **6У** — класс точности 6, повышенная точность по монтажной высоте
- **7520** — конический роликовый, тяжёлая широкая серия, d = 100 мм
- **А** — модифицированная конструкция (вариант А)

**Пример 3:**
```
М-5-36208-К-Б
```

**Расшифровка:**
- **М** — ограниченный момент трения
- **5** — класс точности 5
- **36208** — радиально-упорный, лёгкая серия, d = 40 мм
- **К** — коническое отверстие
- **Б** — бронзовый сепаратор

### Особенности обозначения различных типов

#### Шариковые радиальные однорядные (тип 6)

**Стандарт:** ГОСТ 8338-75

**Структура:** **6YZZ**

**Пример:** **6308**
- Тип: 6 (шариковый радиальный)
- Серия: 3 (средняя)
- Ширина: 0 (нормальная)
- d = 08 × 5 = 40 мм

**Дополнительные обозначения:**
- **-Z, -ZZ** — защитные кольца
- **-RS, -2RS** — резиновые уплотнения
- **-Н, -2Н** — защитные шайбы

#### Роликовые конические (тип 7)

**Стандарт:** ГОСТ 27365-87

**Особенность:** Состоят из **двух комплектов** (продаются отдельно или комплектом)

**Структура:** **7YZZ**

**Пример:** **7208**
- Тип: 7 (конический роликовый)
- Серия: 2 (лёгкая)
- d = 08 × 5 = 40 мм

**Дополнительные обозначения:**
- **А** — модифицированный угол контакта
- **У** — повышенная точность по монтажной высоте
- **К** — комплект из двух колец

**Пример:** **6У-7520А** → класс 6, повышенная точность по высоте, модифицированный угол

#### Радиально-упорные шариковые (тип 36)

**Стандарт:** ГОСТ 831-75

**Структура:** **36YZZ**

**Пример:** **36205**
- Тип: 36 (радиально-упорный однорядный)
- Серия: 2 (лёгкая)
- d = 05 × 5 = 25 мм

**Углы контакта:**
- **36ХХХ** — угол α = 12°
- **46ХХХ** — угол α = 26° (двухрядный)
- **66ХХХ** — угол α = 45° (четырёхточечный контакт)

#### Игольчатые подшипники (тип 4)

**Стандарт:** ГОСТ 4060-78

**Особенность:** Обозначение содержит **прямое указание размеров**

**Структура:** **4[Тип][Размеры]**

**Пример:** **4074115**
- **4** — игольчатый подшипник
- **07** — тип конструкции
- **41** — D = 41 мм
- **15** — B = 15 мм

**Типы:**
- **404** — без колец (только иголки с сепаратором)
- **407** — с одним кольцом
- **408** — с двумя кольцами

#### Сферические двухрядные (тип 1)

**Стандарт:** ГОСТ 5720-75

**Структура:** **1YZZ** или **1YZZZ**

**Пример:** **1310**
- Тип: 1 (двухрядный сферический шариковый)
- Серия: 3 (средняя)
- d = 10 × 5 = 50 мм

**Особенность:** Самоустанавливающиеся (компенсируют перекосы до 2-3°)

### Обозначение невзаимозаменяемых подшипников

Для **комплектных подшипников**, работающих парами или комплектами:

#### Конические роликовые

**Обозначение комплекта:**
```
7520К
```

**К** — комплект из двух колец (внутреннее + наружное с роликами)

**Обозначение отдельных деталей:**
```
7520А — внутренний комплект (конус + ролики + сепаратор)
7520В — наружное кольцо (чашка)
```

#### Радиально-упорные подшипники (установка парами)

**Универсальная схема:**
```
36208 — одиночный подшипник
```

**Обозначение по схеме установки:**
- Устанавливаются парами (дуплексом, триплексом)
- Предварительный натяг регулируется при монтаже

| Характеристика | Старый ГОСТ (до 1991) | Новый ГОСТ 3189-89 |
|----------------|---------------------|-------------------|
| **Класс точности** | Н, П, В, А, С | 0, 6, 5, 4, 2 |
| **Пример** | П-308 | 6-308 |

#### Таблица соответствия классов точности

| Старое обозначение | Новое обозначение | Точность |
|-------------------|-------------------|----------|
| Н | 0 (не указывается) | Нормальная |
| П | 6 | Повышенная |
| В | 5 | Высокая |
| А | 4 | Прецизионная |
| С | 2 | Сверхпрецизионная |

**Пример:**
- Старое: **П-305**
- Новое: **6-305**

### Примеры расшифровки по шагам

#### Пример 1: **6205**

**Шаг 1:** Префикс отсутствует → класс точности 0 (нормальный), зазор нормальный

**Шаг 2:** Основное обозначение **6205**
- **6** — шариковый радиальный однорядный
- **2** — серия диаметров (лёгкая)
- **0** — серия ширины (нормальная)
- **05** — d = 05 × 5 = 25 мм

**Шаг 3:** Суффикс отсутствует → без уплотнений, стальной сепаратор

**Итог:** Стандартный шариковый радиальный подшипник d = 25 мм, D = 52 мм, B = 15 мм

#### Пример 2: **7-5-6205-2RS-Е5**

**Шаг 1:** Префикс **7-5**
- **7** — зазор группы 7 (увеличенный на ~30%)
- **5** — класс точности 5 (высокая точность)

**Шаг 2:** Основное обозначение **6205**
- **6** — шариковый радиальный однорядный
- **2** — серия диаметров (лёгкая)
- **0** — серия ширины (нормальная)
- **05** — d = 25 мм

**Шаг 3:** Суффикс **2RS-Е5**
- **2RS** — два резиновых контактных уплотнения
- **Е5** — сепаратор из стеклонаполненного полиамида

**Итог:** Высокоточный шариковый подшипник d = 25 мм с увеличенным зазором, двумя уплотнениями и полиамидным сепаратором. Для применения при повышенных температурах и натягах.

#### Пример 3: **6У-7520А**

**Шаг 1:** Префикс **6У**
- **6** — класс точности 6 (повышенная точность)
- **У** — повышенная точность по монтажной высоте (для конических)

**Шаг 2:** Основное обозначение **7520**
- **7** — роликовый конический
- **5** — серия диаметров (тяжёлая)
- **2** — серия ширины (широкая)
- **20** — d = 20 × 5 = 100 мм

**Шаг 3:** Суффикс **А**
- **А** — модифицированная конструкция (изменённый угол контакта)

**Итог:** Конический роликовый подшипник d = 100 мм, класс точности 6 с повышенной точностью по монтажной высоте, модифицированный угол контакта.

### Правила записи и чтения

#### Правило 1: Порядок элементов строго определён

**Неправильно:** 6205-5-7-2RS  
**Правильно:** 7-5-6205-2RS

#### Правило 2: Дефисы обязательны

**Неправильно:** 56205  
**Правильно:** 5-6205

**Исключение:** Префикс без дефиса для старых обозначений: **А6205** (категория А)

#### Правило 3: Класс точности 0 не указывается

**Неправильно:** 0-6205  
**Правильно:** 6205

#### Правило 4: Нормальный зазор не указывается

**Неправильно:** Н-6205  
**Правильно:** 6205

#### Правило 5: Стальной сепаратор не обозначается

**Неправильно:** 6205-Сталь  
**Правильно:** 6205

### Сравнение ГОСТ 3189-89 и предыдущих стандартов

| **Уплотнения** | Различные обозначения | Унифицированные (Z, RS) |

### Контрольные вопросы для проверки понимания

1. **Как прочитать обозначение 7-5-6308-2RS-Е5-Ш2?**
   - Зазор: группа 7 (увеличенный)
   - Класс точности: 5 (высокая)
   - Тип: шариковый радиальный
   - d = 40 мм, D = 90 мм, B = 23 мм
   - Уплотнения: два резиновых
   - Сепаратор: полиамид
   - Требования: пониженный шум

2. **Какая разница между 6205-Z и 6205-RS?**
   - **6205-Z**: защитное кольцо (бесконтактное, стальное)
   - **6205-RS**: резиновое уплотнение (контактное, герметичное)

3. **Почему в обозначении 305 опущен первый ноль?**
   - По правилам ГОСТ, код типа "0" в начале обозначения опускается
   - **0305** = **305**

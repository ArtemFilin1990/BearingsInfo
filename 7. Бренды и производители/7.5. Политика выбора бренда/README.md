# 7.5. Политика выбора бренда

## Назначение

Руководство по принятию решения о выборе производителя подшипников с учетом технических требований, бюджета, доступности и рисков.

## Ключевые вопросы

- По каким критериям выбирать производителя подшипников?
- Когда необходимы подшипники премиум-класса, а когда допустимы бюджетные?
- Как учитывать факторы риска при выборе бренда?
- Какие производители рекомендованы для критичных применений (авиация, медтехника, энергетика)?

- **Критерии выбора бренда**:
  - Технические требования (ресурс, точность, скорость, нагрузка, среда)
  - Бюджетные ограничения

  - Наличие технической поддержки
  - Гарантии и сертификация
- **Матрица решений**: таблица "Применение → Рекомендуемый tier бренда"
  - Критичные применения → только Tier 1 (SKF, FAG, NSK)
  - Промышленное оборудование → Tier 1-2
  - Общепромышленные механизмы → Tier 2-3
  - Некритичные узлы → Tier 3
- **Факторы риска**: подделки, серый импорт, несертифицированные партии
- Рекомендации по работе с поставщиками

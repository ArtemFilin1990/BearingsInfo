# 4.1. Нагрузки и эквивалентные нагрузки

## Назначение

Описание типов нагрузок, действующих на подшипники качения (радиальные, осевые, комбинированные, динамические), методов их расчёта и приведения к эквивалентной динамической нагрузке для определения ресурса подшипника по стандартам ГОСТ и ISO.

## Ключевые вопросы

- Какие типы нагрузок действуют на подшипники и как их определить?
- Что такое эквивалентная динамическая нагрузка P и зачем она нужна?
- Как рассчитать эквивалентную нагрузку для радиальных и радиально-упорных подшипников?
- Какие коэффициенты X, Y используются в расчёте и от чего зависят?
- Как учитывать переменные и ударные нагрузки в расчётах ресурса?
- В чём разница между статической и динамической грузоподъёмностью?

## Содержание

### Типы нагрузок на подшипники

Подшипники качения воспринимают внешние силы и моменты, которые можно классифицировать следующим образом:

#### 1. **Радиальная нагрузка Fr**

**Определение:** Сила, действующая перпендикулярно оси вала (в радиальном направлении).

**Источники:**
- Вес ротора, вала, шкивов, зубчатых колёс
- Натяжение ремня, цепи
- Сила резания (станки)
- Реакции в зубчатом зацеплении
- Дисбаланс вращающихся частей

**Типовые примеры:**
- Электродвигатель: вес ротора + натяжение ремня
- Редуктор: усилие от зубчатого зацепления
- Насос: вес рабочего колеса + гидравлическая сила

**Расчёт:** Определяется из статики (уравнения равновесия) или динамики (для вращающихся валов).

#### 2. **Осевая нагрузка Fa**

**Определение:** Сила, действующая вдоль оси вала (в осевом направлении).

**Источники:**
- Винтовая передача (осевая сила винта)
- Зубчатое зацепление (косозубые, конические шестерни)
- Гидравлическое давление (насосы, компрессоры)
- Температурное расширение вала
- Магнитные силы (электродвигатели)

**Типовые примеры:**
- Косозубая передача: осевая составляющая силы зацепления
- Винтовой компрессор: осевая сила от винта
- Осевой вентилятор: давление воздуха на лопатки

**Восприятие осевой нагрузки:**
- **Шариковые радиальные:** ограниченная осевая нагрузка
- **Радиально-упорные:** значительная осевая + радиальная
- **Упорные:** только или преимущественно осевая
- **Конические роликовые:** комбинированная (радиальная + осевая)

#### 3. **Комбинированная нагрузка (Fr + Fa)**

Большинство подшипниковых узлов работают под действием **комбинированной** радиально-осевой нагрузки.

**Примеры:**
- Коробка передач: радиальная от зацепления + осевая от косозубых колёс
- Вентилятор: вес ротора (радиальная) + аэродинамическая сила (осевая)
- Ступица автомобиля: вес автомобиля (радиальная) + боковая сила в повороте (осевая)

#### 4. **Моментные нагрузки**

**Опрокидывающий момент M:** Создаёт неравномерное распределение нагрузки на тела качения.

**Источники:**
- Консольное расположение груза (шкив, звёздочка на консоли вала)
- Несоосность опор
- Перекосы при монтаже

**Влияние:** Снижает ресурс подшипника, требуется учёт в расчёте (коэффициент нагрузки).

#### 5. **Динамические и ударные нагрузки**

**Характер нагрузки:**
- **Постоянная:** не изменяется во времени (вес ротора)
- **Переменная:** изменяется по величине и/или направлению (зубчатое зацепление, дисбаланс)
- **Ударная:** кратковременная импульсная нагрузка (дробилки, прессы)

**Учёт в расчёте:** Коэффициент динамичности нагрузки (см. ниже).

### Грузоподъёмность подшипников

#### Базовая динамическая грузоподъёмность C

**Определение (ISO 281, ГОСТ 18855):** Постоянная радиальная нагрузка (для упорных — осевая), которую подшипник может выдержать при базовом ресурсе L₁₀ = 1 миллион оборотов с вероятностью разрушения 10%.

**Обозначения:**
- **C** — для радиальных подшипников (радиальная нагрузка)
- **Ca** — для упорных подшипников (осевая нагрузка)

**Единицы:** кН (килоньютоны), Н (ньютоны)

**Значения C в каталогах:** Указывается производителем для каждого подшипника (зависит от размера, типа, конструкции).

**Примеры:**
- Подшипник 6206: C ≈ 19,5 кН
- Подшипник 6306: C ≈ 29,6 кН
- Подшипник NU 312: C ≈ 172 кН (цилиндрический роликовый)

#### Базовая статическая грузоподъёмность C₀

**Определение (ISO 76, ГОСТ 18854):** Статическая нагрузка, при которой возникает контактное напряжение, соответствующее остаточной деформации 0,0001 диаметра тела качения.

**Применение:**
- Подшипники, работающие с медленным вращением или качательным движением
- Проверка пиковых нагрузок (пуск, останов, ударные нагрузки)

**Критерий:** Коэффициент статической безопасности **S₀ = C₀ / P₀** (обычно S₀ ≥ 1,0–2,0)

### Эквивалентная динамическая нагрузка P

#### Концепция эквивалентной нагрузки

При комбинированной радиально-осевой нагрузке необходимо **привести** её к эквивалентной радиальной (или осевой для упорных) нагрузке P, которая при тех же условиях обеспечивает тот же ресурс, что и реальная комбинированная нагрузка.

**Определение (ISO 281, ГОСТ 18855):**  
Эквивалентная динамическая нагрузка P — постоянная радиальная нагрузка, при которой ресурс подшипника равен ресурсу при реальных условиях нагружения.

#### Формулы расчёта P

**1. Радиальные шарикоподшипники (однорядные, двухрядные)**

```
P = X · Fr + Y · Fa    (если Fa/Fr > e)
P = Fr                 (если Fa/Fr ≤ e)
```

Где:
- **P** — эквивалентная динамическая радиальная нагрузка, Н
- **Fr** — радиальная нагрузка, Н
- **Fa** — осевая нагрузка, Н
- **X** — коэффициент радиальной нагрузки (обычно 0,56 для шариковых)
- **Y** — коэффициент осевой нагрузки (зависит от угла контакта α и Fa/C₀)
- **e** — коэффициент влияния осевой нагрузки (граничное значение Fa/Fr)

**Значения X, Y, e:** Приводятся в таблицах стандартов (ГОСТ 18855, ISO 281) и каталогах производителей в зависимости от:
- Типа подшипника (радиальный, радиально-упорный)
- Угла контакта α (для радиально-упорных: 15°, 25°, 40°)
- Отношения Fa/C₀

**Пример для радиального шарикоподшипника (глубокий желоб):**
- При Fa/Fr ≤ 0,35: X = 1, Y = 0 → P = Fr
- При Fa/Fr > 0,35: X = 0,56, Y ≈ 1,5–2,0 (зависит от подшипника)

**2. Радиально-упорные шарикоподшипники**

```
P = X · Fr + Y · Fa
```

**Значения X, Y для радиально-упорных:**
- Зависят от угла контакта α (15°, 25°, 40°)
- Зависят от отношения Fa/Fr

**Типовые значения (угол 40°):**
- Fa/Fr < 0,68: X = 1, Y = 0,92
- Fa/Fr ≥ 0,68: X = 0,41, Y = 1,52

**3. Роликовые цилиндрические подшипники N, NU**

Не воспринимают осевую нагрузку:
```
P = Fr
```

**Типы NJ, NUP (с осевой фиксацией):**
```
P = Fr + Y₁ · Fa    (если Fa действует)
```

Где Y₁ — коэффициент осевой нагрузки (обычно 0,4–0,6).

**4. Конические роликоподшипники**

```
P = X · Fr + Y · Fa    (для однорядных, установленных парами)
```

**Значения X, Y:** Зависят от угла конуса α, схемы установки (X, O, тандем), отношения Fa/Fr.

**Типовые значения (угол 15°–20°):**
- Fa/Fr < 1,5: X = 1, Y ≈ 0,4–0,6
- Fa/Fr ≥ 1,5: X ≈ 0,67, Y ≈ 1,0–1,5

**5. Сферические роликоподшипники**

```
P = Fr + Y₁ · Fa    (если Fa/Fr ≤ e)
P = 0,67 · Fr + Y₂ · Fa    (если Fa/Fr > e)
```

Где:
- Y₁, Y₂ — коэффициенты осевой нагрузки (из таблиц)
- e — граничное значение (обычно 0,2–0,4)

**6. Упорные подшипники**

```
P = Fa    (осевая нагрузка)
```

Для упорно-радиальных:
```
P = X · Fr + Y · Fa
```

### Коэффициенты нагрузки

При переменных, ударных нагрузках и других факторах вводятся дополнительные коэффициенты.

#### Коэффициент динамичности нагрузки Kd

Учитывает характер нагрузки:

| Условия работы | Kd |
|----------------|-----|
| Спокойная нагрузка, отсутствие ударов (электродвигатели, вентиляторы) | 1,0 |
| Нормальная нагрузка, лёгкие толчки (редукторы, насосы) | 1,0–1,3 |
| Нагрузка с умеренными ударами (подъёмники, конвейеры) | 1,3–1,5 |
| Сильные удары (дробилки, прессы, прокатные станы) | 1,5–3,0 |

**Формула с учётом коэффициента:**
```
P = Kd · (X · Fr + Y · Fa)
```

#### Коэффициент надёжности Ka

Учитывает требуемую надёжность (вероятность безотказной работы):

| Требуемая надёжность | Ka |
|----------------------|-----|
| 90% (стандартный L₁₀) | 1,0 |
| 95% (L₅) | 0,62 |
| 96% (L₄) | 0,53 |
| 97% (L₃) | 0,44 |
| 98% (L₂) | 0,33 |
| 99% (L₁) | 0,21 |

**Применение:** Умножают расчётный ресурс L₁₀ на Ka для получения Lₙ с требуемой надёжностью.

### Переменные нагрузки

Если нагрузка изменяется во времени (циклическая, ступенчатая), необходимо привести её к эквивалентной постоянной.

#### Метод эквивалентной нагрузки для переменного режима

**Формула:**
```
        ┌────────────────────────────────────
Pm =  ³√ (P₁³·n₁·q₁ + P₂³·n₂·q₂ + ... + Pᵢ³·nᵢ·qᵢ) / Σ(nᵢ·qᵢ)
```

Где:
- **Pm** — средняя эквивалентная нагрузка
- **Pᵢ** — нагрузка на i-м режиме
- **nᵢ** — частота вращения на i-м режиме, об/мин
- **qᵢ** — доля времени работы на i-м режиме (в долях единицы, Σqᵢ = 1)

**Примечание:** Показатель степени 3 — для шариковых подшипников, 10/3 — для роликовых.

**Пример:**  
Подшипник работает в двух режимах:
- Режим 1: P₁ = 5000 Н, n₁ = 1500 об/мин, q₁ = 0,7 (70% времени)
- Режим 2: P₂ = 8000 Н, n₂ = 3000 об/мин, q₂ = 0,3 (30% времени)

```
Pm = ³√[(5000³·1500·0,7 + 8000³·3000·0,3) / (1500·0,7 + 3000·0,3)]
Pm ≈ 6400 Н
```

### Примеры расчёта эквивалентной нагрузки

#### Пример 1: Радиальный шарикоподшипник 6208

**Дано:**
- Подшипник 6208
- Fr = 3000 Н
- Fa = 800 Н
- C = 32,5 кН (из каталога)
- C₀ = 17,8 кН

**Решение:**
1. Определяем Fa/C₀ = 800 / 17800 ≈ 0,045
2. По таблице ГОСТ 18855 для Fa/C₀ ≈ 0,04: e ≈ 0,24
3. Проверяем Fa/Fr = 800 / 3000 ≈ 0,27 > 0,24
4. Так как Fa/Fr > e, используем: P = X·Fr + Y·Fa
5. Из таблицы: X = 0,56, Y ≈ 1,8 (для Fa/C₀ ≈ 0,04)
6. **P = 0,56 · 3000 + 1,8 · 800 = 1680 + 1440 = 3120 Н**

#### Пример 2: Радиально-упорный подшипник 46210 (угол 40°)

**Дано:**
- Fr = 5000 Н
- Fa = 6000 Н
- C = 52 кН

**Решение:**
1. Определяем Fa/Fr = 6000 / 5000 = 1,2
2. Для угла 40°, при Fa/Fr ≥ 0,68: X = 0,41, Y = 1,52
3. **P = 0,41 · 5000 + 1,52 · 6000 = 2050 + 9120 = 11170 Н**

#### Пример 3: Конический роликоподшипник 7208 (схема X)

**Дано:**
- Fr = 10000 Н
- Fa = 3000 Н (осевая нагрузка на опору)
- Установка: схема «X» (два подшипника)

**Решение:**
1. Для схемы «X»: каждый подшипник воспринимает радиальную + половину осевой нагрузки
2. Fr₁ = Fr₂ = 10000 Н
3. Fa₁ = Fa₂ = 3000 / 2 = 1500 Н (равномерное распределение)
4. Fa/Fr = 1500 / 10000 = 0,15
5. По таблице для Fa/Fr < 0,3: X = 1, Y = 0,4
6. **P = 1 · 10000 + 0,4 · 1500 = 10000 + 600 = 10600 Н (для каждого подшипника)**

### Связь между P, C и ресурсом L₁₀

**Формула базового ресурса (ISO 281, ГОСТ 18855):**

```
       ⎛ C ⎞ᵖ
L₁₀ = ⎜───⎟  · 10⁶ оборотов
       ⎝ P ⎠
```

Где:
- **L₁₀** — базовый ресурс (в миллионах оборотов)
- **C** — базовая динамическая грузоподъёмность, Н
- **P** — эквивалентная динамическая нагрузка, Н
- **p** — показатель степени (p = 3 для шариковых, p = 10/3 для роликовых)

**В часах:**
```
        ⎛ C ⎞ᵖ     10⁶
L₁₀h = ⎜───⎟  · ───────  часов
        ⎝ P ⎠    60 · n
```

Где **n** — частота вращения, об/мин.

**Пример:**  
Подшипник 6208, C = 32,5 кН, P = 3120 Н, n = 1500 об/мин:
```
L₁₀ = (32500 / 3120)³ · 10⁶ ≈ 1100 млн. оборотов
L₁₀h = 1100 · 10⁶ / (60 · 1500) ≈ 12200 часов
```

### Рекомендации по расчёту нагрузок

**Последовательность расчёта:**

1. Определить радиальную Fr и осевую Fa нагрузки из расчёта механизма
2. Выбрать тип подшипника (радиальный, радиально-упорный, конический и т.д.)
3. Определить коэффициенты X, Y из таблиц ГОСТ/ISO или каталогов
4. Рассчитать эквивалентную нагрузку P
5. Учесть коэффициент динамичности Kd (при необходимости)
6. Для переменных режимов — рассчитать среднюю нагрузку Pm
7. Проверить статическую нагрузку P₀ ≤ C₀ (особенно при пусках, ударах)
8. Рассчитать ресурс L₁₀ и сравнить с требуемым

**Типовые ошибки:**
- Игнорирование осевой нагрузки (особенно в косозубых передачах)
- Использование неверных коэффициентов X, Y (не соответствующих типу подшипника)
- Недооценка динамических нагрузок (коэффициент Kd = 1 при ударах)
- Неправильный учёт переменных режимов (простое среднее вместо кубического корня)
- Превышение статической грузоподъёмности C₀ (приводит к остаточным деформациям)

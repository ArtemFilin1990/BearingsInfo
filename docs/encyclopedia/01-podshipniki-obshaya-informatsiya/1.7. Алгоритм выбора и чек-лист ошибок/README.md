# 1.7. Алгоритм выбора и чек-лист ошибок

## Назначение

Пошаговый алгоритм выбора подшипника для конкретного применения, включая последовательность расчётов, принятия решений и проверочный чек-лист типовых ошибок при подборе и монтаже подшипников.

## Ключевые вопросы

- Какова последовательность действий при выборе подшипника?
- Как определить тип подшипника по условиям нагружения?
- Какие параметры необходимо учесть при расчёте подшипника?
- Какие типовые ошибки допускаются при выборе и монтаже подшипников?
- Как построить дерево решений для выбора оптимального подшипника?
- Какие проверки необходимо выполнить перед установкой подшипника?

## Содержание

### Общая методология выбора

Выбор подшипника — это многоэтапный процесс, требующий последовательного анализа условий эксплуатации, расчётных проверок и сравнения альтернативных решений.

**Основные этапы:**
1. Анализ условий работы
2. Определение типа подшипника
3. Предварительный подбор размера
4. Расчётная проверка ресурса и нагрузок
5. Проверка предельной скорости
6. Учёт специальных условий
7. Выбор посадок и способа монтажа
8. Итоговая верификация

### АЛГОРИТМ ВЫБОРА ПОДШИПНИКА

#### ШАГ 1. Анализ условий эксплуатации

**1.1. Определение нагрузки**

**Задача:** Определить величину и направление нагрузки на опору

**Действия:**
- Рассчитать или измерить силы, действующие на вал
- Определить радиальную составляющую **Fr** (Н)
- Определить осевую составляющую **Fa** (Н)
- Определить характер нагрузки (постоянная, переменная, ударная)

**Соотношение осевой и радиальной нагрузки:**

| Fa / Fr | Рекомендуемый тип подшипника |
|---------|------------------------------|
| Fa = 0 | Радиальный (6000, NU, N) |
| 0 < Fa/Fr < 0,3 | Радиальный шариковый (6000) |
| 0,3 < Fa/Fr < 1,5 | Радиально-упорный (36000, 7000) |
| Fa/Fr > 1,5 | Упорно-радиальный (9000) |
| Fr = 0 | Упорный (51000, 52000) |

**1.2. Определение частоты вращения**

- Номинальная частота вращения **n** (об/мин)
- Диапазон изменения скорости (если переменная)
- Режим работы (непрерывный, периодический)

**1.3. Условия окружающей среды**

- **Температура:** -30...+120°C (стандарт), выше/ниже (специальные)
- **Загрязнения:** чистые условия, пыль, влага, абразивы
- **Вибрации:** низкие, средние, высокие
- **Агрессивные среды:** да/нет

**1.4. Требования к точности**

- **Радиальное биение вала:** стандартное / повышенное
- **Осевое биение:** допустимое значение
- **Класс точности:** 0 (Normal), 6 (P6), 5 (P5), 4 (P4), 2 (P2)

**1.5. Конструктивные ограничения**

- Доступный внутренний диаметр **d** (диаметр вала)
- Ограничения по наружному диаметру **D** (размер корпуса)
- Ограничения по ширине **B**
- Тип монтажа (открытый доступ, ограниченное пространство)

#### ШАГ 2. Определение типа подшипника

**Дерево решений по выбору типа:**

```
┌─ Направление нагрузки ─────────────────────────────┐
│                                                     │
├─ РАДИАЛЬНАЯ (Fr, Fa мала или отсутствует)          │
│  ├─ Низкая/средняя нагрузка, высокая скорость      │
│  │  └─ Шариковый радиальный (6000)                 │
│  ├─ Высокая нагрузка, средняя скорость             │
│  │  └─ Роликовый цилиндрический (NU, N, NJ)        │
│  └─ Высокая нагрузка + перекосы вала               │
│     └─ Роликовый сферический (3000)                │
│                                                     │
├─ КОМБИНИРОВАННАЯ (Fr + Fa)                         │
│  ├─ Fa/Fr = 0,3-1,5, односторонняя осевая          │
│  │  ├─ Средняя/высокая нагрузка                    │
│  │  │  └─ Конический роликовый (7000)              │
│  │  └─ Средняя нагрузка, высокая скорость          │
│  │     └─ Шариковый радиально-упорный (36000)      │
│  └─ Осевая нагрузка в двух направлениях            │
│     └─ Двухрядный шариковый (4000)                 │
│                                                     │
└─ ОСЕВАЯ (Fa преобладает или Fr = 0)                │
   ├─ Только осевая, низкая скорость                 │
   │  └─ Шариковый упорный (51000)                   │
   ├─ Только осевая, средняя скорость                │
   │  └─ Роликовый упорный (81000)                   │
   └─ Осевая + небольшая радиальная                  │
      └─ Упорно-радиальный (9000)                    │
```

**Специальные условия:**

| Условие | Тип подшипника |
|---------|----------------|
| **Перекосы вала (прогиб, несоосность)** | Сферические роликовые (3000), сферические шариковые (1000) |
| **Компактные габариты (малая ширина)** | Игольчатые (NA, NKI), тонкостенные (61800, 68) |
| **Высокая жёсткость** | Роликовые цилиндрические (NU), конические (7000) |
| **Высокая скорость (n > 10000 об/мин)** | Шариковые (6000), керамические гибридные |
| **Осевая регулировка** | Конические (7000), радиально-упорные (36000) |

#### ШАГ 3. Предварительный подбор размера

**3.1. Выбор внутреннего диаметра d**

- Диаметр вала определяет **d** подшипника
- Стандартный ряд диаметров (ГОСТ 3478-79): 3, 4, 5, 6, 7, 8, 9, 10, 12, 15, 17, 20, 25, 30, 35, 40, 45, 50, 55, 60, 65, 70, 75, 80...

**Связь с обозначением подшипника:**

| Код диаметра | d, мм | Пример |
|--------------|-------|--------|
| 00 | 10 | 6200 → d=10 |
| 01 | 12 | 6201 → d=12 |
| 02 | 15 | 6202 → d=15 |
| 03 | 17 | 6203 → d=17 |
| 04 | 20 | 6204 → d=20 |
| 05 | 25 | 6205 → d=25 |
| 06 | 30 | 6206 → d=30 |

Для d ≥ 20 мм: **d = (код диаметра) × 5** (например, 08 → 40 мм)

**3.2. Выбор серии (диаметр D и ширина B)**

**Серии по диаметру:** 8, 9, 0, 1, 2, 3, 4 (от узких к широким при одинаковом d)

**Серии по ширине:** 8, 0, 1, 2, 3, 4, 5, 6

**Пример серий для d = 25 мм:**

| Обозначение | Серия | D (мм) | B (мм) | Применение |
|-------------|-------|--------|--------|------------|
| 61805 | Особо лёгкая | 37 | 7 | Миниатюрные механизмы |
| 16005 | Сверхлёгкая | 47 | 8 | Малая нагрузка |
| 6005 | Лёгкая | 47 | 12 | Средняя нагрузка |
| 6205 | Средняя | 52 | 15 | Стандартное применение |
| 6305 | Тяжёлая | 62 | 17 | Повышенная нагрузка |

**Правило выбора серии:**
- При ограничении по D → выбирать узкие серии (8, 9, 0)
- При высокой нагрузке → выбирать широкие серии (2, 3, 4)

#### ШАГ 4. Расчёт требуемого ресурса и грузоподъёмности

**4.1. Расчёт эквивалентной динамической нагрузки**

**Формула (ГОСТ 18855-2013):**

**P = X · Fr + Y · Fa**

где:
- **P** — эквивалентная динамическая нагрузка, Н
- **Fr** — радиальная нагрузка, Н
- **Fa** — осевая нагрузка, Н
- **X** — коэффициент радиальной нагрузки (из каталога)
- **Y** — коэффициент осевой нагрузки (из каталога)

**Для шариковых радиальных подшипников (6000):**

| Условие | X | Y |
|---------|---|---|
| Fa/C₀ ≤ e | 1 | 0 |
| Fa/C₀ > e | 0,56 | зависит от Fa/C₀ |

**4.2. Расчёт требуемой динамической грузоподъёмности**

**Формула:**

**C = P · (Lh · n / 500)^(1/p)**

или

**C = P · (L₁₀ / 10⁶)^(1/p)**

где:
- **C** — требуемая динамическая грузоподъёмность, Н
- **P** — эквивалентная динамическая нагрузка, Н
- **Lh** — требуемый ресурс в часах
- **n** — частота вращения, об/мин
- **L₁₀** — ресурс в миллионах оборотов
- **p** — показатель степени (3 для шариковых, 10/3 для роликовых)

**Пример расчёта:**

Дано:
- Fr = 2000 Н
- Fa = 500 Н
- n = 1500 об/мин
- Требуемый ресурс: Lh = 20000 ч

Для шарикового радиального подшипника:
- X = 0,56; Y = 1,2 (из таблиц)
- P = 0,56 × 2000 + 1,2 × 500 = 1720 Н
- L₁₀ = Lh × n × 60 / 10⁶ = 20000 × 1500 × 60 / 10⁶ = 1800 млн об.
- C = 1720 × (1800)^(1/3) = 1720 × 12,16 ≈ **20900 Н**

**Вывод:** Требуется подшипник с C ≥ 20900 Н

**4.3. Проверка статической грузоподъёмности**

Для подшипников, работающих при медленном вращении, частых пусках/остановках или качательном движении:

**P₀ = X₀ · Fr + Y₀ · Fa ≤ C₀**

где:
- **P₀** — эквивалентная статическая нагрузка, Н
- **C₀** — статическая грузоподъёмность подшипника (из каталога), Н
- **X₀, Y₀** — коэффициенты (обычно X₀=0,6, Y₀=0,5 для шариковых)

**Условие:** **P₀ / C₀ ≤ 1** (рекомендуется ≤ 0,5 для повышенной надёжности)

#### ШАГ 5. Проверка предельной скорости

**5.1. Расчёт допустимой скорости**

**Предельная частота вращения** указана в каталогах для:
- Пластичной смазки (обычно ниже)
- Масляной смазки (обычно выше на 30-50%)

**Формула проверки:**

**n ≤ n_пред · k_смазки · k_темп · k_нагр**

где:
- **n_пред** — предельная частота из каталога, об/мин
- **k_смазки** — коэффициент типа смазки (0,7 для пластичной, 1,0 для масляной)
- **k_темп** — коэффициент температуры (1,0 при <80°C, снижается при повышении)
- **k_нагр** — коэффициент нагрузки (1,0 при P/C < 0,1, снижается при увеличении)

**Пример:**

Подшипник 6205: n_пред = 18000 об/мин (масло)

При пластичной смазке и температуре 100°C:
- n_доп = 18000 × 0,7 × 0,8 = **10080 об/мин**

**5.2. Параметр быстроходности**

**DN = d_ср × n**

где:
- **d_ср** — средний диаметр подшипника, мм: d_ср = (d + D) / 2
- **n** — частота вращения, об/мин

**Предельные значения DN:**

| Тип подшипника | DN_max (мм·об/мин) |
|----------------|--------------------|
| Шариковые радиальные | 400 000 - 1 000 000 |
| Роликовые цилиндрические | 300 000 - 500 000 |
| Конические роликовые | 200 000 - 350 000 |
| Керамические гибридные | 2 000 000 - 3 000 000 |

#### ШАГ 6. Учёт специальных условий

**6.1. Выбор класса точности**

| Применение | Класс (ГОСТ) | Класс (ISO) | ABEC |
|------------|--------------|-------------|------|
| Общепромышленное | 0 | P0 | ABEC-1 |
| Электродвигатели, насосы | 6 | P6 | ABEC-3 |
| Станки, коробки передач | 5 | P5 | ABEC-5 |
| Прецизионные шпиндели | 4, 2 | P4, P2 | ABEC-7, 9 |

**6.2. Выбор радиального зазора**

| Обозначение | Зазор | Применение |
|-------------|-------|------------|
| C2 | Меньше нормального | Высокая точность, низкая температура |
| Normal (CN) | Нормальный | Стандартное применение |
| C3 | Больше нормального | Высокая температура, натяг на валу |
| C4 | Увеличенный | Очень высокая температура, большой натяг |

**6.3. Выбор уплотнений**

| Условия | Тип защиты | Обозначение |
|---------|------------|-------------|
| Чистые условия, дозаправка смазкой | Открытый | - |
| Лёгкая пыль | Защитные шайбы | Z, ZZ |
| Пыль, влага | Контактные уплотнения | RS, 2RS |
| Высокая скорость + защита | Бесконтактные уплотнения | RZ, 2RZ |

**6.4. Материалы**

| Условия | Материал |
|---------|----------|
| Температура > +150°C | Высокотемпературная сталь, керамика |
| Агрессивные среды | Нержавеющая сталь (95Х18) |
| Высокая скорость | Гибридные (керамические тела качения) |
| Электроизоляция | Керамические покрытия |

#### ШАГ 7. Выбор посадок и способа монтажа

**7.1. Посадки внутреннего кольца на вал**

| Условие нагружения кольца | Посадка вала | Пример |
|---------------------------|--------------|--------|
| Местное (кольцо неподвижно относительно нагрузки) | Переходная/скользящая | js6, k6 |
| Циркуляционное (кольцо вращается относительно нагрузки) | С натягом | m6, n6, p6 |

**7.2. Посадки наружного кольца в корпусе**

| Условие нагружения кольца | Посадка корпуса | Пример |
|---------------------------|-----------------|--------|
| Местное (кольцо неподвижно относительно нагрузки) | Скользящая | H7, H8 |
| Циркуляционное (кольцо вращается относительно нагрузки) | Переходная/с натягом | K7, M7, N7 |

**7.3. Осевая фиксация**

- **Плавающая опора:** Один подшипник фиксирован осево, второй свободен (компенсация температурных удлинений)
- **Фиксированная опора:** Оба подшипника зафиксированы (для коротких валов)

**Элементы фиксации:**
- Упорные бурты на валу/корпусе
- Стопорные кольца
- Гайки с стопорной шайбой
- Закрепительные/стяжные втулки

#### ШАГ 8. Итоговая верификация

**Проверочный список:**

- [ ] Рассчитана эквивалентная нагрузка P
- [ ] Проверена динамическая грузоподъёмность: C_подшипника ≥ C_требуемая
- [ ] Проверена статическая грузоподъёмность: C₀_подшипника ≥ P₀
- [ ] Проверена предельная скорость: n ≤ n_пред
- [ ] Выбран класс точности
- [ ] Выбраны посадки (вал и корпус)
- [ ] Определён тип смазки
- [ ] Выбран тип уплотнений
- [ ] Определён способ осевой фиксации
- [ ] Проверена доступность подшипника (серийное производство, доступность у поставщиков)

### ЧЕК-ЛИСТ ТИПОВЫХ ОШИБОК

#### ОШИБКИ НА ЭТАПЕ ВЫБОРА

**❌ ОШИБКА 1: Неправильное определение направления нагрузки**

**Проблема:** Выбор радиального подшипника при наличии значительной осевой нагрузки

**Последствия:** Преждевременный выход из строя, разрушение сепаратора

**Правильно:** 
- Проанализировать обе составляющие нагрузки (Fr и Fa)
- При Fa/Fr > 0,3 использовать радиально-упорные или конические подшипники

---

**❌ ОШИБКА 2: Недооценка требуемого ресурса**

**Проблема:** Выбор подшипника по статической нагрузке без расчёта динамической грузоподъёмности

**Последствия:** Износ, усталостное выкрашивание дорожек качения

**Правильно:**
- Рассчитать требуемый ресурс в часах (Lh) или миллионах оборотов (L₁₀)
- Подобрать подшипник с запасом по грузоподъёмности (коэффициент запаса 1,5-2,0 для ответственных узлов)

---

**❌ ОШИБКА 3: Игнорирование предельной скорости**

**Проблема:** Использование роликовых подшипников на частотах, близких к предельным

**Последствия:** Перегрев, разрушение сепаратора, заклинивание

**Правильно:**
- Проверить n_рабочая < 0,7 × n_предельная (запас 30%)
- При высоких скоростях использовать шариковые или гибридные подшипники

---

**❌ ОШИБКА 4: Неправильный выбор радиального зазора**

**Проблема:** Использование стандартного зазора (CN) при посадке с большим натягом или высокой температуре

**Последствия:** Уменьшение зазора до нуля, преднатяг, заклинивание

**Правильно:**
- При натяге > 20 мкм или температуре > 100°C выбирать зазор C3 или C4
- При температурном градиенте (вал горячее корпуса) увеличивать зазор

---

**❌ ОШИБКА 5: Игнорирование перекосов вала**

**Проблема:** Использование несамоустанавливающихся подшипников на длинных или гибких валах

**Последствия:** Неравномерное распределение нагрузки, ускоренный износ

**Правильно:**
- Для валов с прогибом/перекосами использовать сферические подшипники (тип 1, 3)
- Обеспечить жёсткость вала и точность монтажа для несамоустанавливающихся подшипников

---

**❌ ОШИБКА 6: Неучёт условий окружающей среды**

**Проблема:** Использование открытых подшипников в условиях повышенной запылённости или влажности

**Последствия:** Попадание загрязнений, коррозия, быстрый износ

**Правильно:**
- В пыльных/влажных условиях использовать подшипники с уплотнениями (2RS)
- В агрессивных средах использовать нержавеющие подшипники

#### ОШИБКИ ПРИ МОНТАЖЕ

**❌ ОШИБКА 7: Неправильный выбор посадки**

**Проблема:** Скользящая посадка на вращающемся кольце (проворачивание) или чрезмерный натяг

**Последствия:** Проворачивание кольца на валу, фреттинг-коррозия, или избыточный натяг → уменьшение зазора → перегрев

**Правильно:**
- Вращающееся кольцо относительно нагрузки → посадка с натягом (m6, n6)
- Неподвижное кольцо относительно нагрузки → переходная/скользящая посадка (js6, H7)

---

**❌ ОШИБКА 8: Монтаж с ударами по телам качения**

**Проблема:** Установка подшипника ударами молотка через тела качения

**Последствия:** Вмятины на дорожках качения (brinelling), преждевременный отказ

**Правильно:**
- Использовать монтажную втулку или оправку, опирающуюся на МОНТИРУЕМОЕ кольцо
- При насадке на вал — давить на внутреннее кольцо
- При запрессовке в корпус — давить на наружное кольцо

---

**❌ ОШИБКА 9: Отсутствие осевой фиксации или избыточная фиксация**

**Проблема:** Оба подшипника жёстко зафиксированы осево на длинном валу

**Последствия:** Температурные напряжения, заклинивание при нагреве

**Правильно:**
- Схема "фиксированная + плавающая опора": один подшипник фиксирован с двух сторон, второй свободен в осевом направлении
- Плавающая опора компенсирует тепловое расширение вала

---

**❌ ОШИБКА 10: Смешивание подшипников разных производителей в парной установке**

**Проблема:** Установка конических подшипников от разных производителей в парную схему

**Последствия:** Разные зазоры/преднатяги, неравномерная нагрузка, вибрация

**Правильно:**
- Конические и радиально-упорные подшипники в парной установке должны быть от одного производителя и из одной партии
- Производители часто поставляют подшипники парами с подобранным зазором

---

**❌ ОШИБКА 11: Загрязнение подшипника при монтаже**

**Проблема:** Монтаж в запылённых условиях, попадание абразива в смазку

**Последствия:** Абразивный износ, быстрый отказ

**Правильно:**
- Монтаж в чистых условиях
- Использовать чистые инструменты и ветошь
- Не снимать защитную упаковку до момента установки

---

**❌ ОШИБКА 12: Недостаточная или избыточная смазка**

**Проблема:** 
- Недостаток смазки → сухое трение, перегрев
- Избыток смазки → взбивание смазки, перегрев, утечки

**Последствия:** Перегрев, ускоренный износ, утечки смазки

**Правильно:**
- Открытые подшипники: заполнение смазкой на 30-50% свободного объёма
- Подшипники с уплотнениями (2RS): не требуют дополнительной смазки (уже заполнены)
- Консистентная смазка для низких/средних скоростей, масляная для высоких

#### ОШИБКИ ПРИ ЭКСПЛУАТАЦИИ

**❌ ОШИБКА 13: Отсутствие периодического обслуживания**

**Проблема:** Нерегулярная дозаправка смазкой, игнорирование вибрации и шума

**Последствия:** Высыхание смазки, износ, внезапный отказ

**Правильно:**
- Периодическая дозаправка смазкой (интервал зависит от условий работы)
- Вибродиагностика для раннего выявления дефектов
- Замена подшипников после выработки расчётного ресурса

---

**❌ ОШИБКА 14: Превышение допустимых нагрузок и скоростей**

**Проблема:** Эксплуатация подшипника в режимах, превышающих паспортные характеристики

**Последствия:** Ускоренный износ, разрушение, аварийный отказ

**Правильно:**
- Соблюдать номинальные параметры (нагрузка, скорость, температура)
- При изменении условий эксплуатации пересчитать ресурс

---

**❌ ОШИБКА 15: Повторное использование изношенных подшипников**

**Проблема:** Установка демонтированного подшипника повторно без дефектоскопии

**Последствия:** Скрытые дефекты (усталостные трещины, микротрещины) приводят к внезапному разрушению

**Правильно:**
- Подшипники — невосстанавливаемые детали, замена при демонтаже
- Исключение: прецизионные дорогие подшипники после дефектоскопии и заключения специалиста

### ДЕРЕВО РЕШЕНИЙ ДЛЯ ВЫБОРА ПОДШИПНИКА

**Блок-схема пошагового алгоритма:**

```
START
  │
  ├─► [1] Определить d (диаметр вала)
  │
  ├─► [2] Определить направление нагрузки
  │     ├─ Fa = 0 или Fa/Fr < 0,3 → РАДИАЛЬНЫЕ (6000, NU, N)
  │     ├─ 0,3 < Fa/Fr < 1,5 → РАДИАЛЬНО-УПОРНЫЕ (36000, 7000)
  │     └─ Fa/Fr > 1,5 или Fr = 0 → УПОРНЫЕ (51000, 81000)
  │
  ├─► [3] Величина нагрузки (Fr, Н)
  │     ├─ Низкая/средняя → Шариковые
  │     └─ Высокая → Роликовые
  │
  ├─► [4] Частота вращения (n, об/мин)
  │     ├─ Высокая (n > 10000) → Шариковые (6000)
  │     ├─ Средняя (1000 < n < 10000) → Шариковые или роликовые
  │     └─ Низкая (n < 1000) → Роликовые
  │
  ├─► [5] Условия эксплуатации
  │     ├─ Перекосы вала? → Сферические (1000, 3000)
  │     ├─ Высокая температура? → Специальные материалы, смазка
  │     ├─ Загрязнения? → Уплотнения (2RS)
  │     └─ Агрессивная среда? → Нержавеющие
  │
  ├─► [6] Расчёт грузоподъёмности
  │     ├─ Рассчитать P = X·Fr + Y·Fa
  │     ├─ Рассчитать C_требуемая
  │     └─ Выбрать подшипник: C_подшипника ≥ C_требуемая
  │
  ├─► [7] Проверка скорости
  │     └─ n_рабочая ≤ n_предельная? ДА → OK, НЕТ → пересмотр типа
  │
  ├─► [8] Выбор посадок
  │     ├─ Внутреннее кольцо: m6/n6 (вращается), js6/k6 (неподвижно)
  │     └─ Наружное кольцо: H7 (неподвижно), K7/M7 (вращается)
  │
  ├─► [9] Выбор зазора, уплотнений, класса точности
  │
  └─► [10] ИТОГОВАЯ ВЕРИФИКАЦИЯ (чек-лист)
        └─ ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ? → END (Подшипник выбран)
```

### ПРАКТИЧЕСКИЕ ПРИМЕРЫ

#### Пример 1: Подшипник для электродвигателя

**Условия:**
- Диаметр вала: d = 30 мм
- Нагрузка: Fr = 1500 Н, Fa = 0
- Частота вращения: n = 3000 об/мин
- Ресурс: 20000 ч
- Условия: чистые, температура до 80°C

**Решение:**

1. **Тип:** Fa = 0 → радиальный шариковый (серия 6000)
2. **Размер:** d = 30 → обозначение 06
3. **Серия:** Средняя серия 6306 (D = 72 мм, B = 19 мм)
4. **Расчёт:**
   - P = Fr = 1500 Н (только радиальная нагрузка)
   - L₁₀ = 20000 × 3000 × 60 / 10⁶ = 3600 млн об.
   - C_требуемая = 1500 × (3600)^(1/3) ≈ 23 200 Н
   - Подшипник 6306: C = 28 000 Н ✓
5. **Скорость:** n_пред (6306) = 12 000 об/мин > 3000 об/мин ✓
6. **Выбор:** **Подшипник 6306**

**Окончательный выбор:** **6306 ZZ** (с защитными шайбами для защиты от пыли)

#### Пример 2: Подшипник для ступицы колеса автомобиля

**Условия:**
- Диаметр вала: d = 40 мм
- Нагрузка: Fr = 8000 Н, Fa = 3000 Н
- Частота вращения: n = 1500 об/мин (при скорости 120 км/ч)
- Условия: вибрация, загрязнения, влага

**Решение:**

1. **Тип:** Fa/Fr = 3000/8000 = 0,375 → радиально-упорный, конический роликовый
2. **Размер:** d = 40 мм → 7208 или 7308
3. **Нагрузка:** Высокая → роликовый конический
4. **Выбор:** **Конический роликоподшипник 7208** (обычно парная установка)
5. **Защита:** Встроенные уплотнения (условия эксплуатации)

**Окончательный выбор:** **Пара конических 7208 с предварительным натягом**

#### Пример 3: Подшипник для вертикального вала (домкрат)

**Условия:**
- Нагрузка: Fa = 50000 Н (осевая), Fr = 0
- Частота вращения: n = 10 об/мин (медленное вращение)
- Условия: статическая нагрузка

**Решение:**

1. **Тип:** Fr = 0, только осевая → упорный подшипник (серия 51000)
2. **Нагрузка:** Статическая → проверка по C₀
3. **Выбор:** Шариковый упорный подшипник серии 51000 с C₀ > 50000 Н
4. **Скорость:** Низкая → любой тип подходит

**Окончательный выбор:** **Упорный шариковый подшипник 51222** (C₀ = 60 кН)

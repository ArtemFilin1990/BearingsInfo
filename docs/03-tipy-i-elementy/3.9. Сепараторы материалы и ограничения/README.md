# 3.9. Сепараторы: материалы и ограничения

## Назначение

Описание типов сепараторов (разделителей) подшипников, материалов изготовления, конструктивных особенностей и ограничений применения.

## Ключевые вопросы

- Какие функции выполняет сепаратор в подшипнике?
- Какие типы сепараторов существуют (штампованные, литые, механически обработанные)?
- Из каких материалов изготавливают сепараторы?
- Какие ограничения имеют различные типы сепараторов (скорость, температура, нагрузка)?
- Как обозначаются различные типы сепараторов в маркировке?

- **Функции сепаратора**:
  - Разделение тел качения (равномерное распределение по окружности)
  - Направление тел качения по дорожкам
  - Снижение трения между телами качения
  - Удержание тел качения при монтаже/демонтаже
  
- **Типы сепараторов по конструкции**:
  - **Штампованные (прессованные)**: из стального листа, лёгкие, недорогие, ограничены по скорости
  - **Литые (массивные)**: из латуни, алюминиевых сплавов, для высоких скоростей и нагрузок
  - **Механически обработанные (точёные)**: из латуни, стали, PEEK, для прецизионных подшипников
  - **Полнокомплектные подшипники**: без сепаратора, максимальное количество тел качения
  
- **Материалы сепараторов**:
  - **Сталь** (углеродистая, нержавеющая): универсальное применение, до 200-300°C
  - **Латунь** (CuZn, CuSn): высокие скорости, температуры до 300°C, хорошая теплопроводность
  - **Полимеры** (PA66, PEEK, PTFE): лёгкие, низкое трение, химическая стойкость, до 120-250°C
  - **Алюминиевые сплавы**: лёгкие, высокоскоростные применения
  
- **Ограничения по типу сепаратора**:
  - Штампованные: скорость до 70-80% предельной
  - Литые латунные: скорость до 100% предельной
  - Полимерные: температура ограничена, не для очень высоких нагрузок
  - Полнокомплектные: низкие скорости, склонность к нагреву
  
- **Обозначения сепараторов** (ГОСТ, ISO, производители):
  - M, MA — латунный литой
  - J — стальной штампованный
  - Y — штампованный (SKF)
  - TN, TNH — полиамидный
  - P — PEEK (полимер)
  
- **Выбор сепаратора** в зависимости от условий: скорость, температура, смазка, среда

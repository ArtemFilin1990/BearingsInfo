# 7.3. Суффиксы и обозначения по брендам

## Назначение

Систематизация дополнительных обозначений (суффиксов) в маркировке подшипников различных производителей и их расшифровка.

## Ключевые вопросы

- Какие суффиксы используются производителями в обозначениях подшипников?
- Как расшифровываются суффиксы SKF, FAG, NSK, NTN?
- Чем отличаются обозначения уплотнений, смазки, материалов у разных брендов?
- Как сопоставить суффиксы разных производителей для одинаковых характеристик?

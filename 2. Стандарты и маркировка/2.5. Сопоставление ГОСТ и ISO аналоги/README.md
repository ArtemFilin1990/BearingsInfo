# 2.5. Сопоставление ГОСТ и ISO: аналоги

## Назначение

Полное руководство по взаимному преобразованию обозначений подшипников качения между российской системой ГОСТ (Государственный стандарт) и международной системой ISO. Документ содержит таблицы соответствия, алгоритмы преобразования, примеры расчётов и практические рекомендации для инженеров, снабженцев и проектировщиков.

## Ключевые вопросы

- Как преобразовать обозначение подшипника ГОСТ в ISO и обратно?
- Какие подшипники ГОСТ имеют прямые ISO аналоги, а какие уникальны?
- Как определить размеры подшипника по обозначению ГОСТ и найти ISO эквивалент?
- В чём различия в системах кодирования суффиксов между ГОСТ и ISO?
- Какие классы точности ГОСТ соответствуют ISO классам?
- Как корректно заменить подшипник ГОСТ на импортный ISO при модернизации оборудования?

## Содержание

### 1. Основные различия систем ГОСТ и ISO

#### Структура обозначения ГОСТ (ГОСТ 3189-89)

```
Пример: 6-180305 Е
│       │ │  └─ Класс точности (Е = повышенная точность)
│       │ └──── Серия диаметров (03) и ширины (05)
│       └────── Диаметр отверстия (18 × 5 = 90 мм для кода ≥ 04)
└────────────── Тип подшипника (6 = радиальный шариковый однорядный)

Полная структура: [Тип]-[Код диаметра][Серия диаметра][Серия ширины] [Суффикс класса точности]
```

**Особенности ГОСТ:**
- Код диаметра отверстия: 
  - `00` = 10 мм
  - `01` = 12 мм
  - `02` = 15 мм
  - `03` = 17 мм
  - `≥04`: код × 5 = диаметр (например, `18` → 18×5 = 90 мм)
- Серии диаметров: `0` (сверхлёгкая), `2` (лёгкая), `3` (средняя), `4` (тяжёлая)
- Серии ширины: `0`, `1`, `2`, `3`, `5`, `6`, `7`, `8`, `9`

#### Структура обозначения ISO (ISO 15:2017)

```
Пример: 6318/C3
│       │  └─ Суффикс радиального зазора
│       └──── Базовое обозначение (тип 6, серия 03, диаметр 18)
└────────────── Префикс (отсутствует для стандартных исполнений)

Полная структура: [Префикс]-[Тип][Серия ширины][Серия диаметра][Код диаметра]-[Суффиксы]
```

**Ключевое различие:**
- ГОСТ: `6-180305` → тип `6`, диаметр `18`, серия диаметра `03`, серия ширины `05`
- ISO: `6318` → тип `6`, серия ширины `3` (средняя), серия диаметра `1` (лёгкая), диаметр `18`

**Важно:** Порядок цифр в ГОСТ и ISO **различается**!

### 3. Алгоритм преобразования ГОСТ → ISO

#### Шаг 1: Определить тип подшипника

Первая цифра (или группа цифр) ГОСТ обозначения указывает тип:
- `6-xxxxxx` → ISO `6xxx` (радиальный шариковый однорядный)
- `12-xxxxx` → ISO `NUxxx` (цилиндрический роликовый, тип NU)
- `7-xxxxxx` → ISO `3xxxx` (конический роликовый)

#### Шаг 2: Извлечь код диаметра отверстия

**Для ГОСТ:**
- Позиции 3-4 (после дефиса) = код диаметра
- Если код ≥ 04: диаметр = код × 5 мм
- Если код < 04: использовать таблицу (`00`=10, `01`=12, `02`=15, `03`=17)

**Пример:** `6-180305` → код диаметра `18` → d = 18 × 5 = 90 мм

#### Шаг 3: Определить серию диаметров и ширины

**ГОСТ:**
- Позиция 5-6 после дефиса: `03` = серия диаметра `0`, серия ширины `3`
- Позиция 7-8 после дефиса: `05` = уточнение серии ширины

**ISO:**
- Формат: `6[Серия ширины][Серия диаметра][Код диаметра]`
- Пример: `6318` = серия ширины `3`, серия диаметра `1`, код диаметра `18`

**Таблица соответствия серий:**

| **ГОСТ серия D**  | **ISO серия D** | **Описание**                |
|-------------------|-----------------|-----------------------------|
| 00, 01            | 0               | Сверхлёгкая (extra-light)   |
| 02                | 2               | Лёгкая (light)              |
| 03                | 3               | Средняя (medium)            |
| 04                | 4               | Тяжёлая (heavy)             |

| **ГОСТ серия B**  | **ISO серия B** | **Описание**                |
|-------------------|-----------------|-----------------------------|
| 05, 06, 07        | Различные       | Зависит от типа подшипника  |

#### Шаг 4: Собрать ISO обозначение

**Формула:** ISO = `[Тип ISO][Серия B ISO][Серия D ISO][Код d]`

**Пример:**
- ГОСТ: `6-180305`
- Тип: `6` → ISO `6`
- Диаметр: `18` → ISO `18`
- Серия D: `03` → ISO `3` (средняя)
- Серия B: `05` → ISO обычно `3` (для радиальных шариковых)
- **Результат:** ISO `6318`

#### Шаг 5: Проверить размеры в таблицах

**Обязательно сверить:** d (внутренний диаметр), D (наружный диаметр), B (ширина) с каталогами ISO!

### 4. Алгоритм преобразования ISO → ГОСТ

#### Пример: ISO `6308` → ГОСТ

**Шаг 1:** Тип `6` → ГОСТ тип `6-` (радиальный шариковый)

**Шаг 2:** Код диаметра `08` → d = 08 × 5 = 40 мм → ГОСТ код `08`

**Шаг 3:** ISO серия `3` (средняя) → ГОСТ серия диаметров `03`

**Шаг 4:** ISO серия ширины `0` (стандартная) → ГОСТ серия ширины `05`

**Результат:** ГОСТ `6-080305`

**Проверка:** 
- ISO `6308`: d=40 мм, D=90 мм, B=23 мм
- ГОСТ `6-080305`: d=40 мм, D=90 мм, B=23 мм ✓

### 11. Практические примеры преобразования

#### Пример 1: ГОСТ → ISO (радиальный шариковый)

**Дано:** ГОСТ `6-180305 Р5 С3`

**Решение:**
1. Тип `6-` → ISO `6` (радиальный шариковый)
2. Код диаметра `18` → d = 90 мм → ISO код `18`
3. Серия диаметра `03` → ISO серия `3` (средняя)
4. Серия ширины `05` → ISO серия `1` или `3` (проверить по таблице)
5. Класс точности `Р5` → ISO `P5`
6. Зазор `С3` → ISO `C3`

**Проверка по каталогу:**
- ГОСТ `6-180305`: d=90, D=190, B=43
- ISO `6318`: d=90, D=190, B=43 ✓

**Результат:** ISO `6318/P5/C3`

---

#### Пример 2: ISO → ГОСТ (цилиндрический роликовый)

**Дано:** ISO `NU 2210 E/C3`

**Решение:**
1. Тип `NU` → ГОСТ тип `12-` (борт на наружном кольце)
2. Код диаметра `10` → d = 50 мм → ГОСТ код `10`
3. ISO серия `22` → усиленная серия → ГОСТ серия `2210`
4. Зазор `C3` → ГОСТ `С3`

**Результат:** ГОСТ `12-102210 С3` или `2102 (NU2210)`

**Проверка:**
- ISO `NU2210`: d=50, D=90, B=23
- ГОСТ `12-102210`: d=50, D=90, B=23 ✓

---

#### Пример 3: ГОСТ → ISO (конический роликовый)

**Дано:** ГОСТ `7-312 Р6`

**Решение:**
1. Тип `7-` → ISO `32xxx` (конический, серия 320)
2. Код `312` → d = 60 мм (из таблицы конических подшипников)
3. Серия `3` → угол контакта α = 12° → ISO серия `323`

**Результат:** ISO `32312/P6`

**Проверка:**
- ГОСТ `7-312`: d=60, D=130, T=48.5
- ISO `32312`: d=60, D=130, T=48.5 ✓

---

#### Пример 4: ISO → ГОСТ (упорный шариковый)

**Дано:** ISO `51212`

**Решение:**
1. Тип `512` → ГОСТ тип `8-` (упорный шариковый однонаправленный)
2. Код диаметра `12` → d = 60 мм → ГОСТ код `12`
3. Серия `12` → стандартная серия → ГОСТ `8-19`

**Результат:** ГОСТ `8-8112` (упорный шариковый d=60 мм)

**Проверка по каталогу необходима!**

### 14. Рекомендации по замене ГОСТ → ISO

#### Когда замена безопасна:
- ✅ Радиальные шариковые однорядные (тип 6)
- ✅ Цилиндрические роликовые стандартных серий (NU, N, NJ)
- ✅ Конические роликовые метрические серии (проверить угол!)
- ✅ Упорные шариковые однонаправленные

#### Когда требуется дополнительная проверка:
- ⚠️ Сферические роликовые (уточнить тип роликов: симметричные/бочкообразные)
- ⚠️ Игольчатые (размеры могут не совпадать)
- ⚠️ Радиальные упорные (проверить угол контакта)
- ⚠️ Подшипники с уникальными суффиксами ГОСТ

#### Когда замена невозможна:
- ❌ Специальные исполнения ГОСТ (тип 64-, 66-, 100-)
- ❌ Дюймовые подшипники ГОСТ (если ISO метрические)
- ❌ Подшипники устаревших серий без ISO производства

### 15. Чек-лист для замены подшипника ГОСТ → ISO

```
☐ 1. Определить тип подшипника ГОСТ и найти ISO аналог в таблице
☐ 2. Преобразовать обозначение по алгоритму
☐ 3. Проверить габариты (d, D, B/T) в каталогах производителей:
    - Внутренний диаметр (d)
    - Наружный диаметр (D)
    - Ширина (B) или высота (T для конических)
☐ 4. Сравнить класс точности (Р0, Р5, Р6 → P0, P5, P6)
☐ 5. Проверить суффиксы:
    - Уплотнения (-2RS, -2Z)
    - Радиальный зазор (С2, С3, С4)
    - Материал сепаратора (Л, Г)
☐ 6. Для конических подшипников проверить угол конуса (α)
☐ 7. Проверить грузоподъёмность (C, C0) — должна быть ≥ ГОСТ
☐ 8. Уточнить доступность у поставщиков
☐ 9. Проверить совместимость по посадочным поверхностям (допуски вала/корпуса)
☐ 10. Убедиться в совместимости смазки (если подшипник с заводской смазкой)
```

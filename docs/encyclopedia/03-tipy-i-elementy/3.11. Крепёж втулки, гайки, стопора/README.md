# 3.11. Крепёж: втулки, гайки, стопора

## Назначение

Данный раздел описывает вспомогательные элементы для крепления и фиксации подшипников качения на валах и в корпусах. Правильный выбор и применение крепежных элементов обеспечивает надежную осевую и радиальную фиксацию подшипников, предотвращает осевые смещения, упрощает монтаж и демонтаж, а также позволяет использовать подшипники с коническим отверстием на цилиндрических валах.

## Ключевые вопросы

- Какие существуют типы крепежных элементов для подшипников?
- Как выбрать стопорную гайку для конкретного применения?
- В чем различие между адаптерными и стяжными втулками?
- Как рассчитать требуемое усилие затяжки гайки?
- Какие методы фиксации подшипников наиболее надежны?
- Какие стандарты регламентируют размеры крепежных элементов?

## Содержание

### Ключевые определения и рамки темы

**Крепежные элементы подшипников** — детали и узлы, предназначенные для осевой и радиальной фиксации подшипников на валу или в корпусе, а также для обеспечения требуемой посадки и предварительного натяга.

### Основные типы крепежных элементов

#### 1. Гайки для подшипников

**Стопорные гайки** — резьбовые крепежные элементы для осевой фиксации подшипников на валах с резьбой.

##### 1.1. Гайки круглые шлицевые (КМ, КМП)

**Конструкция:**
- Круглая гайка с наружными радиальными шлицами для ключа
- Резьба метрическая или специальная (например, М20×1, М30×1.5)
- Стопорная шайба с усиком для фиксации от отвинчивания

**Стандарты:**
- **ГОСТ 11871-88** — Гайки круглые шлицевые с радиальными отверстиями для шарикоподшипников
- **DIN 981** — Шлицевые гайки
- **ISO 2982** — Rolling bearings — Accessories – Locknuts

**Обозначения:**
- **КМ** — Круглая гайка для подшипника, метрическая резьба
- **КМП** — Гайка с пазами для стопорной шайбы

**Типоразмеры:**
- Диаметр резьбы: М10...М250
- Шаг резьбы: мелкий (1.0, 1.5, 2.0 мм)
- Материал: сталь 45, 40Х (HRC 35-45)

**Применение:**
- Фиксация подшипников на валах с нарезанной резьбой
- Преимущественно для радиальных и радиально-упорных подшипников
- Обеспечение осевого прижима подшипника к буртику вала

**Момент затяжки:**
$$M_з = 0.2 \times d \times F_ос$$

где:
- $d$ — номинальный диаметр резьбы, мм
- $F_{ос}$ — требуемая осевая сила, Н

##### 1.2. Гайки с внутренним шестигранником

**Конструкция:**
- Низкопрофильная гайка с внутренним шестигранником под ключ
- Компактная конструкция для ограниченного пространства
- Резьба метрическая мелкая

**Применение:**
- Ограниченное осевое пространство
- Высокие моменты затяжки
- Эстетичные применения (скрытый монтаж)

##### 1.3. Гайки КМП с предохранительными пластинами

**Конструкция:**
- Стопорная шайба МВ с внутренним усиком
- Усик входит в паз вала или шлиц гайки
- Предотвращает самоотвинчивание при вибрациях

**Стандарты:**
- **ГОСТ 13643-88** — Шайбы стопорные с лапкой
- **DIN 5406** — Стопорные шайбы с носиком

**Применение:**
- Оборудование с вибрациями и ударными нагрузками
- Обязательно для ответственных применений

##### 1.4. Гидравлические гайки (для монтажа)

**Принцип действия:**
- Гидравлическое масло подается в кольцевую камеру гайки
- Давление (1000-2000 бар) расширяет гайку, снижая трение
- После сброса давления гайка обеспечивает требуемый натяг

**Применение:**
- Крупные подшипники (d > 200 мм)
- Точное обеспечение предварительного натяга
- Упрощение монтажа тяжелых подшипников

#### 2. Втулки для подшипников

Втулки позволяют устанавливать подшипники с коническим отверстием (конусность 1:12 или 1:30) на цилиндрические валы, обеспечивая радиальный натяг и упрощая монтаж/демонтаж.

##### 2.1. Адаптерные втулки (серия H)

**Конструкция:**
- Втулка с наружным коническим посадочным местом 1:12
- Внутреннее цилиндрическое отверстие под вал
- Осевая прорезь по всей длине для радиального сжатия
- Резьбовое отверстие для монтажного болта
- Стопорная канавка или отверстия для фиксации

**Обозначение (SKF):**
- **H 2308** — адаптерная втулка для подшипника 1208K/2208K
- **H 3120** — адаптерная втулка для подшипника 1220K/2220K

**Размеры:**
- Диаметр отверстия: 20...500 мм
- Конусность наружной поверхности: 1:12
- Материал: сталь 45, термообработка

**Монтаж:**
1. Надеть втулку на вал, совместив стопорный элемент с пазом вала
2. Надеть подшипник на втулку
3. Затянуть гайку или болт, заставляя подшипник перемещаться по конусу
4. Контролировать увеличение радиального зазора подшипника (затяжка до выбора осевого зазора)

**Демонтаж:**
- Отвинтить гайку
- Ввернуть болт в резьбовое отверстие втулки для стягивания подшипника

**Преимущества:**
- Простота монтажа без нагрева
- Обеспечение радиального натяга
- Легкий демонтаж
- Не требуется высокая точность вала (h9-h11)

**Недостатки:**
- Увеличение габаритов узла
- Дополнительная стоимость
- Не для высоких скоростей (эксцентриситет)

##### 2.2. Стяжные втулки (серия AH, AHX)

**Конструкция:**
- Цилиндрическая втулка с внутренней конической поверхностью
- Осевая прорезь для радиального расширения
- Стяжная гайка на резьбе втулки
- При затяжке гайки втулка расширяется и зажимается на валу

**Обозначение:**
- **AH 2308** — стяжная втулка для подшипника с цилиндрическим отверстием
- **AHX 2317** — усиленная стяжная втулка

**Монтаж:**
1. Надеть втулку на вал
2. Установить подшипник на втулку
3. Затянуть гайку, втулка расширяется и зажимается на валу

**Применение:**
- Подшипники с цилиндрическим отверстием
- Цилиндрические валы без резьбы
- Упрощенный монтаж/демонтаж

##### 2.3. Конические втулки (серия SNW, SNV)

**Конструкция:**
- Разъемная втулка из двух половин с конической наружной поверхностью
- Стяжные болты для сжатия половин
- Эксцентриковое расположение отверстий для регулировки

**Применение:**
- Крупногабаритные подшипники в корпусных узлах
- Быстрый монтаж/демонтаж без съема соседних деталей
- Промышленные редукторы, конвейеры

#### 3. Стопорные кольца и шайбы

##### 3.1. Стопорные кольца пружинные

**Типы:**
- **Наружные** — фиксация в канавках валов (DIN 471, ГОСТ 13942)
- **Внутренние** — фиксация в канавках отверстий (DIN 472, ГОСТ 13943)

**Материал:**
- Пружинная сталь 65Г, 70С2ХА (HRC 42-52)

**Применение:**
- Осевая фиксация подшипников при малых нагрузках
- Ограничение осевого перемещения
- Применение до 200°C

**Расчет несущей способности:**
Допустимая осевая сила:
$$F_{доп} = \sigma_{доп} \times S$$

где:
- $\sigma_{доп}$ — допустимое напряжение материала (600-800 МПа)
- $S$ — площадь сечения кольца, мм²

**Ограничения:**
- Не для ударных и реверсивных нагрузок
- Требуется точная канавка (h11)
- Ослабление вала в зоне канавки (концентрация напряжений)

##### 3.2. Стопорные кольца эксцентриковые

**Конструкция:**
- Разрезное кольцо с эксцентрично расположенным отверстием
- При повороте кольцо зажимается на валу

**Применение:**
- Быстрая фиксация без специальных инструментов
- Регулируемые узлы

##### 3.3. Концевые шайбы

**Конструкция:**
- Плоские или торцевые шайбы с центрирующим пояском
- Фиксация винтами к торцу вала

**Применение:**
- Фиксация подшипников на концах валов
- Малые осевые нагрузки

#### 4. Другие методы фиксации

##### 4.1. Резьбовые буртики

**Описание:**
- Резьба нарезается непосредственно на валу в зоне посадки подшипника
- Гайка навинчивается на вал и прижимает торец внутреннего кольца

**Преимущества:**
- Компактность
- Высокая осевая жесткость
- Не требуются дополнительные детали

**Недостатки:**
- Концентрация напряжений в основании резьбы
- Сложность изготовления
- Затруднен демонтаж

##### 4.2. Торцевые крышки с винтами

**Конструкция:**
- Крышка крепится винтами к торцу вала
- Крышка прижимает торец внутреннего кольца подшипника

**Применение:**
- Малые нагрузки
- Подшипники на концах валов

##### 4.3. Упорные кольца запрессованные

**Конструкция:**
- Кольцо из стали с натягом запрессовывается на вал
- Служит упором для торца внутреннего кольца

**Применение:**
- Средние осевые нагрузки
- Постоянные узлы (затруднен демонтаж)

### Типовые примеры и сценарии применения

#### Пример 1: Фиксация радиально-упорного подшипника на шпинделе

**Условия:**
- Подшипник: 7210 BEP (угловой контакт, универсальная схема)
- Диаметр вала: 50 мм
- Осевая нагрузка: 5000 Н
- Требуется предварительный натяг

**Решение:**
1. **Вал:**
   - Резьба М52×1.5 на конце вала
   - Буртик для упора наружного кольца
   - Стопорный паз под шайбу МВ

2. **Крепежные элементы:**
   - Гайка КМ 52×1.5 (круглая шлицевая)
   - Стопорная шайба МВ 52
   - Момент затяжки: $M_з = 0.2 \times 52 \times 5000 = 52000$ Н·мм = 52 Н·м

3. **Монтаж:**
   - Напрессовать подшипник на вал с натягом (посадка js5/k5)
   - Установить стопорную шайбу усиком в паз вала
   - Навинтить гайку и затянуть моментом 52 Н·м
   - Отогнуть усик шайбы в шлиц гайки

**Обоснование:**
- Круглая гайка обеспечивает равномерное осевое усилие
- Стопорная шайба предотвращает отвинчивание при вибрациях
- Контроль затяжки по моменту обеспечивает требуемый предварительный натяг

#### Пример 2: Установка сферического подшипника в корпусе конвейера

**Условия:**
- Подшипник: 22218 K/C3 (сферический двухрядный с коническим отверстием 1:12)
- Вал цилиндрический: ø80 мм, h9
- Радиальная нагрузка: 15000 Н
- Требуется упрощенный монтаж/демонтаж

**Решение:**
1. **Адаптерная втулка:** H 2218
   - Внутреннее отверстие: ø80 h9
   - Наружная конусность: 1:12
   - Стопорная шайба с усиком

2. **Стопорная гайка:** КМ 18
   - Резьба: М90×2

3. **Монтаж:**
   - Надеть втулку H 2218 на вал, совместив усик с пазом вала
   - Надеть подшипник 22218 K на втулку
   - Навинтить гайку КМ 18 и затянуть до выбора осевого зазора
   - Контроль: измерить увеличение радиального зазора (должно быть 0.020-0.030 мм)
   - Застопорить гайку шайбой

**Обоснование:**
- Адаптерная втулка обеспечивает радиальный натяг без нагрева
- Не требуется точная обработка вала (h9 вместо j6/k6)
- Легкий демонтаж отвинчиванием гайки и стягиванием подшипника

#### Пример 3: Фиксация подшипника малого диаметра в электродвигателе

**Условия:**
- Подшипник: 6205 2RS (глубокий желоб, уплотнения)
- Диаметр вала: 25 мм
- Осевая нагрузка: 200 Н
- Ограничение по габаритам

**Решение:**
1. **Наружное стопорное кольцо:**
   - DIN 471-25 (для вала ø25 мм)
   - Материал: 65Г, HRC 44-51
   - Канавка на валу: глубина 1.0 мм

2. **Монтаж:**
   - Напрессовать подшипник с натягом (посадка k6)
   - Разжать стопорное кольцо съемником
   - Установить кольцо в канавку вала

**Обоснование:**
- Компактное решение (не требует резьбы)
- Низкая стоимость
- Достаточно для малых осевых нагрузок
- Легкий демонтаж (снять кольцо и спрессовать подшипник)

**Расчет несущей способности:**
- Сечение кольца DIN 471-25: $S \approx 3$ мм²
- Допустимая сила: $F_{доп} = 600 \times 3 = 1800$ Н > 200 Н ✓

### Расчет и проектирование

#### Расчет момента затяжки гайки

**Основная формула:**
$$M_з = \frac{P \times d_2}{2} \times \left(\frac{p}{\pi d_2} + \mu \frac{\sec \alpha}{1} + \mu_т \frac{D_{ш}}{d_2}\right)$$

**Упрощенная формула:**
$$M_з \approx 0.2 \times d \times P$$

где:
- $M_з$ — момент затяжки, Н·мм
- $d$ — номинальный диаметр резьбы, мм
- $P$ — требуемая осевая сила затяжки, Н
- $d_2$ — средний диаметр резьбы, мм
- $p$ — шаг резьбы, мм
- $\mu$ — коэффициент трения в резьбе (0.12-0.18)
- $\mu_т$ — коэффициент трения торца (0.10-0.15)
- $D_{ш}$ — средний диаметр опорной поверхности, мм

**Требуемая осевая сила:**

Для обеспечения предварительного натяга:
$$P = K \times C_{0r}$$

где:
- $K$ — коэффициент натяга (0.01-0.05 для легкого, 0.05-0.10 для среднего натяга)
- $C_{0r}$ — базовая статическая грузоподъемность, Н

Для компенсации осевой нагрузки:
$$P \geq 1.5 \times F_а$$

где $F_а$ — внешняя осевая нагрузка, Н

#### Расчет несущей способности стопорного кольца

**Допустимая осевая сила:**
$$F_{доп} = \frac{\sigma_{доп} \times b \times t}{k}$$

где:
- $\sigma_{доп}$ — допустимое напряжение (600-800 МПа для стали 65Г)
- $b$ — ширина кольца, мм
- $t$ — толщина кольца, мм
- $k$ — коэффициент запаса (1.5-2.0)

**Проверка вала на концентрацию напряжений:**
$$\sigma_{max} = K_t \times \frac{32 M}{\pi d^3}$$

где:
- $K_t$ — теоретический коэффициент концентрации (2.0-3.0 для канавки)
- $M$ — изгибающий момент, Н·мм
- $d$ — диаметр вала в канавке, мм

#### Определение величины натяга при монтаже на втулку

**Увеличение радиального зазора:**
$$\Delta G_r = \frac{B \times \tan \alpha}{12}$$

для конусности 1:12, где:
- $B$ — ширина посадочной поверхности внутреннего кольца, мм
- $\alpha$ — угол конуса (4°46')

**Осевое перемещение для достижения требуемого натяга:**
$$\Delta x = 12 \times \Delta G_r$$

**Контроль:**
Измерить радиальный зазор до и после монтажа:
$$\Delta G_r = G_{r\_после} - G_{r\_до}$$

Для подшипников с C3: $\Delta G_r = 0.020-0.040$ мм

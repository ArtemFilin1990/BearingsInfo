# Классификация подшипников

## Назначение
Данный документ содержит комплексную систему классификации подшипников качения по направлению нагрузки, типу конструкции и применению.

## Классификация по направлению нагрузки

### 1. Радиальные подшипники (Радиальные подшипники)
**Основное направление нагрузки:** Перпендикулярно к оси подшипника

**Характеристики:**
- Предназначены в основном для радиальных нагрузок
- Некоторые типы могут воспринимать ограниченные осевые нагрузки
- Наиболее распространенная категория подшипников

**Примеры:**
- Шариковые радиальные однорядные подшипники
- Роликовые подшипники с короткими цилиндрическими роликами
- Роликовые игольчатые подшипники
- Роликовые сферические двухрядные подшипники

### 2. Упорные подшипники (Упорные подшипники)
**Основное направление нагрузки:** Параллельно оси подшипника

**Характеристики:**
- Предназначены в основном для осевых (упорных) нагрузок
- Ограниченная или нулевая радиальная грузоподъёмность
- Часто используются в вертикальных валах

**Примеры:**
- Шариковые упорные подшипники
- Роликовые упорные с цилиндрическими роликами
- Роликовые упорные сферические подшипники

### 3. Комбинированные подшипники (Комбинированные подшипники)
**Направление нагрузки:** Одновременно радиальная и осевая

**Характеристики:**
- Предназначены для одновременного восприятия радиальных и осевых нагрузок
- Угол контакта обеспечивает упорную способность
- Универсальные применения

**Примеры:**
- Шариковые радиально-упорные подшипники
- Роликовые конические подшипники
- Роликовые сферические двухрядные подшипники

## Классификация по типу тел качения

### Шариковые подшипники (Шариковые подшипники)

**Характеристики:**
- Точечный контакт между шариком и дорожкой качения
- Меньшее трение
- Более высокая скоростная способность
- Меньшая грузоподъёмность, чем у роликовых подшипников
- Доступны в различных конструкциях

**Типы:**
- Шариковые радиальные однорядные подшипники
- Шариковые радиально-упорные подшипники
- Шариковые радиальные сферические двухрядные подшипники
- Шариковые упорные подшипники

### Роликовые подшипники (Роликовые подшипники)

**Характеристики:**
- Линейный контакт между роликом и дорожкой качения
- Более высокая грузоподъёмность
- Меньшая скоростная способность, чем у шариковых подшипников
- Различные формы роликов для разных применений

**Типы:**
- Роликовые подшипники с короткими цилиндрическими роликами
- Роликовые конические подшипники
- Роликовые сферические двухрядные подшипники
- Роликовые игольчатые подшипники

## Основные типы подшипников

### 1. Шариковые радиальные однорядные (Шариковые радиальные однорядные)

**Обозначение по ГОСТ:** серии 0, 60, 61, 62, 63, 64, 160, 180

**Характеристики:**
- Наиболее распространенный тип подшипников
- Глубокие канавки дорожек качения (~30% диаметра шарика)
- Низкое трение, низкий уровень шума
- Высокая скоростная способность
- Могут воспринимать некоторую осевую нагрузку в обоих направлениях

**Применения:**
- Электродвигатели
- Редукторы
- Автомобильные компоненты
- Общее машиностроение

**Варианты:**
- Открытые (без уплотнений)
- С защитными шайбами (Z, ZZ)
- С уплотнениями (RS, 2RS)
- Со стопорным кольцом (N, NR)

### 2. Шариковые радиально-упорные (Шариковые радиальные-упорные)

**Обозначение по ГОСТ:** серии 36, 46, 66, 76

**Характеристики:**
- Угол контакта: 15°, 25°, 40°
- Высокая осевая грузоподъёмность в одном направлении
- Используются попарно или в комплектах для двунаправленных нагрузок
- Более высокая скорость, чем у конических роликовых подшипников

**Схемы установки:**
- Спина к спине (DB) - высокая жесткость на опрокидывание
- Лицом к лицу (DF) - менее распространено
- Тандем (DT) - удвоенная осевая грузоподъёмность

**Применения:**
- Шпиндели станков
- Ступицы автомобильных колес
- Компрессоры и насосы
- Прецизионные применения

### 3. Шариковые радиальные сферические двухрядные (Шариковые радиальные сферические двухрядные)

**Обозначение по ГОСТ:** серии 1200, 1300

**Характеристики:**
- Сферическая наружная дорожка качения
- Допускает угловой перекос: 1,5° - 3°
- Два ряда шариков
- Умеренная грузоподъёмность
- Хорошо работают при прогибе вала

**Применения:**
- Сельскохозяйственные машины
- Конвейеры
- Деревообрабатывающее оборудование
- Применения с несоосностью вала

### 4. Роликовые с короткими цилиндрическими роликами (Роликовые с короткими цилиндрическими роликами)

**Обозначение по ГОСТ:** серии 2000, 42000, 32000, 3000, 92000

**Характеристики:**
- Высокая радиальная грузоподъёмность
- Умеренная скоростная способность
- Разборная конструкция
- Низкое трение
- Некоторые конструкции допускают осевое смещение

**Конструкции:**
- NU - наружное кольцо с бортами, внутреннее кольцо без бортов
- N - внутреннее кольцо с бортами, наружное кольцо без бортов
- NJ - наружное кольцо с бортами, внутреннее кольцо с одним бортом
- NUP - NJ + съемный борт на внутреннем кольце

**Применения:**
- Редукторы
- Электродвигатели (больших размеров)
- Буксы железнодорожного транспорта
- Прокатные станы

### 5. Роликовые игольчатые (Роликовые игольчатые)

**Обозначение по ГОСТ:** серии 4000, 5000

**Характеристики:**
- Очень малое поперечное сечение
- Высокая радиальная грузоподъёмность
- Низкая скоростная способность
- Отношение длины к диаметру > 2,5
- Требуют точной соосности

**Типы:**
- С внутренним кольцом
- Без внутреннего кольца (вал служит внутренней дорожкой качения)
- Штампованные чашки
- Сепараторные узлы

**Применения:**
- Шатуны
- Коромысла клапанов
- Карданные шарниры
- Компактные редукторы

### 6. Роликовые конические (Роликовые конические)

**Обозначение по ГОСТ:** серии 7000, 27000, 97000

**Характеристики:**
- Конические ролики и дорожки качения
- Высокая радиальная и осевая грузоподъёмность
- Разборные (чашка и конус)
- Должны регулироваться для предварительного натяга
- Умеренная скорость

**Схемы установки:**
- Однорядные - упор в одном направлении
- Двухрядные - двунаправленный упор
- Четырехрядные - тяжелые нагрузки (прокатные станы)

**Применения:**
- Ступицы автомобильных колес
- Редукторы
- Тяжелое оборудование
- Железнодорожные применения

### 7. Роликовые сферические двухрядные (Роликовые сферические двухрядные)

**Обозначение по ГОСТ:** серии 3500, 3600

**Характеристики:**
- Самоустанавливающиеся: 1° - 2,5°
- Очень высокая грузоподъёмность
- Два ряда бочкообразных роликов
- Сферическая наружная дорожка качения
- Умеренная или низкая скорость

**Применения:**
- Дробилки и мельницы
- Бумагоделательные машины
- Горнодобывающее оборудование
- Тяжелое промышленное оборудование

### 8. Шариковые упорные (Шариковые упорные)

**Обозначение по ГОСТ:** серии 8000, 9000

**Характеристики:**
- Чистая осевая грузоподъёмность
- Минимальная радиальная грузоподъёмность
- Одно- или двунаправленные
- Высокая скоростная способность
- Требуют точной соосности

**Типы:**
- Однонаправленные (одна шайба + корпусная шайба)
- Двунаправленные (две шайбы + центральная шайба)

**Применения:**
- Крановые крюки
- Вертикальные валы
- Автомобильные сцепления
- Шпиндели станков (легкие осевые нагрузки)

### 9. Роликовые упорные с цилиндрическими роликами (Роликовые упорные с цилиндрическими роликами)

**Обозначение по ГОСТ:** серии 81100, 81200

**Характеристики:**
- Очень высокая осевая грузоподъёмность
- Нулевая радиальная грузоподъёмность
- Меньшая скорость, чем у шариковых упорных подшипников
- Разборная конструкция

**Применения:**
- Винтовые прессы
- Вертикальные насосы
- Поворотные платформы кранов
- Тяжелые упорные нагрузки

### 10. Роликовые упорные сферические (Роликовые упорные сферические)

**Обозначение по ГОСТ:** серия 9000 (специальные)

**Характеристики:**
- Очень высокая осевая грузоподъёмность
- Могут воспринимать некоторую радиальную нагрузку
- Способность к самоустановке
- Асимметричная конструкция роликов

**Применения:**
- Гидротурбины
- Гребные валы судов
- Большие вертикальные двигатели
- Тяжелые комбинированные нагрузки

## Классификация по конструктивным особенностям

### Уплотненные и открытые
- **Открытые подшипники** - требуют внешнего уплотнения
- **С защитными шайбами (Z, ZZ)** - бесконтактные металлические шайбы
- **С уплотнениями (RS, 2RS)** - контактные резиновые уплотнения
- **Смазанные на весь срок службы** - уплотненные со смазкой, без обслуживания

### Классы точности
- **Нормальный (P0/Class 0)** - общие применения
- **P6/Class 6** - улучшенная точность
- **P5/Class 5** - прецизионные применения
- **P4/Class 4** - высокая точность (станки)
- **P2/Class 2** - ультрапрецизионные (специальные применения)

### Варианты материалов
- **Стандартная сталь** - подшипниковая сталь сквозной закалки
- **Нержавеющая сталь** - коррозионная стойкость
- **Гибрид (керамические шарики)** - высокая скорость, низкое трение
- **Полная керамика** - экстремальные условия

### Специальные особенности
- **Канавка стопорного кольца** - осевая фиксация
- **Заполнительная выемка** - увеличенный комплект шариков
- **Установочное стопорное кольцо** - для позиционирования наружного кольца
- **Встроенный фланец** - упрощенный монтаж

## Дерево принятия решений по выбору

```
1. Каково основное направление нагрузки?
   ├─ Только радиальная → Шариковые радиальные однорядные, Цилиндрические роликовые, Игольчатые
   ├─ Только осевая → Шариковые упорные, Цилиндрические роликовые упорные
   └─ Комбинированная → Шариковые радиально-упорные, Конические роликовые, Сферические роликовые

2. Ограничено ли пространство?
   ├─ Радиальное пространство ограничено → Игольчатые роликовые подшипники
   ├─ Осевое пространство ограничено → Тонкостенные подшипники
   └─ Нет ограничений → Стандартные подшипники

3. Ожидается ли перекос?
   ├─ Да → Сферические шариковые, Сферические роликовые
   └─ Нет → Переход к следующему вопросу

4. Каково требование к скорости?
   ├─ Очень высокая → Шариковые радиальные однорядные, Шариковые радиально-упорные
   ├─ Высокая → Цилиндрические роликовые
   ├─ Умеренная → Конические роликовые
   └─ Низкая → Сферические роликовые

5. Какова величина нагрузки?
   ├─ Очень высокая → Сферические роликовые, Конические роликовые
   ├─ Высокая → Цилиндрические роликовые
   ├─ Умеренная → Шариковые радиальные однорядные (большие размеры)
   └─ Низкая → Шариковые радиальные однорядные (малые размеры)

6. Есть ли специальные требования?
   ├─ Коррозионная стойкость → Подшипники из нержавеющей стали
   ├─ Высокая температура → Специальные материалы/смазки
   ├─ Низкое трение → Гибридные подшипники
   ├─ Без обслуживания → Уплотненные, смазанные на весь срок службы
   └─ Нет → Стандартный подшипник с соответствующими уплотнениями/смазкой
```
